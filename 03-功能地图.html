﻿# 功能地图

1. 运营端

一级模块 二级能力 说明
用户管理 用户列表、用户详情 查看平台用户基础信息、拥有团队、加入团队、关联 FlowSpace
团队管理 团队列表、团队详情、成员信息、角色列表、协作邀请记录 平台视角管理团队数据和邀请记录
FlowSpace 管理 FlowSpace 列表、FlowSpace 数据详情、成员记录、邮件协作列表、自动化记录 平台视角查看和管理团队 FlowSpace 数据
FlowSpace 仪表盘 仪表盘列表、仪表盘管理 运营端管理 FlowSpace 仪表盘
模板中心 业务模板管理、资源库模板管理 创建、编辑、复制、发布、分配、同步模板
模板设计 表单设计组件、表单属性、显隐设置、里程碑第三方数据对接 定义业务模板和资源库模板的结构
资源库管理 团队资源库列表、资源库数据明细 平台视角查看团队资源库数据
设置 软件更新管理、软件更新记录 管理软件版本信息和记录
集成与报告 外部 API 集成配置、报告管理 支撑外部系统对接和报告能力

2. 贸易端

一级模块 二级能力 说明
账号与个人 注册登录、忘记密码、个人信息、语言切换、退出账号 用户身份与个人设置
团队 创建团队、团队信息、团队角色、成员管理、协作团队管理、邀请流程 团队级组织和协作关系管理
工作台 FlowSpace 列表、创建 FlowSpace、FlowSpace 分组、订单日程、任务中心、常用视图 团队用户进入业务的首页
FlowSpace 设置 基本信息、业务角色、协作方角色、数据围栏、成员、协作团队、里程碑计划、标签、更多设置 FlowSpace 级业务配置
协作 FlowSpace 设置 协作方角色、主团队角色、协作成员、权限设置 协作团队参与 FlowSpace 时的权限与成员管理
订单列表 订单查看、增删改、导入导出、视图设置、子表视图、工单视图、批量操作 订单级数据管理入口
订单详情 详情查看、看板/表格模式、工单创建、采集、批复、里程碑批复、邮件协作、历史、动态、跟踪记录 订单执行主场景
订单管理 订单翻单、订单关联、里程碑互用、工单互用 业务复用和关系管理
资源库 创建资源库、资源库设置、资源库数据、视图管理、分享、FlowSpace 应用数据范围、数据编辑历史 团队主数据管理
自动化 自动化列表、触发条件、执行动作、执行日志、定时任务 FlowSpace 内自动执行业务动作
消息与协作 消息中心、实时消息、邮件协作、批量邮件协作 业务通知和跨团队沟通
日志与审计 设置类操作日志、资源库日志、系统自动执行日志 追踪配置和系统动作
仪表盘与报告 仪表盘权限、报告权限 数据展示和权限控制

3. 采集端

一级模块 二级能力 说明
登录 邮箱密码登录、忘记密码 移动端账号入口
首页 我的任务、团队待指派、我关注、FlowSpace 入口、任务数据展示 移动端任务聚合
任务列表 进行中、已完成、我发起、团队指派、我关注、操作入口 工单、工单批复、里程碑批复任务列表
任务搜索 从任务列表进入搜索页 搜索工单和批复任务
任务详情 工单详情、工单批复详情、里程碑批复详情、订单信息 移动端处理和查看任务
消息中心 首页消息入口、消息列表 查看移动端通知
我的 个人信息、多语言、修改密码、帮助中心、联系成功经理、检查更新、退出账号 个人设置和支持入口

4. 公共横向能力

能力 覆盖范围 需要沉淀的规则
权限体系 团队、FlowSpace、协作 FlowSpace、资源库、仪表盘、报告 权限点、角色叠加、成员范围、协作方边界
状态机 订单、里程碑、工单、批复、自动化、导入导出 状态枚举、状态变更入口、状态限制和异常提示
表单体系 业务模板、资源库模板、订单、工单、批复、采集端 组件、校验、显隐、公式、默认值、移动端展示
数据导入导出 订单、工单、资源库 模板下载、上传校验、记录、失败原因、权限
消息通知 站内、实时、邮件、短信 触发事件、接收对象、模板、免打扰或屏蔽规则
日志审计 操作日志、动态、历史记录、跟踪记录、系统日志 操作人、操作对象、快照、自动程序标识
复用关系 订单翻单、订单关联、里程碑互用、工单互用、资源库引用 来源、目标、同步、取消、历史保留
