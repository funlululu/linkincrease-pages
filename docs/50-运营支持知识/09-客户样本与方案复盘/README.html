09 客户样本与方案复盘

本目录用于沉淀匿名客户样本、方案试点记录、上线复盘和可复用经验。它补足行业知识和 SOP 的“真实经验层”，帮助产品成功知道哪些方案真的跑通过、哪些只是理论建议。

使用原则

  1. 必须匿名化客户名称、人员、账号、合同、报价和敏感数据。
  2. 原始聊天或会议纪要不直接入库，先提炼为结构化样本。
  3. 单个客户做法不能外推为行业标准，只能标记为客户样本。
  4. 可复用结论需要说明适用边界。
  5. 产品规则缺口进入需求池或待确认问题，不直接改权威页。
