资源库数据不同步

常见原因

原因 说明
同步规则未配置 FlowSpace 结果不会自动写入资源库
触发条件未满足 只有审批通过、状态变更或字段完整时才同步
字段映射缺失 流程字段和资源库字段没有对应关系
重复匹配失败 没有唯一编码，导致无法判断新增还是更新
权限不足 执行人无资源库写入权限

排查步骤

  1. 确认期望同步的来源 FlowSpace 和目标资源库。
  2. 检查同步触发条件。
  3. 检查字段映射和唯一匹配字段。
  4. 对比源记录和目标资源库记录。
  5. 记录不同步的具体字段和发生时间。

运营建议

资源库同步必须设计唯一键，例如供应商编码、工厂编码、证书编号。没有唯一键的同步容易产生重复记录。
