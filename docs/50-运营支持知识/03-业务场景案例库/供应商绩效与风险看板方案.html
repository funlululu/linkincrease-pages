供应商绩效与风险看板方案

客户现状

适用于客户已经在 Linkincrease 中沉淀了供应商、工厂、订单、验货、审核或 CAP 数据，希望进一步看供应商表现和风险的场景。常见问题是数据分散在多个 FlowSpace 和资源库中，管理层无法判断哪些供应商表现好、哪些需要复审或限制。

业务目标

  1. 明确供应商绩效和风险指标的管理用途。
  2. 将订单、验货、审核、CAP 和资源库数据关联到供应商/工厂。
  3. 形成可解释的看板，不做无法验证的黑箱评分。
  4. 支持采购、质量、合规和管理层做运营动作。

推荐配置

业务内容 Linkincrease 配置
供应商/工厂主数据 供应商库、工厂库
订单履约指标 订单 FlowSpace + 仪表盘
质量指标 验货工单、质量异常、CAP
合规指标 审核 FlowSpace、证书有效期
风险状态 资源库字段 + 人工评审
改善计划 改善工单或 CAP
管理看板 Tower 仪表盘、报告

资源库设计

资源库 建议字段
供应商库 供应商等级、风险等级、准入状态、最近评审日期、改善状态
工厂库 质量风险、审核状态、证书有效性、CAP 未关闭数量
指标配置表 指标名称、口径、数据来源、责任人、刷新频率

FlowSpace / 模板设计

数据来源 建议沉淀
订单 FlowSpace 准时交付、延期、异常、任务响应
验货 FlowSpace 验货结果、缺陷、复验、质量异常
审核/CAP FlowSpace 审核结果、CAP 关闭、逾期
改善计划 FlowSpace 改善措施、责任人、效果复核

权限边界

角色 权限建议
管理层 查看汇总看板和趋势
采购负责人 查看供应商维度绩效和改善计划
质量/合规负责人 查看质量、审核、CAP 风险
供应商 可选择性查看自身待改善事项，不看其他供应商
产品成功/运营 维护指标口径和数据质量

自动化提醒

  • 证书、审核、CAP 到期或逾期提醒。
  • 供应商风险等级变为高时提醒负责人。
  • 改善计划到期未完成时提醒和升级。

仪表盘指标

指标 用途
准时交付率 评估供应商交付稳定性
验货通过率 评估质量稳定性
CAP 按期关闭率 评估整改执行力
证书有效覆盖率 管理合规基础
高风险供应商/工厂数 管理层优先关注
改善计划完成率 评估行动效果

上线步骤

  1. 先确认看板用于什么决策。
  2. 选择 3-5 个当前数据能支撑的指标。
  3. 校验每个指标字段来源和权限。
  4. 先做供应商/工厂维度看板。
  5. 运行一个周期后再讨论综合评分和权重。

验收标准

  • 每个指标有口径、数据来源和责任人。
  • 看板能下钻到对应订单、验货、审核或 CAP 记录。
  • 风险状态变化有记录。
  • 高风险事项能形成改善动作。

能力边界

Linkincrease 可以做跨流程数据汇总和运营看板；复杂供应商评分模型、财务风险、产能负荷和外部数据需要先确认数据来源和产品边界。
