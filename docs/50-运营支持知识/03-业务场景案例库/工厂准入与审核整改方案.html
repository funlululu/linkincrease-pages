工厂准入与审核整改方案

客户现状

适用于品牌方、贸易公司或采购团队需要管理工厂申报、资质审核、社会责任审核、整改闭环和准入状态的场景。典型问题是工厂资料散落、审核报告难追踪、CAP 逾期没人管、准入状态和订单使用脱节。

业务目标

  1. 建立供应商、工厂、资质和审核报告的主数据。
  2. 把工厂申报、审核、CAP 和复审拆成可追踪流程。
  3. 让工厂风险状态可用于订单选择和管理看板。
  4. 明确平台能力边界，避免把专业合规判断包装成系统自动结论。

推荐配置

业务内容 Linkincrease 配置
供应商/工厂档案 供应商库、工厂库、证书/报告库
工厂申报 工厂准入 FlowSpace
社会责任审核 审核 FlowSpace 或审核里程碑
CAP 整改 CAP FlowSpace 或 CAP 工单
风险状态 工厂资源库字段 + 人工复核更新
复审提醒 自动化日期提醒
管理看板 工厂准入、审核、CAP、风险分布

资源库设计

资源库 建议字段
供应商库 供应商编码、名称、等级、联系人、关联工厂、状态
工厂库 工厂编码、名称、地址、所属供应商、准入状态、审核状态、风险等级、可用于订单
证书/报告库 类型、编号、有效期、附件、关联工厂、审核结论
CAP 问题库 问题类型、等级、责任方、截止日、关闭状态

FlowSpace / 模板设计

FlowSpace 目标
工厂申报与准入 供应商提交工厂资料，品牌方审核并确认准入
社会责任审核 品牌方或服务商执行审核、上传报告、形成结论
CAP 整改跟进 问题项拆分、整改证据、复核关闭
订单管理 订单选择已准入或允许使用的工厂

权限边界

角色 权限建议
品牌方管理员 管理全部工厂、审核和 CAP
品牌方审核人 查看分配范围内的审核任务和报告
供应商 提交自己名下工厂资料和整改证据
工厂联系人 只补充本工厂资料，不看品牌方内部评审
审核服务商 只处理分派审核和复核任务

自动化提醒

  • 工厂资料待补充提醒供应商。
  • 证书/报告到期前提醒品牌方和供应商。
  • CAP 到期前提醒责任人，逾期提醒品牌方。
  • 高风险工厂被订单引用时提醒订单负责人。

仪表盘指标

指标 用途
待准入工厂数 管理审核积压
审核到期工厂数 安排复审
CAP 逾期数 升级整改
高风险工厂关联订单数 管控订单风险
证书有效覆盖率 管理资质健康度

上线步骤

  1. 先清理供应商和工厂清单，定义唯一编码。
  2. 建供应商库、工厂库、证书/报告字段。
  3. 配置工厂准入流程和审核/CAP 流程。
  4. 先用 3-5 个工厂试跑申报、审核、整改。
  5. 确认工厂状态如何影响订单使用。
  6. 上线复审提醒和风险看板。

验收标准

  • 工厂申报、审核、CAP 和状态变化可追溯。
  • 供应商和工厂权限隔离。
  • CAP 关闭有证据和复核记录。
  • 风险状态和可用于订单字段有明确维护责任。

能力边界

Linkincrease 可以承载准入、审核、整改、证据、状态和提醒；审核结论、合规等级和是否允许合作由客户或专业审核方负责。
