运营端概览与各模块地图

本页帮助运营新人快速理解 Linkincrease 运营端负责什么，以及运营端如何支撑贸易端、采集端和客户业务落地。

运营端定位

运营端是平台配置、客户初始化、模板治理、资源库治理、后台监管和产品运营支撑入口。它不直接承载客户每天的订单协作，而是为客户团队提供可复用的模板、资源库结构、权限策略和管理工具。

模块地图

模块 运营价值 关联知识
用户与团队管理 管理平台用户、团队、成员状态和基础权限 运营端、团队权限
FlowSpace 管理 查看客户团队创建和使用的 FlowSpace，辅助定位配置和数据问题 FlowSpace
模板中心 维护业务模板和资源库模板，决定客户可创建的业务空间和数据结构 业务模板、资源库模板
表单设计器 配置字段、组件、显隐、公式、子表和关联引用 表单设计组件
资源库管理 管理供应商、工厂、物料、证书等可复用主数据结构 资源库
仪表盘与报表 支撑客户管理层查看订单、工单、验厂、CAP 等数据 数据分析支持
自动化与集成 支撑通知、提醒、数据写入、外部系统对接 自动化配置、集成方案
日志与审计 辅助运营排查配置、权限、数据变更和系统执行问题 权限、安全与审计

新人理解路径

  1. 先读 产品能力地图，理解产品全貌。
  2. 再读 FlowSpace 数据层级，理解模板、订单、工单、批复、资源库之间的关系。
  3. 然后读 品牌方供应商与工厂准入协同方案，理解外贸供应链核心场景。
  4. 最后进入日常任务区，学习模板、资源库、自动化、问题排查和 SOP。
