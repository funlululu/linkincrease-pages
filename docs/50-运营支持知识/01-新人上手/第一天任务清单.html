第一天任务清单

本页用于运营新人第一天快速建立产品和知识库操作感。

必读

顺序 内容 目标
1 产品能力地图 知道 Linkincrease 的能力分层
2 运营端概览与各模块地图 知道运营端能配置和监管什么
3 FlowSpace 数据层级 知道数据落在哪一层
4 品牌方供应商与工厂准入协同方案 理解典型行业方案
5 问题排查总览 知道出问题先查哪里

第一天练习

  1. 用自己的话解释 FlowSpace、订单、里程碑、工单、工单批复、里程碑批复、资源库。
  2. 画出“工厂申报准入 → 工厂资源库 → 订单工厂报备 → 验厂 → CAP 回写”的数据流。
  3. 找出供应商、工厂、品牌方、DAREN 服务商四类角色分别能做什么。
  4. 选一个业务模板案例，说明它的主表单、里程碑、工单和批复应该如何配置。
  5. 阅读一个问题排查页，练习按“权限、状态、数据来源、日志”定位问题。

交付物

新人第一天结束时，应能输出：

  • 一张产品能力结构图。
  • 一张典型外贸供应链场景数据流图。
  • 一份自己理解的常见术语说明。
  • 至少 3 个可能的客户问题和排查路径。
