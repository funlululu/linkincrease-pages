表单设计组件

1. 功能定位

表单设计组件是 Linkincrease 低代码配置能力的基础。运营端通过布局组件、基础组件、高级组件和行业组件配置业务模板、资源库模板、工单、批复、里程碑批复等表单结构，贸易端和采集端按配置展示、校验和保存数据。

2. 组件分类

分类 组件
布局组件 模块分组、分割线、子表
基础组件 单行文本、多行文本、数字、百分比、单选、多选、图片、附件、日期、评级、定位、地址、富文本、空白占位
高级组件 关联引用、公式、成员单选、成员多选、协作方单选、协作方多选、签名、汇率
行业组件 尺寸检验、组合明细、检测内容选择、检测项目配置套件、检测套餐配置套件等

资源库模板组件与业务模板组件整体相似，但资源库模板中的成员/协作方组件面向团队内成员和团队协作方；业务模板中的成员/协作方组件面向 FlowSpace 内参与成员和协作方。

行业组件不是单纯字段控件，通常包含内置数据结构、生成逻辑、统计口径和端到端流程。尺寸检验组件沉淀抽样、规格、测量记录和补充测量；实验室检验组件沉淀检测内容选择、检测项目配置套件、检测套餐配置套件、样品范围、检测执行和批复链路。

3. 通用属性

属性 规则
标题 多数组件必填，限制 100 字符
提示描述 非必填，通常限制 100 字符
输入框提示 文本、数字、日期等输入型组件可配置
必填项 默认不勾选；提交时按组件规则校验
国际化 可配置标题、提示描述、输入框提示、单位、按钮名称等
布局 影响贸易端展示宽度和排列

4. 布局组件

组件 关键规则
模块分组 基础组件和高级组件可拖入分组；修改分组布局时，需要提示是否同步修改分组内组件宽度
分割线 用于表单视觉分隔，支持标题、提示描述和国际化
子表 可拖入基础组件和高级组件，但排除关联引用；子表必填时，贸易端至少需要一行数据

子表内字段必填时，对应表单提交也需要校验。子表支持单元格编辑、新增行、复制组件、关联字段管理等能力。

5. 基础组件要点

组件 关键规则
单行文本/多行文本 可配置默认值，支持关联已有数据或通过公式计算
数字 支持单位、小数位数、千分符等展示规则
百分比 支持单位和小数位数，数字与百分比互相关联时需换算
单选/多选 选项需要支持贸易端显示和导入校验
图片 可限制最大上传数量和单图最大大小
附件 可限制最大数量、单文件大小和文件类型
日期 支持多种手动输入和粘贴格式，按控件展示格式截取或补全
定位 调取设备定位并记录位置
地址 运营端精度变更后，贸易端已有数据按格式截取或补空
富文本 支持富文本内容录入，导入时通常只处理文字部分

6. 高级组件要点

组件 关键规则
关联引用 可引用组件和子表；可设置引用按钮名称、关联字段、布局和国际化
公式 设置函数与变量，自动计算并展示值
成员单选/多选 业务模板中选择 FlowSpace 内成员；资源库模板中选择团队内成员
协作方单选/多选 业务模板中选择 FlowSpace 内协作方；资源库模板中选择团队协作方
签名 支持 Web 和移动端绘制，账号维度可保存一个签名供下次使用
汇率 支持固定汇率或实时汇率，用户填写金额和币种，基准汇率不可改

7. 资源库双向关联

资源库模板的关联引用组件支持双向关联：

  • 表单 A 的关联引用设置双向关联后，表单 B 末尾新增双向关联组件。
  • 双向关联开启后，允许关联多条自动开启且不可关闭。
  • 表单 B 的双向关联组件可修改位置、标题、提示、自定义按钮、显示字段、布局和国际化。
  • 删除表单 B 的双向关联组件，会关闭表单 A 对应关联引用的双向关联。
  • 双向关联数据也支持贸易端资源库被订单详情使用。

8. 默认值与数据源

文本、数字、百分比、日期等组件可通过“关联已有数据”或“公式计算”设置默认值。不同表单可选数据源不同：

  • 主表单变量来自主表单。
  • 里程碑批复变量来自所有里程碑批复表单和主表单。
  • 工单表单变量来自同一里程碑所有表单、主表单、所有里程碑批复表单。
  • 工单批复表单变量来自同一里程碑所有表单、主表单、所有里程碑批复表单。
  • 子表内组件可额外关联当前子表其他字段。

9. 贸易端应用原则

  • 按运营端配置展示、校验和保存。
  • 组件默认值应用于创建或导入订单、工单、批复等场景。
  • 运营端组件显示格式变更后，贸易端已有数据按新格式截取或补全展示。
  • 导入、导出、资源库引用、第三方 API 写入都必须遵循组件类型和校验规则。

10. 待确认问题

  • 业务模板与资源库模板组件差异需要继续沉淀成字段级清单。
  • 各组件在导入、导出、报告、仪表盘中的展示和可用性需要补完整矩阵。
  • 行业组件已包含尺寸检验和实验室检验，后续每新增一个复杂行业组件都应单独拆页，并补齐内置数据结构、端到端流程、权限、统计和验收清单。
