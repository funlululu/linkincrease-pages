系统与集成执行日志

定位

系统与集成执行日志用于追溯非普通用户手动操作产生的数据变化，包括公式自动更新、自动化执行、资源库数据同步、SCMPro API 数据变更、外部 API 集成同步和运营端自动化记录。

这类记录需要同时进入业务审计链路，避免系统写入的数据无法解释来源。

系统执行来源

来源 说明
公式自动更新 公式字段根据依赖字段自动重新计算
TODAY 公式自动更新 包含 TODAY 的公式随日期变化自动重新计算
自动化更新 FlowSpace 自动化程序根据触发条件执行动作
FlowSpace 互通 目标侧引用来源 FlowSpace 数据、后续自动更新、手动刷新、跳过或失败
关联资源库同步 资源库数据或引用字段配置变化后，同步更新订单数据
SCMPro API 数据变更 第三方系统数据变化后自动更新 Linkincrease
外部 API 集成 运营端配置外部 API 后，外部数据创建或更新订单、工单等

公式自动更新

公式自动更新仅增加订单跟踪记录、动态和历史记录，不更新数据创建人或更新人。

模块 记录规则
订单跟踪记录 主表单公式字段更新时增加记录
动态 里程碑批复、工单批复、工单采集中的公式字段更新时增加动态，归类为修改记录
历史记录 里程碑批复、工单批复、工单采集中的公式字段更新时增加历史记录

操作人显示为系统，操作时间为自动更新时间，历史快照展示公式字段更新前后的值。

公式自动更新需要遵守业务对象状态限制。订单已完成、已取消或已删除时，不再自动更新订单主表单公式；里程碑已完成或已取消时，不再自动更新里程碑批复公式；工单已批复、已终止采集或已删除时，不再自动更新工单采集公式。

自动化更新

自动化更新同普通用户操作逻辑，增加订单跟踪记录、动态、历史记录，并更新数据更新时间和更新人。

模块 记录规则
订单跟踪记录 主表单内容更新、里程碑首次创建工单、订单状态变更、里程碑状态变更时记录
动态 创建里程碑批复、更新里程碑批复、创建工单、更新工单、更新工单批复时记录
历史记录 主表单更新、创建工单、更新工单、更新工单批复、创建或更新里程碑批复时记录
数据更新时间/更新人 更新时间为自动化执行时间，更新人为自动化

操作人显示为自动化，头像为系统。

自动化执行日志

贸易端自动化配置中可查看自动化执行日志。运营端也提供 FlowSpace 自动化记录列表，用于平台级追踪。

贸易端执行日志

每条自动化执行日志可以查看执行记录。详情中每个节点都可以查看配置流程和具体执行数据。

执行记录按自动化配置的数据源展示：

数据源 执行记录展示
订单基本信息 被执行 $订单ID
里程碑批复 被执行 $订单ID_$里程碑名称 里程碑批复
工单 被执行 $订单ID_$里程碑名称_$工单名称

运营端自动化记录

运营端自动化记录列表支持按 FlowSpace、团队、自动化、触发类型、执行状态、触发时间、执行时间筛选。

字段 说明
FlowSpace名称、CODE 对应 FlowSpace 基础信息
所属团队、团队码 对应团队基础信息
订单ID、订单码 自动化涉及的订单信息
自动化名称、自动化ID 自动化基础信息
触发类型 新增数据、数据变更、到达时间、定时任务
触发数据 订单信息、工单信息、里程碑批复
执行动作 自动化执行的动作
执行状态 成功、失败、已失效、待执行
执行结果摘要 成功或失败摘要
执行时间 自动化实际执行时间

列表按创建时间倒序。详情展示规则同贸易端。

关联资源库同步

因关联的是资源库数据 ID，订单侧不增加记录。资源库自身数据历史记录仍需保留资源库数据被编辑、导入、分享编辑等操作来源。

FlowSpace 互通日志

FlowSpace 数据互通需要同时记录方案配置日志、互通执行日志和业务模块日志。方案配置日志只记录互通方案的创建、编辑、保存草稿、发布、启用、停用、删除草稿和配置快照；具体订单、工单或批复被引用时，不写入方案配置日志，而是写入互通执行日志。

互通执行日志需记录执行时间、执行类型、互通方案、使用版本、来源数据、目标数据、处理方式、执行状态和详情。引用或后续更新导致业务数据变化时，还需写入对应订单跟踪记录、工单动态、批复动态和历史记录，并标记操作来源为 FlowSpace 互通。

互通日志详见 FlowSpace 数据互通。

外部API集成日志

外部 API 集成日志展示一定时间范围内的同步日志。

字段 说明
时间 触发同步的时间
事件类型 创建、更新
同步方向 正向、反向
数据标识 外部或 Linkincrease 数据标识
状态 成功、失败
详情 记录成功或失败说明

外部系统同步到贸易端业务数据后，还需要写入订单跟踪记录、工单动态和历史记录。

典型记录：

模块 文案口径
订单跟踪记录-创建订单 $操作人 在 $来源标识 操作了数据，同步创建了订单
订单跟踪记录-更新订单 $操作人 在 $来源标识 操作了数据，同步更新了订单
订单跟踪记录-里程碑开始 $操作人 在 $来源标识 操作了数据，同步在 $里程碑名称 创建了工单，里程碑开始
工单动态-创建工单 $操作人 在 $来源标识 操作了数据，同步创建了工单
工单动态-更新工单采集 $操作人 在 $来源标识 操作了数据，同步更新了工单
工单动态-更新工单批复 $操作人 在 $来源标识 操作了数据，同步更新了工单批复，工单无法继续编辑
动态-更新里程碑批复 $操作人 在 $来源标识 操作了数据，同步更新了里程碑批复

软件更新记录

运营端软件管理包含软件更新管理和软件更新记录。当前用于采集端 APP、Android 平台。

能力 规则
软件更新管理 相同产品类型、软件类型只展示最近更新的一条记录
软件更新记录 记录每一次更新
查看详情 可查看更新详情并下载安装包
更新日志 文字，可换行，暂不需要富文本

记录字段包括产品、平台、发布时间、支持最小版本、当前版本、更新人、更新时间。
