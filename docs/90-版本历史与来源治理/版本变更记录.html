发布检查清单

每次知识库版本更新前，至少检查：

  1. 新增知识页是否加入对应目录 README。
  2. 根 README 阅读路径是否需要更新。
  3. metadata/documents.csv 是否有对应记录。
  4. metadata/sources.csv 是否补充来源。
  5. metadata/search-index.json 是否能解析。
  6. ID 是否唯一。
  7. 待确认问题是否有新增或状态变化。
