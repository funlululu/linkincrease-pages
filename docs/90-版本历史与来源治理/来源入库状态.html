维护动作

新增或更新需求文档时，按以下顺序处理：

  1. 将所思在线内容同步到 最新需求源（source:thoughts-v2-current）。
  2. 运行 python scripts\scan_source_manifest.py，更新 metadata/source-manifest.csv 和 metadata/source-diff.csv。
  3. 更新 需求文档来源台账。
  4. 更新 metadata/sources.csv。
  5. 抽取或更新对应 docs/ 知识页。
  6. 更新 metadata/documents.csv 和 metadata/search-index.json。
  7. 如果存在冲突或缺口，更新 待确认问题。
