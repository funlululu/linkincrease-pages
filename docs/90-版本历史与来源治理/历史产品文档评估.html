历史产品文档评估

1. 页面定位

本页用于评估 source:product-docs-legacy 来源层中的历史产品文档，明确哪些内容已经整理为正式知识页，哪些只能作为背景参考，哪些不应直接进入当前知识库口径。

这批文档整体成文时间早于当前最新需求源，内容偏战略、画像、路线图和三端 PRD 草案。它们有助于补齐产品背景，但不能直接覆盖 source:thoughts-v2-current 和现有 docs/ 标准知识页。

2. 总体结论

结论 说明
可以补齐战略层信息 愿景、定位、问题、用户、指标、路线图可整理为入门层知识页
不适合逐篇原样入库 多数文档重复度高，且混合了假设、目标值、商业模式和功能草案
不能直接覆盖功能规则 三端 PRD 中的功能描述需要与最新需求源逐项核对
旧称需要统一 原文中的 SCCS 在正式知识页中统一为 FlowSpace，来源引用保留原文件名
数据和目标值需确认 例如效率提升、活跃率、增长目标、时间规划等，缺少当前证据时只作假设

5. 后续处理建议

  1. 三端 PRD 草案不建议全文搬入正式知识库，应逐项与 source:thoughts-v2-current 比对。
  2. 如果发现历史 PRD 中有最新需求源缺失但仍有效的能力，应补回最新需求源或登记到待确认问题。
  3. 市场、商业模式、定价、增长目标如需保留，建议建立独立“商业策略/增长策略”页面，并标注确认状态。
  4. 若后续继续维护这批产品文档，应先在原目录中去重、统一术语，再从中抽取到标准知识页。
