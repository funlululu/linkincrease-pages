贸易端

1. 定位

贸易端是 Linkincrease 的客户业务协同主平台，面向客户团队、团队成员、协作团队和业务管理人员。

它承载团队、FlowSpace、订单、里程碑、工单、资源库、自动化、消息、仪表盘、报告和日志审计等核心业务。大部分日常业务创建、协作、查看、审批和数据复用都在贸易端完成。

2. 核心职责

职责 说明
账号与个人设置 注册登录、忘记密码、个人信息、头像、语言、退出账号
团队管理 创建团队、维护团队信息、角色、成员、协作团队
FlowSpace 工作空间 创建 FlowSpace、维护设置、成员、业务角色、数据围栏、协作 FlowSpace
订单执行 创建、编辑、导入、导出、查看、完成、取消、重启订单
工单与批复 发起工单、采集、批复、指派、终止、评论和动态协作
资源库 维护团队资源库、引用资源库数据、同步到 FlowSpace、分享资源库
自动化 配置触发条件、执行动作、定时任务、执行日志
协作通知 消息中心、实时通知、邮件协作、批量邮件协作
展示分析 工作台、订单日程、任务中心、常用视图、仪表盘、报告
日志审计 操作日志、订单跟踪记录、动态、历史记录、快照

3. 主要模块

3.1 账号与个人中心

贸易端账号能力包括注册登录、忘记密码、个人信息维护、头像、姓名、性别、邮箱、手机号、重置密码、语言切换和退出账号。

个人中心还需要展示当前用户加入的团队列表，并支持切换团队。若用户是团队拥有者，应展示拥有者标识。团队代码应支持复制。

语言切换通常包含跟随系统、简体中文、英文等选项，切换后需要保存到账户并更新当前浏览器语言。

3.2 团队与协作团队

团队是贸易端业务归属的组织单位。用户先进入团队，再进入团队下的 FlowSpace、订单、资源库和仪表盘。

团队管理需要覆盖：

  • 创建团队。
  • 修改团队信息。
  • 维护团队角色。
  • 邀请成员。
  • 管理协作团队。
  • 记录成员邀请和协作邀请流程。

团队权限口径详见 团队权限。

3.3 工作台与 FlowSpace

工作台是贸易端进入业务的日常入口。它提供团队下 FlowSpace 列表、FlowSpace 分组、创建 FlowSpace、星标、排序和常用入口。

FlowSpace 是承载订单、里程碑、工单、资源库引用、自动化、仪表盘和报告的业务空间。FlowSpace 设置需要维护基本信息、成员、业务角色、协作团队、标签、数据围栏等。

FlowSpace 对象口径详见 FlowSpace。

3.4 订单、里程碑、工单与批复

订单是 FlowSpace 下的主业务实体。里程碑是订单流程节点，工单是里程碑下的执行任务，批复是对工单或里程碑结果的确认动作。

贸易端负责订单的完整生命周期：

  • 创建订单。
  • 编辑订单。
  • 导入和导出订单。
  • 查看订单列表和详情。
  • 管理里程碑计划。
  • 发起和处理工单。
  • 执行工单批复和里程碑批复。
  • 完成、取消、重启订单。

相关口径详见 订单、里程碑、工单与批复。

3.5 资源库

资源库是团队级主数据管理能力。贸易端用于维护资源库表数据、将资源库应用到 FlowSpace、在订单或工单中引用资源库数据、查看编辑历史、管理资源库视图和分享资源库。

相关口径详见 资源库 和 资源库引用与同步。

3.6 自动化、消息与邮件协作

贸易端支持自动化配置，包括触发条件、执行动作、通知动作和定时任务。自动化执行结果应进入执行日志。

协作通知能力包括：

  • 站内消息中心。
  • 在线实时消息。
  • 邮件协作。
  • 批量邮件协作。
  • 任务相关提醒。

相关口径详见 自动化配置、消息中心与实时通知、邮件协作。

4. 与其他产品端关系

关系 说明
来自运营端 业务模板、资源库模板、表单组件、仪表盘组件、报告入口、外部 API 配置等由运营端维护或监管
同步到采集端 工单、工单批复、里程碑批复、任务状态、消息通知会同步到采集端
回流自采集端 采集端提交的工单数据、批复数据、指派结果、评论或动态回流贸易端

5. 知识库拆分建议

贸易端后续可继续拆成以下细页：

  • 账号注册登录与个人中心。
  • 团队创建与团队设置。
  • 工作台和 FlowSpace 分组。
  • FlowSpace 设置。
  • 协作 FlowSpace 设置。
  • 订单列表、订单详情、订单管理。
  • 工单视图和批量操作。
  • 资源库视图、分享和应用范围。
  • 自动化一期、定时任务。
  • 消息中心、邮件协作。
