PDF与批量导入导出

1. 功能定位

批量导入导出用于将订单、工单、资源库数据与本地 Excel、CSV、PDF 文件流转。导入导出必须同时遵守模板字段配置、组件校验、权限、数据围栏、对象状态、历史记录和进程中心规则。

2. 业务模板中的 PDF 导入设置

业务模板可配置 PDF 导入：

  • PDF 导入开关默认关闭。
  • 当前暂支持指定 PDF 模板。
  • 可配置 PDF 附件是否导入到主表单附件字段。
  • 贸易端支持上传多份 PDF 文件导入。
  • 模板发布和同步至 FlowSpace 时，PDF 导入设置也属于同步内容。

3. 订单 Excel 导入

步骤 规则
上传文件 支持 .xls、.xlsx、.csv；拖拽不支持格式时提示
导入设置 选择工作表、匹配系统字段、设置过滤重复字段、字段格式、日期格式
导入数据 分为新增和覆盖；覆盖可选覆盖整行或覆盖有值
执行导入 在进程中心显示导入任务，完成后提示成功或失败
导入记录 仅能查看本人导入记录，下载文件增加导入执行结果

订单导入支持 999 行订单数。订单 ID、成员邮箱、地址不区分大小写，其余控件区分大小写。

4. 订单 PDF 导入

PDF 导入与 Excel 导入主要差异：

  • 仅支持 .pdf 文件，可上传多份。
  • 无需选择工作表。
  • 导入文件字段展示运营端配置需导入的字段。
  • 无需手动匹配系统字段。
  • 过滤重复数据设置与 Excel 分别记忆。
  • 识别多份 PDF 的订单数据后，归类为新增或覆盖，后续操作同 Excel 导入。

5. 工单导入

规则 说明
权限入口 有任意里程碑导入权限的用户可见工单导入按钮
里程碑选择 只能选择当前用户有工单导入权限的里程碑
模板字段 订单识别字段 + 工单采集字段
匹配订单 仅在当前用户有导入工单权限的订单范围内匹配
新增 匹配到订单的数据可作为新工单导入
覆盖 对有采集权限的已有工单可覆盖采集部分内容
未匹配 未匹配到订单的数据仅可查看，不可导入

新增工单成功后，工单采集人为导入成员；批复人默认跟随运营端配置，未配置时取导入成员。若此前未创建里程碑批复，则同步创建。

6. 资源库导入导出

资源库导入支持工作表选择、字段匹配、重复数据识别、新增、覆盖整行、覆盖有值、导入记录和进程中心。导入成功后，资源库数据历史记录增加导入人操作的新增或修改记录。

资源库导出可选择导出当前资源库或当前表数据。导出当前整个资源库时，仅导出当前用户有查看权限的表。

7. 导入失败与校验

常见失败原因：

  • 当前用户无导入权限。
  • 未设置任何新增或覆盖数据。
  • 同一条数据同时设为新增和覆盖。
  • 覆盖未选择目标数据。
  • 多行覆盖至同一条系统数据。
  • 对象已完成、已取消或已删除。
  • 必填项为空。
  • 控件内容不符合输入规则。
  • 单选/多选内容与选项值不一致。
  • 日期格式与运营端配置不符。

如果必填项正好是当前用户被数据围栏限制不可见字段，则导入时不校验该字段。

8. 导出规则

订单导出范围为当前用户权限内可见的订单、里程碑批复、里程碑工单数据。

导出内容：

  • 订单信息，包括订单字段和各里程碑批复字段，需排除数据围栏不可见字段。
  • 里程碑工单，按里程碑分 sheet。
  • 字段修改次数统计。

导出内容无字段或无数据时，不执行导出并提示没有可导出的数据。

9. 待确认问题

  • PDF 字段整理目前仍引用外部资料，建议导出成本地来源。
  • 订单、工单、资源库导入的字段类型支持范围需要沉淀为统一矩阵。
  • 数据围栏对导入、导出、记录下载的影响需要继续验证。
