工单表单共享与复制

1. 功能定位

工单表单共享与复制用于在同一 FlowSpace 内复用不同工单的采集表单数据，减少重复录入，并让共享关系、覆盖快照、同步状态和异常原因可追溯。历史文档中的“表单互用”可理解为当前“共享表单数据”的前置叫法；后续规则以“共享组”和“一次性复制”为准。

模式 结果 目标侧编辑 数据变化
共享表单数据 多个工单中的同一采集表单组成共享组 共享组内有采集权限的成员可在自己负责的工单中编辑；受状态锁定时只读 任一成员工单保存后，同步到共享组全部成员工单
复制数据 将来源工单表单当前数据一次性覆盖到目标表单 目标表单可继续按普通表单编辑 后续互不影响

2. 适用范围

范围 规则
FlowSpace 仅限同一 FlowSpace，支持同订单和跨订单
模板匹配 共享或复制的来源、目标必须属于同一里程碑模板，并使用兼容的工单采集表单模板
表单范围 首期按整张工单采集表单共享或覆盖，不支持字段级选择
不支持 不支持选择字段、合并数据、仅填充空字段、工单批复表单、里程碑批复表单
不复用内容 不复制或共享工单名称、处理人、状态、批复、动态、评论、邮件协作等工单级数据
关系限制 每张表单最多加入一个共享组；共享组至少包含 2 个有效成员工单；复制不建立持续关系

3. 运营端配置约束

运营端可在业务模板的里程碑工单采集表单属性中控制“表单是否可共享”。该开关只决定贸易端是否允许创建共享组，不会自动创建共享关系；复制数据不受该开关控制。

共享表单需要满足以下模板约束：

  • 不包含关联引用字段。
  • 公式仅引用当前表单字段。
  • 显隐条件仅引用当前表单字段。
  • 首期不包含签名组件。
  • 模板复制、发布、前端保存和后端保存均需校验上述规则。

若已存在共享组后关闭共享配置，系统应将受影响共享组置为“配置变更处理中”，阻止新增成员、退出和写入，按幂等任务解散共享组，保留最后一次共享快照，将各成员工单转为独立表单，并记录动态、历史和系统执行日志。

4. 权限与状态

创建共享组、添加成员、退出共享组或执行复制时，执行人必须同时满足：

  1. 具备源、目标订单及工单查看权限。
  2. 具备源表单完整数据查看权限。
  3. 具备当前目标表单采集权限。
  4. 目标对象当前状态允许采集或编辑。

以下状态不得新建共享或复制：目标工单已批复、已终止、已删除，或所属订单/里程碑已完成、取消。

来源不要求可编辑；已提交、已批复、已终止，或所属订单/里程碑已完成、取消的历史工单可以作为来源，但删除对象不可作为来源。

5. 创建共享组

创建共享组时，入口只展示在已开启共享且尚未加入共享组的工单采集表单上。可选择同一 FlowSpace 内、当前用户是采集人、状态可编辑、未加入其他共享组且模板兼容的其他工单表单。

创建时需选择初始数据来源，可使用当前工单或被选工单的已保存数据。确认后：

  1. 按稳定字段 ID 使用初始来源的已保存数据覆盖共享组全部成员工单。
  2. 公式结果不直接复制，按每个成员工单上下文重新计算。
  3. 保存覆盖前后快照并建立共享组关系。
  4. 共享组内任一成员工单保存时，同步整组业务数据。
  5. 创建期间如果成员范围、权限或状态变化，需要提示用户刷新后重试。

共享组状态包括“进行中”“已锁定”“已解散”。只要任一成员工单因批复、终止、里程碑完成、订单完成或取消等原因不可采集，整个共享组进入锁定，只读保留当前快照。

6. 共享组管理

共享组成员可在表单上查看共享信息。具备任一有效成员工单采集权限的用户可添加成员；当前表单采集人可退出当前工单所在共享组。

退出共享组时，默认保留当前数据；若当前工单可编辑，也可选择清空数据，清空时必须提示必填字段可能为空。锁定成员只能选择保留数据。退出后若共享组有效成员少于 2 个，系统自动解散共享组；若锁定成员退出后剩余成员均可采集且数量不少于 2 个，可解除锁定。

7. 复制数据

复制数据同样使用源表单当前已保存数据并整表覆盖目标。复制后：

  • 不建立持续关系。
  • 不复制工单级信息、批复、动态、历史或共享关系。
  • 目标按普通表单处理，可在权限和状态允许时继续编辑。
  • 源侧不展示被复制去向，也不增加源工单动态。
  • 目标工单动态/历史保留复制来源和覆盖快照。
  • 同订单的关联引用数据可复制；跨订单涉及关联引用时，需要按字段重新选择或阻止复制，不能把不可解析的订单内引用直接带入目标订单。

8. 取消与修改共享关系

共享关系可通过成员退出、共享组解散、模板关闭共享配置或业务对象终态自动解除。操作者需具备当前成员工单采集权限或共享组管理入口权限。

解除时必须明确处理方式：

选项 结果
保留目标数据 保留最后一次同步后的业务有效值，并转为目标本地数据
清空目标数据 清空该表单；需强提示可能造成必填字段为空

解除后其他成员变化不再同步当前表单，不允许恢复共享建立前的数据。相关成员工单均需记录动态；历史记录保存取消方式、取消前后快照和共享组信息；关系审计永久保留。

修改共享组初始来源按“解散或退出原关系 + 创建新关系”处理，需保存切换前后快照以及原、新关系信息。

9. 同步、只读与业务有效值

共享组成员表单在贸易端或采集端产生已保存数据变化时，同步至共享组全部有效成员。同步范围包括普通字段、子表行、图片、附件，以及同一表单 ID 下模板新增字段。

同步要求：

  1. 使用本次保存的数据版本同步，记录各成员最近同步版本、时间、状态及失败原因。
  2. 同一“共享组 ID + 来源版本 + 成员工单 ID”只执行一次。
  3. 共享保存与整组同步需要原子化处理；失败时回滚本次保存，避免组内数据不一致。
  4. 共享表单禁止导入、批量编辑、外部 API、移动端离线导入和自动化直接写入，只允许共享同步及目标公式计算写入。
  5. 同步期间展示“同步中”；失败时保留最后成功版本并展示失败状态。

业务有效值的处理顺序为：同步来源普通字段值 -> 按成员工单重新计算公式 -> 判断成员工单显隐 -> 计算业务有效值和必填完整度 -> 记录动态/历史/执行日志 -> 触发目标自动化。

共享同步不改变工单完成度口径。某个成员工单的共享表单被同步保存后，按该工单自身的采集提交规则判断是否已提交。

10. 特殊组件与显隐

组件 同订单 跨订单
普通字段、子表、图片、附件 支持 支持
签名 首期共享不支持；复制按组件规则处理 首期共享不支持；复制按组件规则处理
订单内关联引用 共享不支持；复制支持 共享不支持；复制需重新选择或阻止
公式 使用目标工单实际因子计算 使用目标订单、目标工单实际因子计算
资源库关联 支持 支持，保留资源数据 ID

字段显隐按各目标工单的数据上下文单独判断：

源字段 目标字段 目标业务有效值
显示且有值 显示 同步源值，只读
显示且有值 隐藏 空，不展示、不校验
隐藏 显示 空且只读，不恢复源历史值
隐藏 隐藏 空，不展示、不校验

11. 批复、自动化与数据出口

  • 目标工单包含共享表单时，批复确认区域需展示风险提示，说明共享组内其他成员保存或目标公式因子变化仍可能改变字段值、公式结果和字段显隐。
  • 批复人必须确认已知晓风险后才能批复。
  • 任一成员工单进入不可采集状态时，共享组锁定，不再允许成员写入，但可展示最后一次共享快照。
  • 共享同步及目标公式/显隐变化合并为一次目标订单数据变更，按最终业务有效值触发自动化。
  • 自动化不得写入共享表单。
  • 仪表盘、报告、查询和导出仍按成员订单、成员工单分别统计，不按共享组去重。
  • 共享表单可导出当前最新值；导入、批量编辑、API 不得覆盖有效共享表单。

12. 日志、动态与审计

需要记录的事件包括：创建共享组、添加成员、成员退出、数据同步、共享组锁定、共享组解锁、共享组解散、模板关闭共享配置导致解散、工单删除导致解除关系和复制覆盖。

成员工单动态应说明共享组、执行人、来源成员工单、影响成员工单、保留或清空方式。历史记录需保存覆盖前后快照、字段差异、来源/目标版本和共享组信息；系统执行日志记录后台解散、重试、同步失败和配置变更处理。

13. 异常与测试重点

重点异常包括：无权限、不可见、当前工单自身、来源已在其他共享组、目标已有共享组、来源无保存版本、模板不匹配、条件并发变化、直接写入共享表单、同步失败、锁定组新增成员、退出并清空。

测试重点覆盖同订单/跨订单、权限建立后丢失、无保存版本、未保存修改、已提交、已批复、已终止、空值、必填、子表、附件、签名限制、订单内关联引用限制、资源库、公式、显隐组合、共享组新增成员、退出、锁定、解锁、解散、部分失败、重试、并发、循环自动化、取消保留/清空、删除成员工单，以及导入、批量编辑、API、自动化直接写入。

14. 待确认问题

  • 跨订单复制存在订单内关联引用时，是阻止整表复制还是跳过关联引用并复制其余字段，需要产品和研发确认。
  • “有效来源数据”是否可完全按存在服务端已保存版本判断，需要研发确认现有表单版本能力。
