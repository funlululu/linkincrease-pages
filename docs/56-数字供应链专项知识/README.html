56 数字供应链专项知识

本目录沉淀供应链数字化、数字供应链协同平台、主数据治理、系统版图、可视化预警和 Linkincrease 产品定位相关知识。它连接 55 外贸供应链行业知识 和 Linkincrease 的产品/运营方案，帮助产品经理和产品成功判断客户问题属于流程协同、数据治理、系统集成、管理可视化还是专业业务系统边界。

使用原则

  1. 先判断客户数字化阶段，再推荐能力组合。
  2. 先治理主数据和流程数据，再谈自动化、看板和智能分析。
  3. 明确 Linkincrease 与 ERP、MES、WMS、TMS、QMS 等系统边界。
  4. 不把系统集成、算法预测或专业业务系统能力默认承诺给客户。
  5. 数字化方案必须落到角色、对象、流程、权限、数据、预警和指标。
