登记规则

  1. 法规、标准必须登记发布组织、版本、生效日期和适用区域。
  2. 书籍必须登记作者、书名、版本和对应章节，不大量复制原文。
  3. 客户实践必须匿名化，并说明客户类型、适用范围和是否为个案。
  4. 竞品材料必须记录观察日期，区分公开能力与推测。
  5. 专家访谈应记录确认角色和时间，不在公开输出中暴露个人敏感信息。
  6. 失效、冲突或无法验证的来源保留记录，但标记状态。
