06 行业到产品研发映射

本分区面向产品、测试和研发，集中维护行业场景与 Linkincrease 业务对象、产品能力、数据规则、测试重点和产品差距之间的关系。

这里的映射用于帮助产品研发理解“行业为什么需要这项能力”以及“产品模型是否足以承载真实业务”。客户配置和业务方案应继续进入运营支持知识，不能用推荐方案覆盖已确认产品规则。
