03 业务流程与单据

本分区按端到端业务场景沉淀参与角色、业务对象、流程阶段、单据、状态、异常和控制点。

场景

P0 核心协同场景

  • 供应商开发、准入与生命周期管理
  • 采购订单履约与交期跟踪
  • 生产进度与异常协同
  • QC 验货与质量异常
  • 社会责任审核与 CAP 整改
  • 出货计划与单证协同
  • 供应商绩效与风险管理
  • 订单变更、异常、索赔与结案

P1 扩展场景

  • 询价、报价、比价与定点（待评估）
  • 样品开发与确认（待评估）
  • 需求预测与采购计划（待评估）
  • 物料准备与齐套管理（待评估）
  • 国际物流与到货跟踪（待评估）
  • 报关、清关与贸易合规（待评估）
  • 对账、付款与结算（待评估）
  • 退货、返工与召回（待评估）

场景优先级依据 Linkincrease 当前产品定位、已有能力和客户推广价值确定，不代表 P1 场景在供应链业务中不重要。
