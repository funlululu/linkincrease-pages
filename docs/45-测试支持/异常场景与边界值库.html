异常场景与边界值库

本页用于长期沉淀测试中高价值的异常场景、边界值和容易遗漏的业务组合。

资源库与引用异常

场景 测试关注
订单引用的工厂被停用 订单历史展示、再次编辑、统计口径是否明确
工厂准入状态从已准入改为暂停 新订单是否禁止选择，旧订单是否保留历史
供应商与工厂解除关联 供应商订单是否还能选择该工厂
资源库记录重复 搜索、选择、同步、报表是否可识别重复风险
资源库字段类型变更 已有订单引用字段是否兼容

流程与状态异常

场景 测试关注
工厂申报被退回后再次提交 历史记录、附件、审批意见是否保留
工单批复前订单被取消 工单和批复状态是否同步受控
CAP 复核退回后再次提交 证据版本、复核记录、通知是否正确
里程碑批复已存在时再次创建工单 里程碑批复唯一性是否保持
自动化重复触发 是否产生重复通知、重复写入或重复日志

权限边界异常

场景 测试关注
供应商被移出协作团队 历史订单、待处理工单、通知链接是否受控
用户角色被降级 已打开页面、导出、接口数据是否同步受限
邮件协作链接过期或转发 外部填写权限是否可控
数据围栏调整后 列表、详情、搜索、仪表盘、导出是否一致

边界值

类型 边界
文本 空值、超长、特殊符号、重复名称、中英文混合
数字 0、负数、小数、超大值、百分比边界
日期 过去日期、当天、跨年、有效期过期、开始晚于结束
附件 空附件、超大附件、多附件、重复文件名、不支持格式
子表 0 行、1 行、多行、删除全部、批量导入重复行
