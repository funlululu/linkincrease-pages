45 测试支持

本目录面向测试人员和质量保障工作，负责把功能文档、业务对象、业务流程、权限规则、数据模型和版本历史转化为可执行的测试资产。

测试支持区不是重复产品规则，而是将权威知识转成验收清单、测试矩阵、边界场景、回归重点和 FAQ，帮助测试人员更快理解业务、更准确设计用例、更系统定位缺陷。

页面

  • 测试支持价值
  • 模块验收标准清单
  • 核心业务流程图索引
  • 数据流转与校验规则
  • 权限测试矩阵
  • 异常场景与边界值库
  • 历史 Bug 高发区标记
  • 版本回归测试重点
  • 测试常见问题 FAQ

使用原则

  1. 功能验收标准从 功能模块详情 提炼。
  2. 流程测试路径引用 业务流程与产品流程图。
  3. 数据校验规则引用 业务对象与数据模型。
  4. 权限测试矩阵引用 权限、安全与审计 并转化为具体用例。
  5. 回归测试重点引用 版本历史与来源治理。
