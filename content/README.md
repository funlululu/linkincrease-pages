## 使用原则

1. 功能模块页是阅读入口，业务对象、流程、权限、数据和审计页面是权威规则层。
2. 来源文档不等于知识库结论。知识库正文只收纳经过归纳、去重、校验并可追溯来源的信息。
3. 涉及数据新增、字段写入、资源库引用、自动化、导入导出、报表统计或权限控制时，先判断目标数据层级。
4. 运营经验、客户反馈、竞品分析和需求候选应进入运营支持或产品维护区；确认后再同步到权威规则页。
5. Mermaid 图表代码保留在 Markdown 中，站点提供预览能力，方便复制和维护。

## 本地生成站点

```powershell
python scripts\build_static_site.py
```

生成结果位于 `exports/site`。推送到主分支后，GitHub Actions 会根据部署配置生成并发布公开只读站点。
