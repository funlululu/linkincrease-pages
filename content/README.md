## 当前资料来源

本次整理主要依据 `最新需求源（source:thoughts-v2-current）` 中的 60 余份迭代需求文档，覆盖：

- 贸易端：账号、个人中心、团队、工作台、FlowSpace、订单列表、订单详情、订单管理、资源库、自动化、消息、日志、仪表盘、报告权限。
- 运营端：用户/团队/FlowSpace/资源库数据管理、模板中心、业务模板、资源库模板、表单设计器、仪表盘、第三方数据对接、外部 API、报告管理、软件管理。
- 采集端：首页、任务列表、任务搜索、任务详情、消息中心、我的、登录。
- 公共能力：公式函数、系统自动执行日志、验货组件流程。

## 使用原则

1. 需求原文不等于知识库结论。原文用于追溯，知识库正文用于沉淀当前共识。
2. 同一能力跨多份需求出现时，以业务对象和流程归并，而不是按迭代时间重复记录。
3. 权限、状态、通知、日志、导入导出、协作边界必须单独沉淀，不隐藏在页面说明里。
4. 不确定内容进入 [99-待办与问题池.md](./99-待办与问题池.md)，确认后再合入正式页面。
