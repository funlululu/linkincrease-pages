# FAQ

本页用于沉淀运营对内和对客户解释 Linkincrease 外贸供应链方案时的常见问答。

## 场景问答

| 问题 | 回答 |
| --- | --- |
| Linkincrease 是不是只做订单管理？ | 不是。订单管理是核心入口之一，但平台还支持供应商协同、工厂资源库、工厂准入、验厂审核、CAP 整改、自动化提醒、仪表盘分析和审计追溯。 |
| 品牌方的一线供应商和实际生产工厂如何管理？ | 建议用供应商资源库管理一级供应商，用工厂资源库管理实际生产工厂，并通过关联字段建立供应商与工厂关系。 |
| 供应商可以自己申报工厂吗？ | 可以。可以在工厂申报 FlowSpace 中开放供应商提交权限，品牌方进行资料审核和准入确认。 |
| 订单里如何选择生产工厂？ | 推荐在订单字段或生产报备工单中引用工厂资源库，并按供应商、准入状态、风险状态过滤可选工厂。 |
| 如果供应商要使用未准入工厂怎么办？ | 不建议直接在订单中手填。应先进入工厂申报与准入流程，品牌方确认后同步到工厂资源库，再回到订单中选择。 |
| 社会责任验厂适合放在哪里？ | 建议作为独立 FlowSpace 承载。它可以引用工厂资源库，执行验厂计划、现场审核、报告提交和品牌方确认。 |
| CAP 整改如何和验厂报告关联？ | 验厂报告产生的问题项可以进入 CAP 跟进 FlowSpace，每个整改项都有责任人、截止日期、证据和复核结论。 |
| DAREN 服务商需要看到品牌方全部数据吗？ | 不需要。建议通过协作团队、任务指派和数据围栏，只开放验厂或 CAP 所需的数据。 |
| 运营如何向客户解释资源库价值？ | 资源库不是普通表格，而是订单、工厂申报、验厂、CAP 和仪表盘都可以复用的主数据底座。 |
| 为什么要拆多个 FlowSpace，而不是一个大流程？ | 工厂准入、订单管理、验厂审核、CAP 整改的生命周期、角色、权限和数据结果不同。拆开后更清晰，也更便于复用和分析。 |
