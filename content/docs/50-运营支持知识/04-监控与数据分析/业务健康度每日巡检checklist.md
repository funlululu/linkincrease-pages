# 业务健康度每日巡检 checklist

本清单用于运营人员每日检查客户业务是否正常推进。适合客户上线初期、关键项目交付期、版本发布后观察期使用。

## 每日巡检

| 检查项 | 关注问题 |
| --- | --- |
| 待处理任务 | 是否存在大量无人认领或超期任务 |
| 订单交期 | 是否有临近交期但关键里程碑未完成的订单 |
| 工厂准入 | 是否有订单使用未准入或高风险工厂 |
| 验厂审核 | 是否有排期未确认、报告未提交、品牌方未批复 |
| CAP 整改 | 是否有超期未关闭或反复退回的问题项 |
| 自动化通知 | 关键提醒是否正常触发 |
| 外部协作 | 供应商、工厂、服务商是否有权限异常反馈 |

## 记录方式

- 每日记录异常数量、影响客户、责任人、处理动作和关闭时间。
- 对重复出现的问题，沉淀到问题排查手册或模板优化建议。
- 对影响配置规则的问题，更新 SOP 或模板配置指南。

## 升级条件

以下情况应升级给产品或研发确认：

- 自动化规则按配置应触发但未触发。
- 权限配置正确但外部角色仍可见不应可见的数据。
- 数据同步后出现字段丢失、状态不一致或重复记录。
- 同类客户反复出现同一流程卡点。
