# Tower 仪表盘配置指南

Tower 仪表盘用于把 FlowSpace、资源库、任务和状态转成运营可读的监控视图。运营人员不应只展示数量，而要围绕“风险、效率、交付、质量、协同”构建指标。

## 推荐看板

| 看板 | 核心指标 |
| --- | --- |
| 订单交付看板 | 订单总数、延期订单、待验货、待出货、异常订单 |
| 供应商治理看板 | 供应商数量、准入状态、风险等级、活跃订单数 |
| 工厂风险看板 | 工厂准入状态、验厂有效期、CAP 未关闭数量 |
| CAP 整改看板 | 未关闭项、超期项、高风险项、平均关闭时长 |
| 运营任务看板 | 待处理任务、超期任务、按负责人统计 |

## 配置步骤

1. 明确看板服务对象：运营、品牌方管理者、供应商协同负责人或测试验证人员。
2. 选择数据来源：订单 FlowSpace、工厂资源库、验厂 FlowSpace、CAP FlowSpace。
3. 统一状态口径：例如“延期”必须明确按计划交期还是里程碑截止日期计算。
4. 配置筛选维度：供应商、工厂、客户、订单状态、风险等级、时间范围。
5. 固定每日巡检视图，避免每次临时筛选。

## 口径维护

指标发生变化时，应同步更新指标说明、数据来源、字段含义和更新时间。涉及业务决策的指标，必须能追溯到具体 FlowSpace 或资源库记录。
