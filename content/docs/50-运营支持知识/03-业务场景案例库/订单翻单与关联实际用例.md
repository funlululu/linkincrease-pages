# 订单翻单与关联实际用例

订单翻单通常发生在客户重复采购、同款不同批次、同供应商持续生产或历史订单复用的场景。运营配置时，重点是复用历史结构，同时保留新订单的独立生命周期。

## 适用场景

| 场景 | 配置重点 |
| --- | --- |
| 同款翻单 | 复用产品、供应商、工厂、关键工艺字段 |
| 同供应商新批次 | 复用供应商和工厂，重新生成交期、数量、验货计划 |
| 订单拆分生产 | 一个订单关联多个生产工厂或多个批次 |
| 历史异常复盘 | 创建新订单时带出历史 CAP、验厂风险和质量异常 |

## 推荐做法

1. 在订单模板中配置“关联历史订单”字段。
2. 将产品、工厂、供应商、验货报告、CAP 等作为可引用对象。
3. 翻单时只复制稳定字段，不复制状态、批复、历史工单结论。
4. 对被复制字段做人工确认，避免历史数据直接污染新订单。

## 数据流转

```mermaid
flowchart LR
    A["选择历史订单"] --> B["带出稳定字段"]
    B --> C["运营/供应商确认新订单信息"]
    C --> D["生成新订单里程碑"]
    D --> E["引用工厂资源库风险信息"]
    E --> F["推进生产、验货、出货"]
```

## 检查点

- 新订单是否拥有独立状态和独立工单。
- 历史异常是否作为风险提示，而不是自动变成新订单异常。
- 翻单后供应商权限是否仍按新订单范围计算。
