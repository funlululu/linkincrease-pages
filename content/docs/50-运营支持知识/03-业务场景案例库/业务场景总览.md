# 运营使用场景

本页用于帮助运营人员从外贸供应链行业场景出发，解释 Linkincrease 能解决什么问题，以及应该如何把客户业务映射到平台能力。

## 行业问题到平台能力

| 行业问题 | 业务表现 | Linkincrease 支撑方式 |
| --- | --- | --- |
| 供应商与工厂资料分散 | 一级供应商清单、工厂资质、准入状态散落在 Excel、邮件和聊天记录中 | 用资源库维护供应商、工厂、资质、准入状态等主数据 |
| 新工厂准入流程不可控 | 供应商提交工厂资料后，品牌方审批、补充资料、结果确认缺少统一流程 | 用 FlowSpace 设计工厂申报与准入流程，沉淀审批记录和资质附件 |
| 订单生产工厂不透明 | 供应商接单后实际使用哪个工厂生产，品牌方难以及时掌握 | 在订单管理 FlowSpace 中让供应商按权限选择关联工厂，形成订单工厂报备数据 |
| 未准入工厂临时使用风险高 | 订单执行中发现需要使用新工厂，但无法快速完成申报、审批、准入 | 从订单工厂报备引导到工厂申报 FlowSpace，准入通过后同步资源库 |
| 社会责任验厂协同复杂 | 品牌方、供应商、工厂、DAREN 服务商之间的验厂任务、资料、审核结果难追踪 | 用独立 FlowSpace 承载验厂审核流程，工单派发给服务商和现场执行人员 |
| CAP 整改闭环不完整 | 验厂报告中的改进项责任、期限、整改证据和复核结论难以闭环 | 用 CAP 跟进 FlowSpace 管理整改项、提交证据、品牌方或服务商复核 |
| 管理层缺少全局视图 | 供应商数量、准入状态、订单使用工厂、验厂风险、CAP 进度无法联动分析 | 用仪表盘和报表跨资源库、订单、工单、批复汇总分析 |

## 运营讲解顺序

1. 先问客户现在如何管理订单、供应商、工厂、验货、整改。
2. 区分哪些是长期主数据，哪些是流程中产生的一次性过程数据。
3. 把主数据放到资源库，把过程数据放到 FlowSpace、订单、工单和批复。
4. 用权限和数据围栏说明品牌方、供应商、工厂、服务商各自能看到什么、能填什么。
5. 用日志、历史记录、仪表盘说明过程可追溯、结果可分析。
