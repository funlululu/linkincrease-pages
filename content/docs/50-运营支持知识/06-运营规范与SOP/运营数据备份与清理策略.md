# 运营数据备份与清理策略

运营数据包括资源库、FlowSpace 记录、工单、批复、附件、报表和配置文档。备份与清理要兼顾客户业务连续性、审计追溯和数据最小化。

## 备份对象

| 对象 | 建议频率 |
| --- | --- |
| 资源库主数据 | 上线前、批量导入前、重大变更前 |
| 模板配置说明 | 每次模板发布后 |
| 关键报表口径 | 指标变更前后 |
| 客户上线配置清单 | 首次上线后和每次大版本调整后 |
| 问题处理台账 | 每周或每月归档 |

## 清理原则

- 不清理仍用于审计、追溯、统计的业务记录。
- 测试数据应与正式数据区分，客户上线后及时清理测试记录。
- 清理前确认是否影响报表、自动化、引用关系和历史记录。
- 外部协作成员离开项目后，应移除权限而不是删除业务记录。

## 操作建议

1. 清理前导出影响范围内的数据。
2. 记录清理条件、数量、执行人和验证结果。
3. 对客户可见数据清理，应取得客户确认。
4. 清理后检查仪表盘和关键流程是否正常。
