# 客户配置建议

本页用于指导运营人员把外贸供应链客户的业务转成 Linkincrease 可落地配置。

## 配置总原则

1. 先识别主数据：供应商、工厂、物料、款式、客户、证书、报告。
2. 再识别流程数据：申报、订单、验厂、整改、采集、批复。
3. 主数据进入资源库，流程数据进入 FlowSpace、订单、工单和批复。
4. 流程确认后的稳定结果再同步回资源库。
5. 权限设计必须围绕品牌方、供应商、工厂、服务商、现场执行人员的真实边界。

## 外贸供应链客户配置顺序

| 步骤 | 配置内容 | 说明 |
| --- | --- | --- |
| 1 | 团队与角色 | 建品牌方团队，区分管理员、审核人、业务跟单、数据查看者 |
| 2 | 协作团队 | 邀请供应商、DAREN 服务商、QC 或现场执行团队 |
| 3 | 资源库模板 | 先配置供应商库、工厂库、证书/报告字段 |
| 4 | 业务模板 | 配置工厂申报、订单管理、验厂审核、CAP 跟进 FlowSpace 模板 |
| 5 | 权限与数据围栏 | 限制供应商只能查看和提交自己相关数据 |
| 6 | 自动化与通知 | 逾期提醒、资料补充提醒、CAP 截止提醒、审核结果通知 |
| 7 | 仪表盘与报表 | 准入状态、订单工厂使用、验厂结果、CAP 风险 |
| 8 | 日志与历史 | 确认关键数据变更有记录，便于审计追溯 |

## 资源库配置建议

| 资源库 | 建议字段 | 配置重点 |
| --- | --- | --- |
| 供应商库 | 名称、编码、等级、状态、联系人、关联工厂、风险等级 | 作为品牌方管理一级供应商的主数据 |
| 工厂库 | 名称、地址、所属供应商、准入状态、资质附件、审核状态、CAP 状态 | 作为订单生产工厂选择和验厂 CAP 的基础 |
| 证书/报告库 | 文件类型、有效期、来源、审核结论、关联工厂 | 如果证书和报告数量多，建议独立管理 |
| 问题项库 | 问题分类、风险等级、整改要求、适用标准 | 用于 CAP 模板和验厂报告结构化 |

## FlowSpace 配置建议

| FlowSpace | 核心目的 | 推荐设计 |
| --- | --- | --- |
| 工厂申报与准入 | 供应商提交工厂，品牌方审批 | 主表单记录申请，工单承载资料补充和审核，批复承载准入结论 |
| 订单管理 | 管理采购订单与生产工厂报备 | 主表单记录订单，工单记录生产进度和异常，工厂字段引用工厂库 |
| 社会责任验厂审核 | 品牌方发起验厂，服务商执行 | 主表单记录验厂项目，工单记录计划、现场审核、报告 |
| CAP 整改跟进 | 跟进报告问题项整改 | 每个问题项形成工单，提交证据后批复关闭 |

## 权限配置建议

| 角色 | 建议权限 |
| --- | --- |
| 品牌方管理员 | 全部资源库、全部 FlowSpace、模板、权限、仪表盘管理 |
| 品牌方审核人 | 查看分配范围内的申报、订单、验厂、CAP，填写批复 |
| 供应商管理员 | 维护自己供应商资料，提交自己名下工厂申报，查看自己相关订单 |
| 工厂联系人 | 只补充自己工厂资料或提交被分配的整改证据 |
| DAREN 服务商 | 查看被分配的验厂项目和 CAP 任务，不查看品牌方全部订单 |
| 现场审核员/QC | 通过采集端完成现场工单、图片、附件、签名和结论提交 |

## 关键配置检查

- 订单中的生产工厂字段是否引用工厂资源库。
- 工厂资源库是否记录准入状态、审核状态、CAP 状态。
- 供应商是否只能看到自己相关工厂和订单。
- 未准入工厂是否有清晰的申报入口。
- 验厂报告是否能产生 CAP 跟进任务。
- CAP 关闭状态是否能回到工厂资源库，供订单风险判断。
