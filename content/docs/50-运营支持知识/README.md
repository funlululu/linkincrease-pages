# 50 运营支持知识

本目录面向产品运营、客户成功、实施配置和售前方案，沉淀 Linkincrease 在外贸供应链行业中的可复用场景方案。

Linkincrease 当前重点服务贸易企业、品牌方、采购团队、QC 服务商和 Sourcing Agency。运营支持知识不只解释功能怎么用，更要说明“客户的真实业务问题如何拆成资源库、FlowSpace、订单、工单、批复、自动化、权限和数据分析”。

## 运营使用原则

1. 先讲行业问题，再映射 Linkincrease 能力。
2. 先识别主数据，再设计流程数据。
3. 先确定品牌方、供应商、工厂、服务商的权限边界，再配置 FlowSpace。
4. 所有场景方案都要说清楚数据如何进入资源库、如何在订单中被引用、如何在工单和批复中流转、如何被审计和分析。
