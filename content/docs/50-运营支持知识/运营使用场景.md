# 运营使用场景

本页用于沉淀运营端、客户成功和实施人员在真实客户场景中的使用方式。

## 场景分类

| 场景 | 说明 | 关联能力 |
| --- | --- | --- |
| 新客户初始化 | 帮助客户完成团队、模板、资源库和权限初始化 | 业务模板、资源库、团队权限 |
| 业务流程上线 | 将客户线下流程转成 FlowSpace、订单、里程碑和工单 | FlowSpace、订单、工单 |
| 协作方接入 | 邀请供应商或外部团队参与采集与批复 | 协作团队、采集端、邮件协作 |
| 数据复盘 | 通过仪表盘、报表和视图分析业务进展 | 仪表盘、报表、常用视图 |

## 维护规则

运营场景必须关联到具体功能模块、业务对象和流程文档，避免只沉淀经验口径。
