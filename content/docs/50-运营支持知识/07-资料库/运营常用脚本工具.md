# 运营常用脚本工具

本页用于记录运营在知识库维护、站点生成、数据检查中常用的本地脚本和命令。公开站点中不要写入个人本地路径、账号、Token 或客户敏感数据。

## 知识库站点

| 用途 | 命令 |
| --- | --- |
| 生成静态站点 | `python scripts/build_static_site.py` |
| 检查敏感信息 | 使用搜索工具检查本地盘符、访问令牌前缀、客户敏感词等不应公开发布的内容 |
| 查看 Git 状态 | `git status --short` |

## 文档维护

| 用途 | 建议 |
| --- | --- |
| 新增文档 | 放入对应编号目录，并更新入口页或索引页 |
| 删除旧文档 | 同步清理 metadata 和站点索引 |
| Mermaid 图表 | 保留源码，并在站点中使用预览能力查看大图 |
| 来源说明 | 写业务来源和确认状态，不写个人电脑路径 |

## 安全提醒

- 不要把 Personal Access Token 写入文档、脚本或提交记录。
- 不要把客户内部文件路径写入公开站点。
- 公开站点只发布已脱敏、可共享的知识内容。
