# 产品功能更新日志（运营视角）

本页用于从运营视角记录产品能力变化，帮助运营判断客户配置、培训材料、SOP 和问题排查手册是否需要同步更新。

## 运营关注点

- 新能力是否会改变客户配置建议。
- 字段、权限、状态、自动化是否影响既有模板。
- 是否需要补充测试验收标准。
- 是否需要更新培训材料和 FAQ。
- 是否需要在仪表盘中增加新指标。

## 维护规范

每次产品版本发布后，运营应至少检查一次本页，并将影响沉淀到对应的模板指南、问题排查或 SOP 文档中。
