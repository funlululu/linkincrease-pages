# 常见业务模板案例

本页用于沉淀外贸供应链场景中可复用的业务模板方案。

## 案例 1：工厂申报与准入模板

| 配置项 | 建议 |
| --- | --- |
| 适用场景 | 品牌方要求供应商提交使用工厂，品牌方审批后进入可用工厂清单 |
| 订单主表单 | 申请编号、供应商、工厂名称、工厂地址、联系人、申请原因、是否紧急 |
| 里程碑 | 资料提交、品牌方初审、资质审核、准入确认 |
| 工单 | 补充资料、资质审核、现场核验、风险评估 |
| 批复 | 初审结论、准入结论、不通过原因 |
| 资源库同步 | 通过后写入工厂资源库，关联供应商资源库 |
| 仪表盘 | 待审核数量、通过率、平均审核周期、按供应商统计申报数量 |

## 案例 2：订单管理与工厂报备模板

| 配置项 | 建议 |
| --- | --- |
| 适用场景 | 品牌方需要知道供应商实际使用哪个工厂生产订单 |
| 订单主表单 | 订单号、供应商、产品、数量、交期、生产工厂、工厂准入状态 |
| 里程碑 | 订单确认、生产准备、生产中、验货、出货 |
| 工单 | 生产计划、产前确认、生产进度、异常上报、出货资料 |
| 批复 | 品牌方确认生产工厂、验货通过、出货确认 |
| 资源库引用 | 生产工厂引用工厂资源库，带出准入、验厂、CAP 信息 |
| 仪表盘 | 订单进度、使用工厂分布、高风险工厂订单、延期订单 |

## 案例 3：社会责任验厂审核模板

| 配置项 | 建议 |
| --- | --- |
| 适用场景 | 品牌方对准入中或已准入工厂发起社会责任审核 |
| 订单主表单 | 审核编号、工厂、供应商、审核类型、计划日期、服务商 |
| 里程碑 | 需求确认、排期、现场审核、报告提交、品牌方确认 |
| 工单 | 审核计划、现场检查、照片附件、报告上传、补充说明 |
| 批复 | 报告审核结论、是否需要 CAP |
| 资源库引用 | 引用工厂资源库，审核结论回写工厂审核状态 |
| 仪表盘 | 审核通过率、待审核工厂、服务商任务进度、审核周期 |

## 案例 4：CAP 整改跟进模板

| 配置项 | 建议 |
| --- | --- |
| 适用场景 | 根据验厂报告、资质报告或订单异常提出整改项 |
| 订单主表单 | CAP 编号、工厂、供应商、来源报告、总体状态 |
| 里程碑 | 问题确认、整改提交、复核、关闭 |
| 工单 | 问题项、风险等级、整改要求、责任人、截止日期、整改证据 |
| 批复 | 复核结论、退回原因、是否关闭 |
| 资源库同步 | 关闭状态、未关闭数量、风险等级回写工厂资源库 |
| 仪表盘 | 未关闭 CAP、逾期 CAP、高风险问题、平均关闭周期 |
