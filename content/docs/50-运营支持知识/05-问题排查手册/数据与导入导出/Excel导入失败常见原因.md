# Excel 导入失败常见原因

## 常见原因

| 原因 | 说明 |
| --- | --- |
| 表头不匹配 | Excel 表头与系统字段名不一致 |
| 必填字段为空 | 关键字段缺失，导致记录无法创建 |
| 选项值不匹配 | 单选、多选字段的值不在系统选项内 |
| 日期格式错误 | 日期时间字段格式不符合要求 |
| 关联数据不存在 | 供应商、工厂、产品等引用对象无法匹配 |
| 附件字段不支持直接导入 | 附件需要按系统支持方式上传 |

## 排查步骤

1. 使用系统导出的模板重新填写。
2. 先导入 3 到 5 条样例数据验证字段。
3. 检查必填字段、选项值、日期格式和唯一编码。
4. 对关联引用字段，先确认资源库中已有目标记录。
5. 保存失败报告，逐行修复后再批量导入。

## 运营建议

客户首次导入前，应先完成字段口径确认和小批量试导入。大批量导入必须保留原始文件和清洗后文件。
