# 协作团队看不到数据

## 常见原因

| 原因 | 说明 |
| --- | --- |
| 未加入协作团队 | 用户只在客户组织中，不在目标协作团队中 |
| 未授权到 FlowSpace | 团队存在，但没有目标 FlowSpace 的访问权限 |
| 数据围栏过滤 | 供应商、工厂、订单归属与用户不匹配 |
| 视图筛选条件过窄 | 默认视图过滤了状态、负责人或时间范围 |
| 字段权限限制 | 可见记录存在，但关键字段被隐藏 |

## 排查步骤

1. 确认用户要看的对象：资源库记录、订单、工单、批复或仪表盘。
2. 检查用户团队、角色、协作范围。
3. 检查记录的供应商、工厂、负责人、协作团队字段。
4. 临时切换到全量视图排除筛选问题。
5. 检查字段权限，确认是否是“看得到记录但看不到内容”。

## 记录要求

权限类问题要记录用户、角色、目标记录、期望可见范围和实际可见范围，方便后续形成权限测试矩阵。
