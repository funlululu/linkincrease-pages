# 用户无法登录注册

## 常见原因

| 现象 | 排查方向 |
| --- | --- |
| 收不到注册或邀请邮件 | 邮箱是否正确、邮件是否进垃圾箱、企业邮箱拦截 |
| 登录后看不到团队 | 是否加入正确团队、是否被移除、是否使用了错误账号 |
| 外部协作方无法访问 | 协作邀请是否过期、权限是否只授予到指定 FlowSpace |
| 手机号或邮箱已被占用 | 是否已有历史账号，是否需要找回或合并 |

## 排查步骤

1. 确认用户使用的邮箱、手机号、团队名称和登录环境。
2. 检查团队成员列表中是否存在该用户。
3. 检查用户是否被加入正确角色、协作团队或 FlowSpace。
4. 如涉及邮件，确认邮件服务、白名单和客户企业邮箱拦截情况。
5. 将无法复现的问题记录到客户问题处理台账。

## 需要升级的信息

- 用户账号标识。
- 发生时间。
- 操作入口。
- 报错截图。
- 所属团队、角色和目标 FlowSpace。
