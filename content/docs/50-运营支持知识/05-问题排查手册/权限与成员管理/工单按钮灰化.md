# 工单按钮灰化

## 常见原因

| 原因 | 说明 |
| --- | --- |
| 当前角色无创建权限 | 用户没有该里程碑或表单的工单创建权限 |
| 里程碑状态不允许 | 当前里程碑未开始、已关闭或被批复阻断 |
| 模板未挂载表单 | 里程碑下没有可创建的工单表单 |
| 前置批复未完成 | 工单批复或里程碑批复仍在处理中 |
| 数据范围不匹配 | 协作团队用户不在该订单或 FlowSpace 授权范围内 |

## 排查步骤

1. 确认用户角色和所在团队。
2. 检查当前 FlowSpace 模板中该里程碑是否挂载表单。
3. 查看当前订单或里程碑状态。
4. 检查是否存在未完成批复。
5. 使用同角色测试账号验证是否为个别用户权限问题。

## 运营建议

将按钮灰化类问题沉淀为模板验收项。每次模板上线前，应分别用品牌方、供应商、服务商、现场人员角色验证按钮状态。
