# 采集端无法登录或上传附件

## 常见原因

| 现象 | 排查方向 |
| --- | --- |
| 无法登录 | 账号、密码、团队、网络、版本 |
| 看不到任务 | 是否为执行人、是否加入协作团队、任务是否已关闭 |
| 图片上传失败 | 网络不稳定、图片过大、权限未开启 |
| 无法定位或拍照 | 手机权限未授权 |
| 提交后数据缺失 | 附件未上传完成就退出页面 |

## 排查步骤

1. 记录设备型号、系统版本、APP 版本和网络环境。
2. 确认用户账号是否可在 Web 端登录。
3. 检查用户是否为目标工单执行人或协作人员。
4. 检查相机、相册、定位权限。
5. 弱网环境下建议先减少单次上传附件数量。

## 运营建议

现场采集前应给执行人员一页纸说明：登录入口、任务入口、必填项、附件上传完成标识、无法提交时的截图要求。
