# 工单无法提交采集

## 常见原因

| 原因 | 说明 |
| --- | --- |
| 必填字段未完成 | 图片、附件、定位、签名等必填项未提交 |
| 网络或附件上传失败 | 移动端弱网导致附件未完成上传 |
| 工单状态已关闭 | 工单已提交、已批复或被管理员关闭 |
| 账号权限不匹配 | 当前用户不是工单执行人或协作人员 |
| 字段校验不通过 | 数字、日期、选项、公式字段校验失败 |

## 排查步骤

1. 确认具体报错文案和提交入口。
2. 检查工单状态、执行人和用户权限。
3. 检查必填字段和附件上传状态。
4. 让用户保留草稿或截图，避免现场数据丢失。
5. 如为移动端问题，记录设备、系统版本、APP 版本和网络环境。

## 运营建议

现场采集类工单要减少不必要必填项。图片、附件、定位等重字段应明确使用场景，避免现场人员无法提交。
