# 客户问题处理

本页用于帮助运营人员排查外贸供应链客户在配置和使用 Linkincrease 时的常见问题。

## 排查总路径

1. 先判断问题发生在哪个层级：资源库、FlowSpace、订单、里程碑、工单、批复、自动化、仪表盘。
2. 再判断数据来源：用户手填、资源库引用、流程审批、自动化写入、系统同步、导入数据。
3. 检查权限：用户是否属于正确团队、协作团队、FlowSpace 角色、数据围栏范围。
4. 检查状态：供应商、工厂、订单、工单、验厂、CAP 是否处于可操作状态。
5. 检查日志和历史：确认谁在什么时间改了什么数据。

## 常见问题

| 问题 | 可能原因 | 处理建议 |
| --- | --- | --- |
| 供应商看不到工厂申报入口 | 未加入协作团队，或未配置创建/提交工单权限 | 检查协作 FlowSpace 权限和数据围栏 |
| 订单里选不到某个工厂 | 工厂未进入资源库、未关联该供应商、准入状态不可用 | 检查工厂资源库和订单字段过滤规则 |
| 工厂已申报但订单仍不能使用 | FlowSpace1 审批结论未同步资源库，或工厂状态未更新为可用 | 检查准入批复字段和资源库同步动作 |
| 品牌方看不到供应商提交的资料 | 数据围栏、字段可见性或协作角色配置不正确 | 检查 FlowSpace 业务角色、协作方角色和字段权限 |
| 验厂报告无法形成 CAP | 报告字段未结构化，或未配置 CAP 创建流程 | 建议把报告问题项拆成 CAP 工单字段 |
| CAP 已关闭但订单仍提示高风险 | CAP 状态未回写工厂资源库，或风险公式未更新 | 检查资源库字段和公式/自动化执行日志 |
| 仪表盘数据和订单列表不一致 | 指标口径、权限范围、刷新频率或数据源不同 | 对照核心指标口径和数据来源说明 |
