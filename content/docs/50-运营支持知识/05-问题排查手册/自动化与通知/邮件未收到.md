# 邮件未收到

## 常见原因

| 原因 | 说明 |
| --- | --- |
| 收件人邮箱错误 | 用户资料或协作邀请中的邮箱填写错误 |
| 企业邮箱拦截 | 客户邮箱安全策略拦截系统邮件 |
| 邮件进入垃圾箱 | 用户未检查垃圾邮件或广告邮件 |
| 通知规则未触发 | 业务事件本身没有触发邮件动作 |
| 用户关闭通知 | 用户个人通知设置关闭 |

## 排查步骤

1. 确认邮件类型：注册、邀请、任务、批复、自动化通知。
2. 确认收件人邮箱和发送时间。
3. 检查对应业务事件是否已发生。
4. 让客户检查垃圾箱、拦截列表和企业邮箱网关。
5. 如多名用户同时未收到，记录时间段并升级排查。

## 运营建议

客户上线前，应让 IT 将系统邮件域名加入白名单。关键节点不要只依赖邮件，可同时配置站内消息或任务提醒。
