# 客户配置建议

本页用于沉淀客户配置 Linkincrease 时的推荐做法。

## 配置顺序

1. 明确客户业务对象和协作角色。
2. 设计业务模板、里程碑和表单结构。
3. 设计资源库模板和主数据维护方式。
4. 配置团队角色、FlowSpace 业务角色和数据围栏。
5. 配置自动化、消息通知、仪表盘和报表。
6. 试运行后补充日志、导入导出和异常处理规则。
