# 运营端概览与各模块地图

本页帮助运营新人快速理解 Linkincrease 运营端负责什么，以及运营端如何支撑贸易端、采集端和客户业务落地。

## 运营端定位

运营端是平台配置、客户初始化、模板治理、资源库治理、后台监管和产品运营支撑入口。它不直接承载客户每天的订单协作，而是为客户团队提供可复用的模板、资源库结构、权限策略和管理工具。

## 新人理解路径

1. 先读 [产品能力地图](../../00-产品总览与规划/产品能力地图.md)，理解产品全貌。
2. 再读 [FlowSpace 数据层级](../../20-业务对象与数据模型/FlowSpace数据层级.md)，理解模板、订单、工单、批复、资源库之间的关系。
3. 然后读 [品牌方供应商与工厂准入协同方案](../03-业务场景案例库/外贸供应商治理/品牌方供应商与工厂准入协同方案.md)，理解外贸供应链核心场景。
4. 最后进入日常任务区，学习模板、资源库、自动化、问题排查和 SOP。
