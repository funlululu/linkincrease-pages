# 客户问题处理

本页用于沉淀客户常见问题的判断路径和处理建议。

## 处理框架

1. 判断问题属于功能使用、配置错误、权限不可见、数据异常、同步延迟还是系统缺陷。
2. 定位涉及的业务对象和数据层级。
3. 检查权限、状态、字段来源、自动化和日志。
4. 给出处理建议，并记录是否需要产品需求补充。
