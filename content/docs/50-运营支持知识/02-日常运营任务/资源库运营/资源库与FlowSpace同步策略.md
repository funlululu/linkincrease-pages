# 资源库与 FlowSpace 同步策略

本页说明资源库主数据与 FlowSpace 流程数据之间如何同步。

## 同步方向

| 方向 | 场景 | 注意事项 |
| --- | --- | --- |
| 资源库到 FlowSpace | 订单选择供应商、工厂、物料时带出信息 | 明确是只读引用还是复制字段 |
| FlowSpace 到资源库 | 工厂准入通过后写入工厂库 | 保留审批记录和来源 FlowSpace |
| FlowSpace 到 FlowSpace | 验厂报告生成 CAP 跟进 | 建议用关联字段或明确来源编号 |
| 资源库状态反向影响 FlowSpace | 工厂暂停后订单侧提示风险 | 明确历史订单是否受影响 |

## 运营建议

- 稳定资料放资源库，过程记录放 FlowSpace。
- 同步前明确来源、目标、触发条件、覆盖规则。
- 状态回写要有日志或历史记录。
- 关键结论不应只由自动化无痕更新。
