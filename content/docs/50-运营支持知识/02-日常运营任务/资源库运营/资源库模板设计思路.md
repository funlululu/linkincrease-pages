# 资源库模板设计思路

资源库用于维护可复用主数据。外贸供应链场景中，供应商、工厂、物料、款式、证书、报告、问题项都适合资源库化。

## 设计步骤

1. 判断数据是否会被多个 FlowSpace 或订单复用。
2. 判断数据是否有长期维护价值。
3. 判断是否需要权限、分享、历史记录和审计。
4. 设计字段、唯一标识、状态、附件、关联引用。
5. 设计与 FlowSpace 的引用和同步方式。

## 常见资源库

| 资源库 | 核心字段 |
| --- | --- |
| 供应商库 | 名称、编码、等级、准入状态、联系人、关联工厂 |
| 工厂库 | 名称、地址、所属供应商、准入状态、审核状态、CAP 状态 |
| 物料库 | 物料编码、名称、规格、供应商、状态 |
| 证书/报告库 | 类型、有效期、附件、关联工厂、审核结论 |
| 问题项库 | 分类、风险等级、整改要求、适用标准 |
