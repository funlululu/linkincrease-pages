# 分享链接与外部协作安全规范

本页用于规范资源库分享、邮件协作、外部填写链接和协作团队参与方式。

## 基本原则

1. 外部协作只开放完成任务所需的最小数据。
2. 不通过截图、转发表格替代系统权限。
3. 分享链接应关注有效期、访问范围和是否可编辑。
4. 协作团队进入 FlowSpace 前必须明确角色和数据围栏。

## 检查清单

| 项目 | 检查点 |
| --- | --- |
| 链接有效期 | 是否需要过期时间 |
| 数据范围 | 是否只包含必要字段和记录 |
| 编辑权限 | 是否允许外部修改数据 |
| 附件权限 | 是否可下载敏感资料 |
| 日志追踪 | 是否能追踪外部提交或查看行为 |
