# 里程碑工单批复设置详解

本页说明里程碑、工单、工单批复和里程碑批复的配置边界。

## 基本关系

| 对象 | 作用 | 基数 |
| --- | --- | --- |
| 里程碑 | 表达订单或项目阶段 | 一个订单下多个里程碑 |
| 工单 | 承载阶段下的执行任务和采集数据 | 一个里程碑下多个工单 |
| 工单批复 | 审核单个工单的提交结果 | 每个工单可对应一个工单批复 |
| 里程碑批复 | 审核整个里程碑阶段的结果 | 一个里程碑通常一个里程碑批复 |

## 配置建议

- 如果每次提交都需要独立确认，用工单批复。
- 如果整个阶段完成后统一确认，用里程碑批复。
- 如果只是记录处理意见，不需要流程控制，可以用普通字段或动态评论。
- 工单批复处理人和里程碑批复处理人应在创建或触发时明确。

## 常见误区

- 把里程碑当成任务明细使用，导致阶段过多。
- 把工单批复用于阶段总确认，导致多个工单结论难以汇总。
- 只配置批复字段，不配置处理人和通知，导致流程卡住。
