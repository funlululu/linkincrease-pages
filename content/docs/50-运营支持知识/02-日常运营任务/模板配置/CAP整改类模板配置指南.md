# CAP 整改类模板配置指南

CAP 整改类模板用于跟进验厂、审核、订单异常或资质报告中提出的改进项。

## 推荐结构

| 层级 | 推荐内容 |
| --- | --- |
| 订单主表单 | CAP 编号、工厂、供应商、来源报告、总体状态、风险等级 |
| 里程碑 | 问题确认、整改提交、复核、关闭 |
| 工单 | 问题项、整改要求、责任人、截止日期、整改证据 |
| 批复 | 复核结论、退回原因、是否关闭 |
| 资源库回写 | 工厂 CAP 未关闭数量、风险等级、整改状态 |

## 配置建议

- CAP 应按问题项拆分，不建议整份报告只用一个总状态。
- 每个问题项要有责任人、截止日期、整改证据和复核结论。
- 逾期 CAP 应配置自动化提醒。
- CAP 关闭后应回写工厂资源库，供订单报备和风险分析使用。
