# 验厂审核类模板配置指南

验厂审核类模板用于品牌方、DAREN 服务商、QC 团队围绕工厂完成社会责任、质量、资质或现场审核。运营配置的重点不是“收集一份报告”，而是把审核计划、现场采集、报告结论、整改动作和工厂主数据连接起来。

## 推荐结构

| 层级 | 推荐内容 |
| --- | --- |
| 主表单 | 验厂编号、工厂、供应商、审核类型、计划日期、服务商、审核状态 |
| 里程碑 | 需求确认、排期、现场审核、报告提交、品牌方确认 |
| 工单 | 审核计划、现场检查、问题记录、图片附件、报告上传 |
| 批复 | 报告审核结论、是否通过、是否需要 CAP、退回原因 |
| 资源库引用 | 工厂资源库、供应商资源库、证书/报告库 |

## 字段建议

- 工厂字段应引用工厂资源库。
- 审核类型可配置为社会责任、质量、资质、复审、专项审核。
- 现场审核工单应支持图片、附件、签名、定位或地址。
- 报告结论应结构化，方便后续生成 CAP。
- 风险等级、审核有效期、下次复审日期应能回写工厂资源库。

## 数据回写建议

验厂完成后，可将审核结论、最近验厂日期、报告附件、是否产生 CAP、风险等级同步回工厂资源库。订单管理流程选择生产工厂时，可以基于这些字段判断是否允许使用、是否需要提醒、是否需要品牌方二次确认。

## 常见配置陷阱

- 只上传报告附件，没有结构化结论，后续无法统计风险。
- CAP 与验厂报告没有关联，整改闭环断裂。
- 供应商能看到品牌方内部审核意见，权限边界过宽。
- 审核有效期没有形成提醒规则，复审容易漏掉。
