# 消息中心运营技巧

消息中心用于帮助用户及时处理任务、批复、协作、异常和系统提醒。

## 运营配置建议

- 关键动作必须有明确接收人，例如审核人、负责人、供应商管理员。
- 消息文案应包含对象名称、任务类型、截止时间和入口。
- 对逾期任务设置多级提醒，避免只提醒一次。
- 对外部协作场景，要区分系统内消息和邮件通知。

## 常见消息场景

| 场景 | 接收人 |
| --- | --- |
| 工厂申报提交 | 品牌方审核人 |
| 工厂申报退回 | 供应商提交人 |
| 订单工厂报备 | 品牌方跟单或审核人 |
| 验厂任务派发 | DAREN 服务商或现场 QC |
| CAP 逾期 | 责任人、供应商管理员、品牌方审核人 |
