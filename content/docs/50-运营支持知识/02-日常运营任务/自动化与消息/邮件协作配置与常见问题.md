# 邮件协作配置与常见问题

邮件协作适合外部人员无需完整登录系统，但需要提交资料、填写工单或补充附件的场景。

## 适用场景

- 工厂联系人补充资质文件。
- 供应商提交生产进度或异常说明。
- 外部服务商上传验厂报告。
- 临时协作方提交整改证据。

## 配置检查

| 项目 | 检查点 |
| --- | --- |
| 数据范围 | 邮件链接中是否只展示必要字段 |
| 有效期 | 链接是否需要失效时间 |
| 附件 | 是否允许上传附件、图片、签名 |
| 通知 | 提交后是否通知品牌方或负责人 |
| 历史 | 邮件填写记录是否可追溯 |

## 常见问题

- 未收到邮件：检查邮箱、垃圾箱、发送记录、自动化执行日志。
- 链接打不开：检查链接有效期、权限和环境地址。
- 字段不可填写：检查表单属性、显隐规则和数据围栏。
