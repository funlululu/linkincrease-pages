# 自动化规则配置食谱

本页沉淀运营常用自动化配置场景。

## 常用规则

| 场景 | 触发条件 | 执行动作 |
| --- | --- | --- |
| 工厂申报待补充 | 审核退回或资料不完整 | 通知供应商补充资料 |
| 工厂准入通过 | 品牌方批复为通过 | 更新工厂资源库准入状态 |
| 订单交期临近 | 距计划交期 N 天 | 通知负责人和供应商 |
| CAP 逾期 | 截止日期已过且未关闭 | 通知责任人和品牌方审核人 |
| 验厂报告提交 | 服务商上传报告 | 通知品牌方审核人 |

## 配置注意

- 自动化写入字段前必须确认目标层级。
- 自动化通知前必须确认接收人范围。
- 关键状态变更要保留系统执行日志。
- 同一条件可能重复触发时，要设计去重或状态判断。
