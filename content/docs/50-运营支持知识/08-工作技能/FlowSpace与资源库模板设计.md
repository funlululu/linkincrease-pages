# Skill：FlowSpace 与资源库模板设计

## 适用场景

将客户稳定主数据和重复业务流程设计成资源库模板、业务模板、FlowSpace、里程碑、工单、批复和自动化时使用。

## 输入

- 业务场景和流程节点
- 稳定主数据对象
- 需要采集、审批、同步和统计的字段
- 内外部角色和权限边界
- 是否需要移动端采集、附件、图片、批量导入导出或报表

## 执行步骤

1. 区分稳定主数据和流程过程数据。
2. 将供应商、工厂、产品、证书、报告等稳定对象放入资源库。
3. 将订单履约、工厂准入、验厂、QC、CAP 等重复流程设计成业务模板。
4. 为每个流程阶段设计里程碑、工单、批复和状态限制。
5. 设计字段来源、引用关系、写回规则、自动化和日志。
6. 校验角色权限、外部协作和数据围栏。
7. 输出模板验收清单和试点数据清单。

## 输出格式

```md
## 业务目标
## 资源库设计
## FlowSpace / 业务模板设计
## 里程碑、工单与批复
## 字段与数据流转
## 权限与数据围栏
## 自动化与通知
## 仪表盘与报表
## 验收清单
## 风险与待确认
```

## 验收标准

- 主数据和流程数据边界清楚。
- 每个字段知道来源、写入位置和是否可更新。
- 外部协作对象只能看到应看到的数据。
- 配置方案能支持试点数据跑通。

## 常见坑

- 把一次性流程做成资源库字段，导致主数据膨胀。
- 把稳定主数据重复放进每个订单，后续同步困难。
- 自动化写入和资源库同步写入同一字段时未定义优先级。
