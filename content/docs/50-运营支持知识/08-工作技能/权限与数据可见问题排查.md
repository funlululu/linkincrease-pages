# Skill：权限与数据可见问题排查

## 适用场景

用户无法登录、看不到数据、按钮灰化、无法提交、无法指派、协作团队看不到 FlowSpace 或工单时使用。

## 输入

- 用户账号、团队、角色和协作团队身份
- 操作路径和目标记录
- 期望结果与实际结果
- 截图、报错、时间点和环境
- 最近是否调整模板、成员、权限、数据围栏或状态

## 执行步骤

1. 先确认用户是否能登录，以及所属团队和角色是否正确。
2. 确认目标记录是否存在，是否属于用户可见的数据范围。
3. 检查协作团队、FlowSpace 角色、工单指派和状态限制。
4. 检查模板字段、按钮条件、批复规则和自动化规则是否影响操作。
5. 查询动态、历史记录、操作日志或系统执行日志，区分配置问题和产品缺陷。
6. 输出临时处理、根因修复和是否需要沉淀 FAQ。

## 输出格式

```md
## 问题分类
## 已知信息
## 优先排查路径
## 可能原因
## 临时处理
## 根因修复
## 是否沉淀知识库
```

## 验收标准

- 能说明问题属于权限、数据围栏、状态、模板配置还是系统异常。
- 有明确复现路径和验证账号。
- 临时处理和永久修复分开。
- 复发问题进入 FAQ 或排查手册。

## 常见坑

- 只看团队角色，漏看协作团队角色。
- 只看按钮权限，漏看订单、里程碑、工单状态。
- 只问截图，不追踪目标记录的数据归属。
