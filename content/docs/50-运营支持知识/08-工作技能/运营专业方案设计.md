# Skill：运营专业方案设计

## 适用场景

产品成功需要基于外贸供应链专业场景，为客户输出 Linkincrease 业务方案、配置建议、能力边界和上线计划时使用。

## 输入

- 客户原始诉求、会议纪要或群消息
- 客户类型：品牌方、贸易公司、采购团队、Sourcing Agency、供应商、工厂、服务商
- 业务场景：准入、订单履约、验货、审核/CAP、出货单证、绩效风险、异常结案等
- 当前资料：Excel、截图、表单、历史方案、现有系统

## 执行步骤

1. 先识别客户问题属于哪个行业场景，不要直接从功能模块开始。
2. 从行业页抽取角色、对象、流程、状态、风险和指标。
3. 从客户方案页抽取推荐资源库、FlowSpace、权限、自动化和看板。
4. 回到产品权威页确认能力边界。
5. 标记支持度：L1、L2、L3、L4、LX。
6. 输出客户方案，并列出需要客户确认和产品确认的问题。
7. 若方案已试点，补充到客户样本与方案复盘。

## 输出格式

```md
## 客户场景判断
## 行业业务理解
## Linkincrease 推荐方案
## 资源库设计
## FlowSpace / 模板设计
## 权限边界
## 自动化与仪表盘
## 能力边界
## 上线步骤
## 验收标准
## 待确认问题
```

## 验收标准

- 方案同时包含行业理解和平台落地方式。
- 不把行业通行做法直接说成产品已支持能力。
- 不把普通异常默认升级为 CAP。
- 有明确的上线试点范围和验收标准。

## 常见坑

- 只讲功能，不解释客户业务为什么需要这样配。
- 只讲行业，不说明 Linkincrease 怎么落地。
- 指标没有数据来源和管理动作。
- 客户样本没有匿名化就直接入库。
