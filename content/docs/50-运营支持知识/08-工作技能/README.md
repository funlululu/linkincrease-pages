# 08 工作技能

本目录沉淀面向产品成功、实施配置、运营支持和需求设计的可复用工作 Skill。Skill 不是产品规则本身，而是把一次次跑通的工作方法整理成可复用流程，供人和 AI Agent 在相似任务中调用。

## Skill 列表

| Skill | 适用场景 |
| --- | --- |
| [客户场景诊断](./客户场景诊断.md) | 客户描述模糊、只说想提效或想管理供应链时，用于还原业务问题并映射平台能力 |
| [新客户上线方案](./新客户上线方案.md) | 为品牌方、贸易公司、采购团队、QC 服务商等客户设计上线计划 |
| [需求文档入库](./需求文档入库.md) | 将新需求、评审结论或来源文档同步进知识库 |
| [权限与数据可见问题排查](./权限与数据可见问题排查.md) | 用户看不到数据、按钮灰化、无法操作或协作团队权限异常 |
| [FlowSpace 与资源库模板设计](./FlowSpace与资源库模板设计.md) | 将客户业务流程拆成资源库、业务模板、里程碑、工单和批复 |
| [运营专业方案设计](./运营专业方案设计.md) | 基于外贸供应链专业场景和 Linkincrease 能力映射输出客户方案 |

## 使用原则

1. 先判断任务是否匹配 Skill 的适用场景。
2. 执行前先阅读 Skill 中列出的必读知识页。
3. Skill 输出的是工作方法和交付结构，不替代权威产品规则。
4. 遇到产品规则不确定时，登记到待确认问题，不直接写成结论。
