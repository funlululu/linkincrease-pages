# 09 客户样本与方案复盘

本目录用于沉淀匿名客户样本、方案试点记录、上线复盘和可复用经验。它补足行业知识和 SOP 的“真实经验层”，帮助产品成功知道哪些方案真的跑通过、哪些只是理论建议。

## 使用原则

1. 必须匿名化客户名称、人员、账号、合同、报价和敏感数据。
2. 原始聊天或会议纪要不直接入库，先提炼为结构化样本。
3. 单个客户做法不能外推为行业标准，只能标记为客户样本。
4. 可复用结论需要说明适用边界。
5. 产品规则缺口进入需求池或待确认问题，不直接改权威页。

## 样本分类

| 类型 | 说明 | 去向 |
| --- | --- | --- |
| 成功配置样本 | 已在客户侧跑通的配置方案 | 本目录 + 对应场景方案页 |
| 问题复盘样本 | 上线或使用中踩坑 | 本目录 + FAQ/SOP |
| 需求信号样本 | 多个客户反复出现的产品缺口 | 本目录 + 需求池 |
| 能力边界样本 | 客户期望超出当前平台能力 | 本目录 + 待确认问题 |

## 每周复盘入口

每周从客户群消息、项目复盘、上线问题中提取：

```text
客户类型
业务场景
原始问题
实际配置方案
上线效果
踩坑
可复用结论
不能外推的部分
```
