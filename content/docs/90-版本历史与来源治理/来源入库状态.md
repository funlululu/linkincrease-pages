# 来源入库状态

## 定位

本页用于追踪 `最新需求源（source:thoughts-v2-current）` 原始材料与标准知识页之间的入库关系，回答三个问题：

1. 哪些原始需求已经被归类。
2. 哪些原始需求已经抽取进标准知识页。
3. 哪些模块还需要继续拆页、补来源或校验。

## 入库状态定义

| 状态 | 说明 |
|---|---|
| 已归类 | 已确定原始需求所属模块，但未必完整抽取 |
| imported | 已进入 `metadata/sources.csv` 来源台账 |
| authoritative | 已形成标准知识页，可作为当前知识库口径 |
| draft | 仍作为问题池或过程文档，需要后续确认 |
| 待校验 | 需求之间存在冲突，或需要与线上版本、产品负责人确认 |
| 待补充来源 | 需求中引用了外部表格、外部链接或未入库材料 |

## 维护动作

新增或更新需求文档时，按以下顺序处理：

1. 将所思在线内容同步到 `最新需求源（source:thoughts-v2-current）`。
2. 运行 `python scripts\scan_source_manifest.py`，更新 `metadata/source-manifest.csv` 和 `metadata/source-diff.csv`。
3. 更新 [需求文档来源台账](../../05-需求文档来源台账.md)。
4. 更新 `metadata/sources.csv`。
5. 抽取或更新对应 `docs/` 知识页。
6. 更新 `metadata/documents.csv` 和 `metadata/search-index.json`。
7. 如果存在冲突或缺口，更新 [待确认问题](./待确认问题.md)。
