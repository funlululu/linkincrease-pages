# 团队共享与只读发布方案

## 定位

本页说明如何将 Linkincrease 知识库提供给产品团队查看，同时保持“仅维护人可管理”的权限边界。

推荐方案：

```text
私有 Git 仓库管理源文件
+ 静态网站只读发布给产品团队
+ linkincrease-requirement-design Skill 辅助需求设计和入库
+ Daren 保留维护权限
```

## 1. 权限模型

| 角色 | 权限 | 说明 |
|---|---|---|
| 知识库维护人 | 读写源文件、提交 Git、发布站点、更新 Skill | 通常由 Daren 负责 |
| 产品成员 | 只读访问静态站点 | 查看知识库，不直接修改源文件 |
| 需求提出人 | 提交需求草稿或确认稿 | 可让 Skill 做检查，但不直接入库 |
| 评审参与人 | 查看影响范围、待确认问题、版本记录 | 用于评审和对齐 |

## 2. Git 私有仓库

建议将知识库本地工作区初始化为私有 Git 仓库，并托管到公司认可的平台。

可选平台：

- 公司内部 GitLab / Git 服务。
- GitHub Private Repository。
- Gitee 私有仓库。
- Azure DevOps / Bitbucket 等。

建议权限：

| 成员类型 | Git 权限 |
|---|---|
| Daren | Maintainer / Admin |
| 产品成员 | Reporter / Read-only |
| 研发、测试 | Reporter / Read-only |

源文件只通过维护人合入，避免知识库口径被多人随手改散。

## 3. 静态网站只读发布

当前知识库提供本地静态站点生成脚本：

```powershell
python scripts\build_static_site.py
```

生成目录：

```text
exports\site
```

默认静态站只展示公开知识页，不展示 `skills/` 文档和本地临时目录。需要给 Agent 使用者临时发布 Skill 文档或下载包时，可显式设置：

```powershell
$env:INCLUDE_SKILLS_IN_SITE="1"
$env:INCLUDE_SKILL_DOWNLOADS="1"
python scripts\build_static_site.py
```

发布方式可以按团队条件选择：

| 方式 | 说明 |
|---|---|
| 内网服务器 | 将 `exports\site` 部署为只读目录 |
| Git Pages / GitLab Pages | 由私有仓库发布静态站点 |
| NAS / 共享盘 | 将 `exports\site` 作为只读共享目录 |
| 临时预览 | 本机运行 `python -m http.server` 预览 |

本地预览命令：

```powershell
cd exports\site
python -m http.server 8010
```

然后访问：

```text
http://localhost:8010
```

## 4. Skill 共享方式

Skill 名称：

```text
linkincrease-requirement-design
```

当前本机位置：

```text
本地 Codex skills 目录中的 `linkincrease-requirement-design` skill
```

团队使用时建议采用可配置知识库路径：

```text
LINKINCREASE_KB_PATH
```

优先级建议：

1. 使用环境变量 `LINKINCREASE_KB_PATH` 指向团队共享的知识库本地副本或只读路径。
2. 如果没有环境变量，由使用者提供知识库本地路径。
3. 如果都不存在，由使用者提供知识库路径。

产品成员如果只是查看知识库，不需要安装 Skill。只有需要在 Codex 中做需求设计、草稿检查、影响分析的人才需要安装。

## 5. 需求确认后的入库流程

```text
成员编写需求草稿
→ 使用 Skill 做补漏和冲突检查
→ 需求评审确认
→ 维护人将确认稿同步到最新需求源（source:thoughts-v2-current）
→ 维护人运行来源扫描
→ 维护人更新知识页、来源台账、metadata、待确认问题和版本记录
→ 重新生成静态站点
→ 产品团队查看最新只读站点
```

扫描命令：

```powershell
python scripts\scan_source_manifest.py
```

生成站点命令：

```powershell
python scripts\build_static_site.py
```

## 6. 注意事项

1. 静态站点是阅读入口，不是编辑入口。
2. Skill 是工作方法和路径索引，不是面向所有阅读者的知识库正文；默认不在静态站导航中展示。
3. 知识库正文统一使用 FlowSpace；历史 `source:` 引用中的 SCCS 保留原始文件名。
4. 产品成员可以提交需求建议，但最终入库应由维护人审核。
5. 每次入库后需要重新生成并发布静态站点。
