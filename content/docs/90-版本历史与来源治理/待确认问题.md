## 当前待补充来源

| 内容 | 需要补充 |
|---|---|
| 邮件、短信、通知规则及模板 | 多份需求引用该材料，但最新源中未见独立完整文档 |
| 权限矩阵表 | 多处引用钉钉表格，需要导出并入库为可追溯材料 |
| 第三方 API / PDF 导入字段整理 | 需求中有外部链接和嵌入说明，建议整理为本地文档 |
| 线上实际菜单结构 | 需要与当前产品版本核对，确认知识库功能地图是否与线上一致 |
| 截图资源 | 需求文档中大量截图仍为远程链接，建议批量下载并建立本地映射 |

## 处理原则

1. 不确定内容不直接写成最终规则；先标注来源和假设。
2. 如果多个需求文档冲突，以更晚版本或产品确认结果为准。
3. 一旦问题确认，需要同步更新对应知识页、来源台账、metadata 和本页状态。
4. SCCS 更名为 FlowSpace 已按当前口径处理；后续新增需求若仍出现 SCCS，正文继续映射为 FlowSpace。
4. 与权限、状态、数据写入优先级相关的问题优先处理，因为它们会影响多个模块。
