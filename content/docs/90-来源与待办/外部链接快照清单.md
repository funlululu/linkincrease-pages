# 外部链接快照清单

## 定位

原始需求文档中包含大量远程截图、Teambition 图片、Thoughts 链接和钉钉表格链接。为了避免外部链接失效，本页用于定义外部链接的快照策略和优先处理清单。

## 外部链接类型

| 类型 | 示例来源 | 风险 | 处理策略 |
|---|---|---|---|
| Teambition 图片 | `https://tcs.teambition.net/storage/...` | 链接过期、签名失效 | 批量下载到 `assets/images/` 并建立映射 |
| Thoughts 文档 | `https://thoughts.teambition.com/...` | 权限变化、目录结构变化 | 导出为 Markdown 或 PDF 放入 `sources/exported/` |
| 钉钉表格 | `https://alidocs.dingtalk.com/spreadsheetv2/...` | 权限变化、在线内容变动 | 导出为 xlsx/csv 放入 `sources/exported/` |
| 外部 API 说明 | 需求中的外部链接或嵌入说明 | 链接不可访问、字段口径丢失 | 整理为本地接口说明文档 |

## 当前重点外部资料

| 资料 | 当前出现位置 | 建议处理 |
|---|---|---|
| FlowSpace 权限矩阵钉钉表格 | `【贸易端】【SCCS设置】.md`、`【贸易端】【协作SCCS设置】.md`、订单详情相关文档 | 优先导出为权限矩阵表，补入 `docs/40-权限与安全/` |
| 需求截图 | 几乎所有原始需求文档 | 批量下载并按来源文档、行号或资源 ID 建立索引 |
| 采集端消息中心关联 Thoughts 文档 | `【采集端】【消息中心】消息通知列表.md` | 导出原文，补入消息模板来源 |
| 邮件、短信、通知规则及模板 | 多份文档引用但未见独立完整文档 | 从在线资料或团队文件中补齐后入库 |
| 第三方 API / SCMPRO 字段说明 | 外部 API、第三方数据对接、PDF 导入相关需求 | 整理为字段映射和接口示例文档 |

## 建议本地存储结构

```text
sources/
  exported/
    tables/
    thoughts/
    api/
  snapshots/
    screenshots/
assets/
  images/
    requirements/
```

命名建议：

```text
需求来源短名__资源类型__序号__简述.ext
```

示例：

```text
sccs-settings__table__permission-matrix.xlsx
order-detail__image__tracking-record.png
external-api__doc__field-mapping.md
```

## 快照元数据建议

后续可新增 `metadata/external-links.csv`，字段建议如下：

| 字段 | 说明 |
|---|---|
| id | 外部资源唯一 ID |
| source_file | 出现在哪个原始需求文档 |
| source_line | 出现行号 |
| url | 原始 URL |
| type | image、thoughts、dingtalk、api、other |
| local_path | 本地快照路径 |
| status | pending、downloaded、failed、not_needed |
| captured_at | 快照时间 |
| notes | 备注 |

## 优先级

| 优先级 | 范围 | 原因 |
|---|---|---|
| P0 | 权限矩阵表、通知模板、外部 API 字段说明 | 会影响产品规则和后续开发判断 |
| P1 | 订单、工单、权限、自动化关键截图 | 有助于还原复杂交互 |
| P2 | 普通页面原型截图 | 可在知识页稳定后批量归档 |
