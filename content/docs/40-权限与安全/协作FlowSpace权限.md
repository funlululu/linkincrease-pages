# 协作FlowSpace权限

## 1. 功能定位

协作 FlowSpace 权限控制外部协作团队成员在链主方 FlowSpace 中能看什么、能处理什么、能否指派协作任务。它由链主方在 FlowSpace 设置中授予协作团队角色和协作里程碑，再由协作团队在协作 FlowSpace 设置中分配具体成员。

## 2. 权限来源

| 来源 | 说明 |
| --- | --- |
| 链主方 FlowSpace 协作方角色 | 链主方创建，选择协作团队并配置订单、里程碑、工单相关权限 |
| 协作团队自建角色 | 协作团队在协作 FlowSpace 设置中自建，控制本团队成员对协作任务的查看和指派 |
| 对接人角色 | 协作团队固定角色，可管理角色和成员，并可指派所有协作任务 |
| 主团队角色 | 链主方创建并开放给当前协作团队的角色，协作团队只能编辑成员，不能改权限点 |

## 3. 链主方配置规则

链主方在 FlowSpace 设置中添加协作团队时，可配置：

- 协作方角色。
- 数据围栏。
- 协作的里程碑。

添加协作团队到 FlowSpace 时，协作团队拥有者默认成为该 FlowSpace 的对接人。链主方删除协作团队后，该协作团队所有成员在当前 FlowSpace 相关业务数据不可查看，任务中心相关工单隐藏，相关邮件和消息跳转提示暂无权限。

## 4. 协作团队角色权限点

| 权限分类 | 权限名称 | 控制功能 |
| --- | --- | --- |
| FlowSpace 工具权限 | FlowSpace 设置 | 当前协作 FlowSpace 的设置权限 |
| 订单权限 | 查看订单基本信息 | 订单列表查看订单、订单详情主表单 |
| 里程碑权限 | 查看工单 | 工单视图和订单详情查看工单 |
| 里程碑权限 | 查看里程碑批复 | 里程碑批复视图和订单详情查看里程碑批复 |
| 里程碑权限 | 工单采集/指派 | 指派或修改本团队工单采集成员，也可处理相关采集任务 |
| 里程碑权限 | 工单批复/指派 | 指派或修改本团队工单批复成员，也可处理相关批复任务 |
| 里程碑权限 | 里程碑批复/指派 | 指派或修改本团队里程碑批复成员，也可处理相关批复任务 |

## 5. 订单范围

| 范围 | 说明 |
| --- | --- |
| 所有参与协作的订单 | 当前协作团队作为工单采集人、工单批复人、里程碑批复人的订单 |
| 自定义 | 在本团队参与的所有订单基础上，再按主表单字段设置限制条件 |

协作方自定义订单范围是在“参与协作订单”的基础上收窄，不是跨越链主方授权范围的扩权。

## 6. 勾选联动规则

- 勾选工单采集/指派、工单批复/指派时，需要同时勾选查看工单。
- 勾选里程碑批复/指派时，需要同时勾选查看里程碑批复。
- 勾选查看里程碑批复时，需要同时勾选查看工单。
- 勾选任意里程碑权限时，需要同时勾选查看订单基本信息。
- 自定义订单范围权限跟随查看订单基本信息。

## 7. 消息通知设置

协作团队自建角色中，里程碑任务指派权限旁可设置“对接人不再接收此类消息通知”。打开时，如果当前里程碑对应权限尚无其他角色勾选，需要提醒：暂未设置其他成员接收该类消息，打开后可能无法及时通知。

## 8. 成员管理规则

- 协作 FlowSpace 成员来自已成功加入本团队的成员。
- 添加成员时可设置角色，多选且非必填。
- 删除最后一名对接人时不可删除，提示至少保留一名对接人。
- 删除成员后，该成员当前 FlowSpace 相关业务数据不可查看；任务中心相关工单隐藏；相关邮件、消息跳转提示暂无权限。

## 9. 审计要求

协作 FlowSpace 设置操作日志需要记录：

- 自建角色新增、编辑、删除。
- 主团队角色编辑，仅记录成员编辑。
- 成员管理新增、删除、设置权限。

主团队修改或删除协作方角色，不记录在协作方 FlowSpace 的操作日志中。

## 10. 待确认问题

- “对接人”“有指派权限成员”“任务实际处理人”在所有通知和任务列表中的边界需要继续校验。
- 链主方删除协作里程碑权限时，协作团队历史任务和历史记录是否保留完整可见，需要补规则。
