# 资源库权限

## 1. 功能定位

资源库权限控制团队资源库的创建、删除、设置、表数据查看、创建、编辑、删除、导入、导出、分享，以及协作团队对资源库数据的访问和操作范围。

## 2. 团队级入口权限

| 权限 | 说明 |
| --- | --- |
| 创建资源库 | 允许成员在当前团队下创建资源库 |
| 删除资源库 | 允许成员删除本团队下任意资源库，并可查看所有资源库数据 |
| 资源库设置 | 允许成员查看本团队资源库所有数据，并管理资源库设置 |
| 协作资源库管理 | 允许成员管理本团队参与协作的资源库设置，以及主团队授权的数据操作权限 |

## 3. 单个资源库角色

| 角色 | 规则 |
| --- | --- |
| 资源库管理员 | 每个资源库固定角色，拥有当前资源库所有权限；默认创建资源库的成员为管理员；不可删除，不可修改权限点，但可修改成员 |
| 成员角色 | 面向本团队成员，可配置资源库设置和各表权限 |
| 协作方角色 | 面向协作团队，权限类似成员角色，但没有资源库设置权限 |

任意资源库中任意角色添加了成员后，该成员即可见资源库主菜单；具体可见哪个资源库、哪些表、哪些数据，继续由角色勾选内容决定。

## 4. 表权限与数据范围

| 维度 | 规则 |
| --- | --- |
| 表权限 | 资源库下每张表单独配置权限；勾选任意表操作权限时，需同时勾选该表“查看数据” |
| 全部 | 可操作对应表下所有数据 |
| 本人创建 | 仅可操作成员本人创建的数据 |
| 自定义 | 必须配置字段条件；字段范围包括模板字段、创建人、创建时间、更新人、更新时间等 |

成员控件、创建人、更新人可选择“当前用户”；协作方控件可选择“当前团队”。

## 5. 数据操作权限

| 操作 | 权限要求 |
| --- | --- |
| 查看数据 | 需拥有当前表查看权限和对应数据范围 |
| 创建数据 | 需拥有当前表新增权限 |
| 编辑数据 | 需拥有当前表编辑权限；批量编辑按钮也受此权限控制 |
| 删除数据 | 需拥有当前表删除权限 |
| 导入数据 | 当前用户在当前资源表需有导入权限 |
| 导出数据 | 仅导出当前用户有查看权限的表和数据 |
| 批量下载文件 | 所有可进入当前资源表的成员可见 |

导入记录仅能查看本人导入的记录。资源库数据导入成功后，需要增加导入人操作的新增或修改历史记录。

## 6. 协作资源库

主团队授权后，协作团队资源库列表会展示协作类型资源库，并只展示授权给本团队且有查看权限的表。协作资源库设置包含成员管理，可添加当前团队成员并设置角色。

| 协作角色 | 说明 |
| --- | --- |
| 资源库管理员 | 拥有当前协作资源库设置权限，以及主团队授权给本团队的所有表内相关权限 |
| 普通成员 | 拥有当前资源库中主团队授权给本团队的所有表内相关权限 |

同一协作团队拥有多个角色时，权限叠加。

## 7. 分享权限

| 分享类型 | 规则 |
| --- | --- |
| 单条数据分享 | 内部成员或协作团队成员只要有数据查看权限，即可分享单条数据 |
| 整表分享 | 有资源表查看权限即可分享整表 |
| 分享权限同步 | 分享者权限变更后，被分享方权限同步更新 |
| 分享失效 | 分享者失去查看权限时，分享链接失效；重新获得权限后原链接仍失效，需重新分享 |
| 分享链接管理 | 管理员可查看权限范围内所有分享链接；成员个人只可查看本人分享链接 |

分享链接删除后失效。预览、删除、编辑提交时均需校验权限。

## 8. 与 FlowSpace 引用的关系

资源库被 FlowSpace 引用后，数据权限和同步规则会影响订单数据。若资源库协作授权导致数据不可见，当前需求暂按“资源库数据被删除”逻辑同步清空 FlowSpace 订单字段处理，但该方案仍需作为重点确认项保留。

## 9. 审计要求

资源库设置操作日志需要记录：

- 基本信息新增、编辑。
- 权限管理新增、编辑、删除。

运营端模板修改不记录在资源库设置操作日志中。

## 10. 待确认问题

- 协作资源库数据不可见时，历史引用数据保留还是同步清空，目前需求中存在方案说明，需与线上规则确认。
- 外部分享只读开关、分享者编辑权限、被分享者编辑权限之间的最终优先级需补充矩阵。
- 导出是否严格按数据范围过滤字段和记录，需要后续用线上验证。
