# 历史 Bug 高发区标记

本页用于沉淀历史缺陷高发区域和回归时必须重点关注的风险点。

## 当前高风险区域

| 区域 | 常见风险 |
| --- | --- |
| 权限和数据围栏 | 列表可见、详情可见、字段可见、导出可见不一致 |
| 资源库引用与同步 | 引用字段显示正确但保存或同步目标错误 |
| 模板同步到实例 | 模板字段变更影响既有 FlowSpace、订单、工单数据 |
| 工单与批复 | 工单批复、里程碑批复的基数和状态容易混淆 |
| 自动化执行 | 重复触发、失败无日志、写入层级错误 |
| 仪表盘与报表 | 指标口径、权限过滤、刷新时机不一致 |
| 导入导出 | 字段映射、权限过滤、子表、附件和历史记录容易遗漏 |
