# 测试常见问题 FAQ

本页用于沉淀测试人员在理解业务、设计用例和定位缺陷时的常见问题。

## 常见问题

| 问题 | 回答 |
| --- | --- |
| 测试一个需求时先看哪些文档？ | 先看功能模块页，再看业务对象、业务流程、权限、安全审计和数据分析相关页面。 |
| 如何判断字段应该测订单还是工单？ | 先看 [FlowSpace 数据层级](../20-业务对象与数据模型/FlowSpace数据层级.md)，判断字段属于订单主表单、里程碑工单、批复表单、资源库还是子表。 |
| 权限测试只测按钮显示够吗？ | 不够。还要测列表、详情、搜索、导出、仪表盘、报告、通知链接和接口数据范围。 |
| 资源库引用类需求怎么测？ | 必须测引用选择、权限过滤、字段带出、同步回写、引用记录停用或删除后的行为。 |
| 自动化类需求怎么测？ | 必须测触发条件、执行动作、重复触发、失败记录、执行日志和权限边界。 |
| 仪表盘数据不一致怎么定位？ | 先确认指标口径、数据源、权限范围、刷新时机，再对照列表和源数据。 |
| 发现知识库与系统行为不一致怎么办？ | 先确认系统行为是否符合产品预期，再更新权威知识页、待确认问题或缺陷记录。 |
