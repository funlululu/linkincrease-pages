# 权限测试矩阵

本页用于把权限规则转化为测试用例矩阵。权威规则以权限目录为准，本页负责测试覆盖。

## 通用权限维度

| 维度 | 测试点 |
| --- | --- |
| 团队角色 | 拥有者、管理员、普通成员、外部协作者的入口和操作差异 |
| FlowSpace 业务角色 | FlowSpace 内订单、里程碑、工单、设置和数据范围 |
| 协作 FlowSpace 角色 | 协作团队只看到被授权的数据和任务 |
| 数据围栏 | 字段、标签、订单、资源库记录的可见性 |
| 资源库权限 | 创建、编辑、删除、分享、引用、同步、历史记录 |
| 仪表盘与报告权限 | 图表、报表、数据源和结果是否按权限过滤 |

## 品牌方供应商工厂场景权限矩阵

| 角色 | 应能操作 | 不应能操作 |
| --- | --- | --- |
| 品牌方管理员 | 查看全部供应商、工厂、订单、验厂、CAP，配置模板和权限 | 不适用 |
| 品牌方审核人 | 审核被分配的工厂申报、验厂报告、CAP 复核 | 修改无关模板和全局权限 |
| 供应商管理员 | 提交自己名下工厂申报，查看自己相关订单，提交生产工厂报备 | 查看其他供应商订单、工厂和品牌方内部审核意见 |
| 工厂联系人 | 补充本工厂资料，提交被分配的整改证据 | 查看供应商全量订单、其他工厂资料 |
| DAREN 服务商 | 查看被分配的验厂和 CAP 任务，提交审核报告或复核意见 | 查看品牌方全部订单和供应商资源库 |
| 现场审核员/QC | 在采集端完成现场工单、上传图片附件、签名 | 修改品牌方审批结论和资源库主数据 |

## 测试用例转化规则

每条权限规则至少转化为三类用例：

1. 有权限用户可以完成操作。
2. 无权限用户看不到入口或无法提交。
3. 数据范围变化后，已有页面、搜索、导出、仪表盘同步受控。
