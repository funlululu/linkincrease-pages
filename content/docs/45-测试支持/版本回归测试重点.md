# 版本回归测试重点

本页用于根据版本变更和历史风险沉淀回归测试重点。

## 回归范围判断

| 变更类型 | 回归重点 |
| --- | --- |
| 功能模块变更 | 对应模块验收清单、入口、权限、主流程 |
| 业务对象变更 | 数据层级、字段保存、历史记录、导入导出 |
| 权限变更 | 不同角色、数据围栏、导出、仪表盘和报告 |
| 流程变更 | 主路径、退回路径、状态边界、通知和日志 |
| 资源库变更 | 引用、同步、删除/停用、历史记录和权限过滤 |
| 自动化变更 | 触发条件、执行动作、失败日志、重复触发 |
| 仪表盘/报表变更 | 指标口径、数据源、权限范围、刷新时机 |
