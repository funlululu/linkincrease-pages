
# 公式函数

## 1. 功能定位

公式函数用于表单字段的自动计算，可服务于订单、工单、批复、资源库、验货组件和统计分析。公式组件可输出数字、百分比、文本或日期等类型，并在相关因子变化后自动更新。

## 2. 基础规则

| 规则 | 说明 |
| --- | --- |
| 空值定义 | `null`、`undefined`、空字符串统一视为空值 |
| 布尔值 | 条件判断目前仅支持小写 `true`、`false` |
| 变量来源 | 通常来自当前表单或允许引用的数据源字段 |
| 子表计算 | 支持对子表数组字段进行求和、计数、条件统计和去重 |

## 3. 函数分类

| 分类 | 函数 |
| --- | --- |
| 文本函数 | CONCATENATE、TEXTJOIN、LEFT、RIGHT、SEARCH |
| 数学函数 | SUM、AVERAGE、MAX、MIN、CEILING、FLOOR、INT、SUMIF、SUMIFS、COUNTIF、COUNTIFS、COUNTA、UNIQUE |
| 逻辑函数 | IF、IFS、AND、OR |
| 时间函数 | DAYS、WORKDAY、DATEDIF、NETWORKDAYS、YEAR、MONTH、DAY、HOUR、TODAY、NOW、MINUTE、SECOND |

## 4. 常用函数规则

| 函数 | 用途 | 空值处理 |
| --- | --- | --- |
| CONCATENATE | 合并多个文本 | 空值视为空字符串 |
| TEXTJOIN | 按分隔符合并文本 | 可设置是否忽略空值 |
| SUM | 求和 | 忽略空值 |
| AVERAGE | 平均值 | 忽略空值 |
| MAX/MIN | 最大/最小值 | 忽略空值 |
| SUMIF/SUMIFS | 按一个或多个条件求和 | 条件区域空值忽略，求和区域空值按 0 |
| COUNTIF/COUNTIFS | 条件计数 | 可专门计算空值 |
| IF/IFS | 条件判断 | 条件空值按 false |
| AND/OR | 逻辑判断 | 空值按 false |
| DAYS/DATEDIF | 日期差 | 日期参数为空时返回错误 |
| TODAY | 返回当天日期 | 用于自动更新“今天” |

## 5. TODAY 自动更新

当公式组件内含 TODAY 函数时，贸易端展示需要每天自动更新到当天。

当公式中直接包含 `TODAY`，或公式变量因子引用的其他公式中包含 `TODAY` 时，该公式视为 TODAY 公式。TODAY 公式默认进入系统自动计算范围，即使未开启普通公式自动计算，也会随日期变化自动重新计算。

不更新场景：

- 订单已完成。
- 订单已取消。
- 里程碑已完成。
- 里程碑已取消。

## 6. 自动更新与日志

公式因子发生变更后，相关公式字段需要同步更新。系统自动执行日志中需要记录公式自动更新，并在对应业务模块留下可追溯记录，例如订单跟踪记录、工单/里程碑批复动态、主表单或批复历史记录。

未开启自动计算时，公式只在用户编辑当前表单期间实时计算，提交后固化。开启自动计算后，公式成为系统自动写入能力，需要按照公式所在数据源判断是否允许更新：订单主表单、里程碑批复表单、工单采集表单和工单批复表单分别遵守订单、里程碑、工单状态限制。

资源库表单公式变量只来自当前表单，按普通表单编辑逻辑处理：用户编辑资源库记录时实时计算，提交后固化，不纳入公式自动计算状态限制表。

## 7. 与组件的关系

- 文本、数字、百分比、日期等组件可通过公式计算默认值。
- 公式组件可被其他组件作为关联数据源。
- 公式显示类型影响显隐设置、导入校验、导出和展示格式。
- API 写入触发字段后，也会触发相关公式字段自动计算。

## 8. 待确认问题

- NOW、MINUTE、SECOND 是否已正式上线，原始资料中部分标注为后期考虑。
- 公式错误值如何在贸易端、导出、报告中展示，需要补统一规则。
- 公式自动更新失败是否需要重试、告警或单独日志页。
