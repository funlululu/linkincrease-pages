# 订单数据模型

订单数据模型用于说明订单在 FlowSpace 运行态中的数据位置、字段来源和关联对象。

## 数据位置

| 数据层级 | 说明 | 关键约束 |
| --- | --- | --- |
| FlowSpace | 订单所属业务空间 | 决定可用模板、业务角色、权限和数据围栏 |
| 订单 | FlowSpace 下的主业务记录 | 承载主表单数据和订单状态 |
| 主表单字段 | 创建订单时填写的订单信息 | 来自业务模板默认主表单 |
| 里程碑 | 订单下的阶段节点 | 由业务模板配置生成 |
| 工单 | 里程碑下的执行记录 | 与订单关联，不替代订单主数据 |
| 跟踪记录 | 订单关键操作记录 | 用于审计和回溯 |
