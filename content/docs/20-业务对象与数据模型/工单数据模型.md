# 工单数据模型

工单数据模型用于说明工单、工单批复、里程碑批复在 FlowSpace 中的层级和基数关系。

## 数据位置

| 数据层级 | 说明 | 关键约束 |
| --- | --- | --- |
| 里程碑 | 工单所属阶段 | 工单必须挂在具体里程碑下 |
| 工单 | 里程碑下的执行记录 | 同一里程碑可创建多个工单 |
| 工单表单字段 | 工单填写内容 | 来自当前里程碑挂载的表单 |
| 工单批复 | 对单个工单的批复数据 | 开启后每个工单对应一个工单批复 |
| 里程碑批复 | 对当前里程碑的批复数据 | 开启后当前里程碑仅有一个里程碑批复 |
