# 资源库数据模型

资源库数据模型用于说明资源库模板、团队资源库、协作资源库和引用数据之间的关系。

## 数据位置

| 数据层级 | 说明 | 关键约束 |
| --- | --- | --- |
| 资源库模板 | 运营端配置资源库结构 | 决定资源库表单、字段和组件 |
| 团队资源库 | 团队内维护的主数据集合 | 可被 FlowSpace、订单、工单引用 |
| 协作资源库 | 通过分享或协作开放的数据集合 | 受资源库权限和数据范围控制 |
| 资源库记录 | 资源库中的具体数据行 | 可被字段引用、同步或记录历史 |
| 引用字段 | FlowSpace 运行数据中的资源库引用 | 必须区分引用关系和写入目标 |
