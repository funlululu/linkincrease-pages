# 产品需求影响分析清单

本清单用于产品经理在需求进入 PRD 或排期前快速判断影响范围，避免只看到页面改动而漏掉权限、数据、日志、报表和测试。

## 快速结论

| 判断项 | 结论 |
| --- | --- |
| 建议处理方式 | 产品需求 / 配置方案 / SOP / 待确认 / 暂缓 |
| 影响等级 | 低 / 中 / 高 |
| 是否需要 PRD | 是 / 否 |
| 是否需要技术预研 | 是 / 否 |
| 是否需要客户验证 | 是 / 否 |
| 是否需要决策记录 | 是 / 否 |

## 影响矩阵

| 维度 | 检查问题 | 关联知识页 |
| --- | --- | --- |
| 产品端 | 影响运营端、贸易端、采集端还是公共能力？ | `docs/10-功能模块详情/README.md` |
| 业务对象 | 是否影响 FlowSpace、订单、里程碑、工单、资源库、模板、字段、附件？ | `docs/20-业务对象与数据模型/README.md` |
| 业务流程 | 是否改变创建、编辑、提交、批复、采集、同步、归档、导入导出？ | `docs/30-业务流程与产品流程图/README.md` |
| 权限 | 是否影响角色、协作团队、数据围栏、按钮权限、字段可见性？ | `docs/40-权限、安全与审计/权限体系总表.md` |
| 数据规则 | 是否涉及字段写入来源、引用关系、同步规则、历史数据和数据口径？ | `docs/20-业务对象与数据模型/字段、组件、子表、引用关系.md` |
| 通知自动化 | 是否影响消息、邮件、自动化、定时任务、执行记录？ | `docs/10-功能模块详情/自动化.md` |
| 报表指标 | 是否影响仪表盘、报告、统计口径、筛选维度、数据权限？ | `docs/60-数据分析支持/README.md` |
| 日志审计 | 是否需要操作日志、动态、历史记录、系统执行记录？ | `docs/40-权限、安全与审计/README.md` |
| 兼容迁移 | 是否影响旧模板、旧 FlowSpace、旧数据、移动端版本或客户已有配置？ | `docs/90-版本历史与来源治理/版本变更记录.md` |
| 测试验收 | 是否需要权限矩阵、异常边界、回归重点、历史 Bug 高发区？ | `docs/45-测试支持/README.md` |

## 拆分建议

| 情况 | 建议 |
| --- | --- |
| 只影响文案、展示、筛选，不改数据结构 | 可作为小需求或配置优化 |
| 影响字段、状态、权限或日志 | 进入 PRD，并补验收标准 |
| 影响多个产品端或历史数据 | 先做方案评审和技术预研 |
| 只服务单个客户且边界不稳定 | 先做客户配置/SOP，暂不产品化 |
| 涉及产品原则或长期方向 | 补决策记录，再进入需求池 |
