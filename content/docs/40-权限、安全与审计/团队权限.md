
# 团队权限

## 1. 功能定位

团队权限控制贸易端团队级配置和团队级资源入口，包括团队设置、团队成员、团队角色、协作团队、创建 FlowSpace、FlowSpace 分组、资源库创建与删除等能力。团队权限是 FlowSpace、资源库、仪表盘等后续权限的上层入口。

## 2. 权限主体

| 主体 | 说明 |
| --- | --- |
| 拥有者 | 固定角色，有且只有一名成员，默认为团队创建人，可在团队基本信息中移交，拥有团队角色内所有权限 |
| 团队管理员 | 固定角色，拥有团队角色内所有权限；不可删除，不可修改权限勾选，但可修改成员 |
| 自定义团队角色 | 团队内自定义角色，可配置成员和权限点 |
| 团队成员 | 加入或被邀请加入团队的账号，可同时拥有多个团队角色，权限叠加 |
| 协作团队 | 与当前团队建立协作关系的外部团队，可加入本团队创建的 FlowSpace 或资源库协作链路 |

## 3. 团队角色权限点

| 权限分类 | 权限名称 | 控制范围 |
| --- | --- | --- |
| 团队管理 | 团队设置 | 团队设置页面、邀请成员快捷入口、团队角色、团队成员、协作团队管理 |
| FlowSpace 管理 | 创建 FlowSpace | 工作台创建 FlowSpace |
| FlowSpace 管理 | 内部 FlowSpace 管理 | 查看和管理本团队创建的 FlowSpace 内订单、工单、仪表盘等全部数据；可配置 FlowSpace 设置、自动化、关联资源库、仪表盘权限 |
| FlowSpace 管理 | 协作 FlowSpace 设置 | 查看协作 FlowSpace 内本团队权限范围内的数据；可管理协作 FlowSpace 设置 |
| FlowSpace 管理 | FlowSpace 分组 | 工作台 FlowSpace 分组管理 |
| FlowSpace 管理 | FlowSpace 互通配置 | 团队设置 > FlowSpace 互通菜单；创建、编辑、发布、停用互通方案和查看历史版本 |
| 资源库管理 | 创建资源库 | 在当前团队下创建资源库 |
| 资源库管理 | 删除资源库 | 删除本团队下资源库，并可查看所有资源库数据 |
| 资源库管理 | 资源库设置 | 查看本团队资源库所有数据，管理资源库设置 |
| 资源库管理 | 协作资源库管理 | 管理本团队参与协作的资源库设置和主团队授权的数据操作权限 |

## 4. 成员管理规则

| 操作 | 规则 |
| --- | --- |
| 邀请成员 | 输入邮箱并设置团队角色；成员可为未注册账号；后续流程变更后，被邀请邮箱可立即成为团队成员 |
| 设置成员角色 | 可为成员设置多个团队角色；与团队角色列表数据双向同步 |
| 删除成员 | 成员从团队移除，同时从参与的 FlowSpace 中同步删除 |
| 重新邀请 | 未注册或未加入成员可重新发送邀请邮件 |
| 拥有者限制 | 拥有者不可删除，也无需设置团队角色 |

删除成员时，如果该成员是某些协作 FlowSpace 的唯一对接人，需要先设置其他对接人后再删除。被删除成员当前若仍在该团队上下文内，请求时应跳转到剩余团队选择页或首次创建团队引导页，并提示已被移出团队。

## 5. 协作团队管理规则

| 操作 | 规则 |
| --- | --- |
| 邀请协作团队 | 通过团队码识别对方团队；后续流程变更后，邀请团队后协作团队即加入当前团队作为协作方 |
| 协作团队列表 | 展示我邀请的团队、邀请我的团队、参与的 FlowSpace 等信息 |
| 删除协作团队 | 协作团队从团队中移除，同时从参与的 FlowSpace 中同步删除 |
| 邀请失效 | 协作团队被删除后，未处理的邮件链接失效 |

## 6. 权限叠加与失效

- 同一成员可以拥有多个团队角色，权限按并集叠加。
- 删除角色后，使用该角色的成员失去对应角色权限。
- 从团队删除成员，会同步影响 FlowSpace 成员、任务中心、消息跳转和相关可见数据。
- 从团队删除协作团队，会同步影响 FlowSpace 协作团队、协作任务和相关可见数据。

## 7. 审计要求

团队设置操作日志需要覆盖：

- 团队角色新增、编辑、删除。
- 成员管理新增、删除、设置权限。
- 协作团队管理新增、删除。

在角色中修改成员，仅记录在角色操作中；在成员中修改权限，仅记录在成员操作中。

## 8. 运营端功能权限配置

运营端团队列表新增 `功能权限` 入口，用于配置团队级或 FlowSpace 维度功能入口权限。V1.0 团队权限配置区仅作为占位，不提供具体配置项；FlowSpace 维度权限区用于配置 `自动化配置入口` 的授权成员。

自动化配置入口权限规则：

| 项目 | 规则 |
| --- | --- |
| 配置入口 | 运营端 > 团队管理 > 团队列表 > 功能权限 |
| 配置粒度 | 当前团队下的 FlowSpace |
| 授权对象 | 仅当前 FlowSpace 内部成员，不展示协作方成员 |
| 生效规则 | 成员列表为空即无权限；成员列表非空时，对应成员可见贸易端 FlowSpace 内自动化配置入口 |
| 保存规则 | 配置成员弹窗保存后立即生效，并记录配置日志 |
| 日志 | 记录操作人、类型、权限、变更前后成员，成员需保留邮箱便于追溯 |

贸易端不再提供 `自动化配置` 权限点的配置入口。FlowSpace 设置的业务角色权限不展示自动化配置勾选项，业务管理员默认角色也不可直接获得该权限；服务端也必须停止接受贸易端对该权限点的写入，旧接口提交该权限点时应忽略或返回不支持修改。

## 9. 待确认问题

- 团队角色完整权限矩阵仍依赖外部钉钉表格，建议导出为本地来源文件。
- 删除团队成员后的任务批量交接仍为后期规划，需要补充正式规则。
- 协作团队加入流程已发生优化，历史“接受/拒绝”流程是否仍在部分场景保留，需要与线上核对。
