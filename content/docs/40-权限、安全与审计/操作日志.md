# 设置操作日志

## 定位

设置操作日志用于追溯团队、FlowSpace、协作 FlowSpace、资源库等配置类功能的新增、编辑、删除和权限变更。它记录的是“配置被谁改了、改了什么、改前改后是什么”，区别于订单跟踪记录和工单动态。

## 适用范围

| 日志范围 | 记录对象 |
|---|---|
| 团队设置 | 基本信息、团队角色、成员管理、协作团队管理、FlowSpace 关联设置 |
| FlowSpace设置 | 基本信息、业务角色、协作方角色、数据围栏、成员管理、协作团队管理、计划时间、标签设置、订单标识设置、订单取消原因 |
| 协作FlowSpace设置 | 自建角色、主团队角色、成员管理 |
| 资源库设置 | 基本信息、权限管理 |

运营端模板修改不记录在贸易端 FlowSpace 设置、协作 FlowSpace 设置或资源库设置操作日志中。

## 列表查询

设置操作日志列表支持按操作对象、功能模块、操作类型、操作人和操作时间查询。

| 查询项 | 说明 |
|---|---|
| 模糊搜索 | 搜索操作对象 |
| 功能模块 | 取值参照各设置日志的记录内容 |
| 操作类型 | 新增、编辑、删除、设置权限 |
| 操作人 | 可选择日志列表中出现过的成员 |
| 操作时间 | 日期范围 |

列表数据中可点击快照查看对应操作的详细变更内容。

## 团队设置日志

| 模块 | 记录操作 |
|---|---|
| 基本信息 | 新增、编辑；新增指创建团队 |
| 团队角色 | 新增、编辑、删除；在角色中修改成员，仅记录在角色操作中 |
| 成员管理 | 新增、删除、设置权限 |
| 协作团队管理 | 新增、删除 |
| FlowSpace关联设置 | 新增、删除；仅记录主动新增或删除的 FlowSpace |

FlowSpace 被动关联或被动取消关联时，不在团队设置日志中记录。

## FlowSpace设置日志

| 模块 | 记录操作 |
|---|---|
| 基本信息 | 新增、删除；新增指创建 FlowSpace |
| 业务角色 | 新增、编辑、删除 |
| 协作方角色 | 新增、编辑、删除 |
| 数据围栏 | 新增、编辑、删除 |
| 成员管理 | 新增、删除、设置权限 |
| 协作团队管理 | 新增、删除、设置权限 |
| 计划时间 | 编辑 |
| 标签设置 | 新增、编辑、删除 |
| 订单标识设置 | 编辑 |
| 订单取消原因 | 新增、编辑、删除 |

从团队设置中删除成员或协作团队，导致其从 FlowSpace 中被删除时，FlowSpace 设置日志也记录一条删除记录。

## 协作FlowSpace设置日志

| 模块 | 记录操作 |
|---|---|
| 自建角色 | 新增、编辑、删除 |
| 主团队角色 | 编辑，仅能编辑主团队角色中的成员 |
| 成员管理 | 新增、删除、设置权限 |

主团队修改协作团队协作的里程碑，不记录在协作方 FlowSpace 的操作日志内。主团队修改或删除协作方角色，也不记录在协作方 FlowSpace 的操作日志内。

## 资源库设置日志

| 模块 | 记录操作 |
|---|---|
| 基本信息 | 新增、编辑；新增指创建资源库 |
| 权限管理 | 新增、编辑、删除 |

## 快照查看

快照用于查看某次配置操作当时的数据。

| 操作类型 | 快照规则 |
|---|---|
| 新增 | 仅展示新增当时的数据 |
| 删除 | 仅展示删除当时的数据 |
| 编辑 | 展示编辑前和编辑后的数据 |
| 协作团队增删 | 仅记录“我邀请的”团队增删，无快照 |

多层级内容需要通过气泡方式展示，例如业务角色或协作方角色的自定义订单范围规则、计划时间默认负责人规则、标签设置多语言、自建角色自定义订单范围等。
