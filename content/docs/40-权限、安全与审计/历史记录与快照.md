# 历史记录与快照

## 定位

历史记录用于查看订单主表单、工单、里程碑批复、资源库数据和邮件协作等实体在创建、编辑、采集、批复、导入、同步过程中的字段快照。它回答“某次修改前后字段值是什么”。

## 通用展示规则

历史记录通常由左侧操作记录和右侧历史快照组成。

| 区域 | 说明 |
|---|---|
| 编辑日志 | 展示创建、编辑、采集、批复、导入等操作 |
| 字段修改次数统计 | 统计字段被修改次数 |
| 历史快照 | 切换到当前选中操作记录对应的字段快照 |

快照差异标记：

| 差异 | 标记 |
|---|---|
| 本次新增内容 | 绿色 |
| 本次删除内容 | 红色 |
| 本次修改内容 | 原内容红色，新内容绿色 |
| 创建记录 | 不显示新增或删除标记 |

字段修改次数统计只统计创建以外的修改记录，并且变更前后值不一致才计数。排序按模板布局顺序，支持搜索字段。

## 订单主表单历史记录

订单主表单历史记录记录创建订单和编辑订单历史。

| 项目 | 规则 |
|---|---|
| 编辑日志 | 包括创建、编辑，按操作时间倒序 |
| 字段统计 | 统计主表单字段修改次数 |
| 快照 | 展示当前选中操作记录的主表单快照 |

订单导入新增或更新时，也会生成订单主表单历史记录。批量编辑订单时，被编辑订单主表单增加编辑历史记录。

## 工单历史记录

工单历史记录可从修改类动态后的“查看历史”进入，用于查看工单创建、采集、批复的历史快照。

| 项目 | 规则 |
|---|---|
| 编辑日志 | 包括创建、采集、批复，按操作时间正序 |
| 动态定位 | 从某条修改动态进入时，定位到对应菜单 |
| 字段统计 | 统计工单字段被修改次数 |
| 快照 | 展示当前选中操作记录的工单快照 |

采集提交、批复提交、导入工单、批量创建工单、自动化更新和外部 API 更新，都可能增加工单历史记录。

## 里程碑批复历史记录

里程碑批复历史记录规则同工单历史记录，主要记录里程碑批复创建、编辑、批复等操作。

自动化创建里程碑批复、更新里程碑批复，或外部 API 同步创建、更新里程碑批复时，也会增加对应历史记录。

## 资源库数据历史记录

资源库数据列表中，每条数据增加“历史记录”查看按钮。可见该条数据的人都可以查看历史记录。

| 项目 | 规则 |
|---|---|
| 查看权限 | 可见该条资源库数据的人可查看 |
| 排序 | 按操作时间正序 |
| 默认查看 | 点击历史记录按钮后默认查看最新一条记录 |
| 游客操作 | 增加分享人信息 |

资源库导入新增或修改、手动编辑资源库数据、分享链接中的游客编辑等，都应形成可追溯历史。

## 邮件协作历史记录

邮件协作历史记录记录邮件协作者提交数据的历史。发出邮件时不记录历史，提交数据时记录。

运营端邮件协作列表中的历史记录，列表和操作规则同贸易端。

## 系统来源快照

系统来源写入历史记录时，应明确操作人和操作文案。

| 来源 | 操作人 | 典型文案 |
|---|---|---|
| 公式自动更新 | 系统 | 自动更新 |
| 自动化更新 | 自动化 | 更新订单、创建工单、更新工单、更新工单批复、创建里程碑批复、更新里程碑批复 |
| 外部API同步 | 来源标识或对应操作人 | 创建订单、编辑订单、创建工单、编辑工单、编辑工单批复、编辑里程碑批复 |

快照仍需展示更新前后字段值，并用红色和绿色标出差异。
