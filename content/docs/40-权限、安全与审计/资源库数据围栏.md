
# 资源库数据围栏

## 1. 功能定位

资源库数据围栏是在资源库表级操作权限和行级数据范围基础上增加的列级可见权限，用于限制成员、协作团队查看资源表中的敏感列，并统一作用于资源库页面、数据出口、外部分享和 FlowSpace 引用。

本期不包含单元格级权限、字段脱敏、FlowSpace 现有数据围栏改造、权限变更通知。隐藏列不展示字段名及字段值。

## 2. 管理权限

| 角色 | 权限 |
| --- | --- |
| 团队层面资源库管理员 | 管理全部资源库的数据围栏 |
| 拥有当前资源库设置权限的成员角色 | 管理当前资源库的数据围栏 |
| 协作方角色、协作资源库普通成员、其他成员 | 不展示入口；地址访问提示“暂无权限，请联系管理员” |

管理包括查看、新增、编辑、删除数据围栏。服务端必须再次校验权限。

## 3. 围栏配置

| 配置项 | 规则 |
| --- | --- |
| 围栏名称 | 必填，最多 100 字符 |
| 资源表 | 必填，单选当前资源库内正常资源表 |
| 限制成员 | 选填，多选本团队成员，可包含未注册成员 |
| 限制协作团队 | 选填，多选与本团队仍有效的协作团队，包括邀请我的和我邀请的团队；限制字段作用于该团队全部成员 |
| 不可查看列 | 必填，新增时默认不选；至少 1 列；仅展示所选资源表当前有效业务列，支持按模块分组全选 |

保存时校验管理权限、资源表、成员、团队及字段有效性。资源表失效、成员移出团队、协作关系解除、字段删除等场景需阻止保存或自动移除失效字段。

## 4. 权限计算

```text
用户可访问数据 = 表级操作权限 ∩ 行级数据范围 ∩ 列级数据围栏
有效可见列 = 当前有效列 - 用户命中的全部不可查看列
```

规则：

1. 数据围栏只收窄列范围，不授予表、行或操作权限。
2. 同一用户命中多个围栏时，不可查看列取并集。
3. 协作团队围栏作用于该团队全部成员。
4. 资源库管理员本人也可被限制；但有围栏管理权限的用户在围栏配置页可看到全部字段名，以便完成配置。
5. 有资源表查看权限但有效可见列为空时，保留资源表入口和记录数，内容区展示“暂无可查看字段”。

## 5. 页面与数据出口影响

列权限必须由服务端统一过滤，不能只在前端隐藏。

| 功能面 | 规则 |
| --- | --- |
| 列表、详情 | 不返回隐藏列名、列值及空占位；关联引用控件来源被围栏限制的字段也不显示 |
| 新增、编辑、批量编辑 | 不展示隐藏列；提交其他列时不得覆盖隐藏列原值 |
| 模糊查询、筛选、排序、列设置 | 不提供隐藏列；已保存视图中的相关条件失效，且不暴露字段名和值 |
| 统计 | 不返回隐藏列统计结果 |
| 附件、历史记录 | 附件列隐藏时不可查看/下载或批量下载；历史记录不展示隐藏列新旧值及差异 |
| 导出 | 字段选择和文件内容均排除隐藏列 |
| 导入 | 字段匹配、预览不展示隐藏列；导入其他列时不校验、不修改隐藏列 |

## 6. 外部分享列权限

单条数据分享、整表分享均增加“分享列权限”。

```text
外部实际可见列 = 本次分享可见列 ∩ 分享者实时有效可见列 ∩ 当前有效列
```

| 场景 | 规则 |
| --- | --- |
| 可选范围 | 仅返回分享者当前有效可见列，不返回被围栏隐藏的字段名 |
| 首次创建 | 默认所有可分享字段都勾选为“分享可见” |
| 保存校验 | 至少保留 1 个可见字段 |
| 搜索/全选 | 仅作用于当前可选列，不得命中隐藏列 |
| 编辑分享 | 返回当前仍有效且当前用户可见的列；删除或暂不可见的列不返回，也不可重新选择 |
| 实际访问 | 分享创建、预览、外部访问、搜索、筛选、排序、统计、详情、导出、下载、编辑提交时均按最新权限计算 |

分享方式由编辑时实时同步改为需点击保存才生效。分享链接管理列表允许编辑本人创建的链接；关闭分享仍按删除处理，只允许在列表中操作。

## 7. 默认、变更与兼容

1. 未配置围栏的存量资源库默认全部列可见。
2. 新增资源表字段在平台内默认可见，但不自动加入已有外部分享。
3. 新成员加入受限协作团队后自动命中团队围栏；本团队成员级围栏需单独配置。
4. 权限变更服务端立即生效；已打开页面在刷新、翻页、导出、提交时按最新权限重新校验。
5. 资源库数据编辑、删除及外部分享编辑触发的订单同步，继续遵循既有同步范围和失效规则。

## 8. 验收重点

1. 数据围栏可按资源表配置成员、协作团队和不可查看列。
2. 多围栏命中时隐藏列按并集生效，且不改变表级、行级和操作权限。
3. 列表、详情、编辑、视图、搜索、统计、附件、历史、导入、导出和用户身份接口结果一致，响应及文件不包含隐藏值。
4. 编辑、导入或外部提交可见列时，不覆盖隐藏列原值。
5. 单条和整表分享均可单独选择分享列；隐藏字段名不出现在可选项、搜索结果或提示中。
6. 外部实际可见列符合三项交集；权限变化、字段新增/重命名/删除和空列状态符合规则。
7. 存量分享的初始分享列等于上线时分享者当前有效可见列，不突破新围栏。
