# 订单跟踪记录

## 定位

订单跟踪记录是订单级业务过程日志，用于追踪订单、里程碑、工单、翻单、订单关联、FlowSpace 关联等关键业务节点。它回答“这个订单经历了哪些关键事件”。

## 查看权限

只有拥有当前订单“查看跟踪记录”权限的成员，才能在订单详情中看到跟踪记录入口并查看内容。

## 记录字段

每条跟踪记录至少包含：

| 字段 | 说明 |
|---|---|
| 操作人 | 头像、姓名；系统执行时可为系统、自动化或第三方来源 |
| 操作时间 | 事件发生时间 |
| 事件 | 按操作类型生成的记录文案 |

排序按操作时间正序。

## 订单操作

| 操作 | 触发页面 | 记录文案 |
|---|---|---|
| 创建订单 | 订单列表创建订单、导入订单 | `$操作人 创建订单` |
| 编辑订单 | 订单列表、订单详情、批量编辑、导入更新 | `$操作人 编辑订单` |
| 删除订单 | 订单详情、订单列表 | `$操作人 删除订单` |
| 完成订单 | 订单详情、订单列表批量修改状态 | `$操作人 完成订单` |
| 取消订单 | 订单详情、订单列表批量修改状态 | `$操作人 取消订单` |
| 重启订单 | 订单详情、订单列表批量修改状态 | `$操作人 重启订单` |

订单完成、取消、重启后，均增加跟踪记录。

## 里程碑与工单操作

| 操作 | 触发页面 | 记录文案 |
|---|---|---|
| 里程碑开始 | 首次创建工单、批量创建工单、导入工单 | `$操作人 创建工单 $工单名称，$里程碑名称 开始` |
| 创建工单 | 订单详情、批量创建工单、导入工单 | `$操作人 在 $里程碑名称 创建工单 $工单名称` |
| 删除工单 | 订单详情 | `$操作人 删除 $里程碑名称 的工单 $工单名称` |
| 完成里程碑 | 订单详情、批量修改里程碑状态 | `$操作人 完成里程碑 $里程碑名称` |
| 取消里程碑 | 订单详情、批量修改里程碑状态 | `$操作人 取消里程碑 $里程碑名称` |
| 重启里程碑 | 订单详情、批量修改里程碑状态 | `$操作人 重启里程碑 $里程碑名称` |
| 移交订单负责人 | FlowSpace 管理 > 数据移交 | `$执行人 已将订单负责人从 $原负责人 移交给 $新负责人。移交原因：XXXX。备注：xxxx` |
| 移交里程碑负责人 | FlowSpace 管理 > 数据移交 | `$执行人 已将 $里程碑名称 负责人从 $原负责人 移交给 $新负责人。移交原因：XXXX。备注：xxxx` |

首次创建工单时，如果里程碑从未开始进入进行中，需要同时记录里程碑开始。

## 订单复用关系

### 里程碑互用

里程碑互用会在原单和被互用单分别增加跟踪记录。

| 场景 | 记录口径 |
|---|---|
| 原单 | `$操作人 将 $里程碑名称 互用于 $被互用的订单标识...` |
| 被互用单 | `$操作人 将 $原单订单标识 中的 $里程碑名称 互用于此订单` |
| 原单取消互用 | `$操作人 将 $里程碑名称 取消互用于 $被互用的订单标识` |
| 被互用单取消互用并保留数据 | `$操作人 取消 $原单订单标识 中的 $里程碑名称 互用于此订单，并保留了数据` |
| 被互用单取消互用并清空数据 | `$操作人 取消 $原单订单标识 中的 $里程碑名称 互用于此订单，并清空了数据` |

### 翻单

| 场景 | 原单记录 | 翻单记录 |
|---|---|---|
| 创建新订单为翻单 | `$操作人 创建 $翻单订单标识 为此订单的翻单` | `$操作人 创建此订单为 $原单订单标识 的翻单` |
| 设置已有订单为翻单 | `$操作人 设置 $翻单订单标识 为此订单的翻单` | `$操作人 设置此订单为 $原单订单标识 的翻单` |
| 取消翻单 | `$操作人 取消 $翻单订单标识 作为此单的翻单` | `$操作人 取消此订单作为 $原单订单标识 的翻单` |

### 订单关联与FlowSpace关联

| 操作 | 记录文案 |
|---|---|
| 订单关联 | `$操作人 建立与 $订单标识 关联` |
| 取消订单关联 | `$操作人 取消与 $订单标识 关联` |
| FlowSpace关联 | `$操作人 建立与 $FlowSpace名称 中的 $订单标识 关联` |
| 取消FlowSpace关联 | `$操作人 取消与 $FlowSpace名称 中的 $订单标识 关联` |

## 系统来源记录

系统、自动化、第三方 API 也可能写入订单跟踪记录。系统来源需要在操作人位置清晰标识，常见来源包括：

| 来源 | 记录场景 |
|---|---|
| 公式自动更新 | 主表单公式字段更新时记录 |
| 自动化 | 主表单更新、首次创建工单、创建工单、订单状态变更、里程碑状态变更 |
| 外部API | 外部系统创建或更新订单、创建或删除工单 |
