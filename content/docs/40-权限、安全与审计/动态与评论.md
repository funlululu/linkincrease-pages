# 动态与评论

## 定位

动态是工单和里程碑批复级别的过程记录，用于展示采集、批复、指派、修改处理人、终止采集、互用、评论等事件。动态同时承担协作评论入口和未读角标提示。

## 动态类型

| 类型 | 说明 |
|---|---|
| 修改 | 创建工单、采集工单、批复工单、创建或编辑里程碑批复等 |
| 评论 | 成员在工单或里程碑批复动态中发表评论 |
| 其他 | 指派、修改处理人、终止采集、工单互用、取消互用等 |

动态按操作时间正序排序。

## 工单动态

有工单动态的页面包括查看工单、工单采集、工单批复。动态按钮数字角标表示当前成员上次打开这些页面之后新增的评论数。

### 参与人

工单动态参与人包括：

1. 工单发起人。
2. 采集人。
3. 批复人。
4. 里程碑批复人。

对接人或负责人未指派时，处理人头像显示协作团队头像；已指派后展示对应协作成员头像并增加协作标识。已提交的采集人、批复人头像展示已提交标识。

### 过滤

| 过滤项 | 说明 |
|---|---|
| 所有 | 展示所有类型动态 |
| 仅评论 | 只展示评论类动态，默认过滤该项 |
| 仅修改历史 | 只展示修改表单类型动态，此类动态可查看编辑历史记录 |

### 典型记录

| 操作 | 动态文案 |
|---|---|
| 创建工单 | `$操作人 创建了工单` |
| 导入工单 | `$操作人 导入工单` |
| 采集工单或修改工单采集部分 | `$操作人 编辑了工单` |
| 批复工单 | `$操作人 批复了工单，工单无法继续编辑` |
| 协作方指派采集 | `$操作人 将工单任务指派给 $被指派人...` |
| 协作方指派批复 | `$操作人 将工单批复任务指派给 $被指派人...` |
| 修改采集人 | `$操作人 将工单任务处理人修改为 $修改后成员...` |
| 修改批复人 | `$操作人 将工单批复人修改为 $修改后成员...` |
| 终止采集 | `$操作人 终止采集，工单无法继续编辑` |
| 工单互用于 | `$操作人 将此工单互用于 $订单标识` |
| 取消互用 | `$操作人 取消 $订单标识 互用此工单` |

修改处理人前后不一致时才记录。

## 里程碑批复动态

有里程碑批复动态的页面为查看里程碑批复。动态按钮数字角标表示当前成员上次打开页面之后新增的评论数。

### 参与人

里程碑批复动态参与人包括发起人和里程碑批复人。协作团队未指派时展示协作团队头像；已指派后展示具体协作成员头像并增加协作标识。

### 典型记录

| 操作 | 动态文案 |
|---|---|
| 创建里程碑批复 | `$操作人 创建了里程碑批复` |
| 里程碑批复 | `$操作人 编辑了里程碑批复` |
| 协作方指派里程碑批复 | `$操作人 将里程碑批复任务指派给 $被指派人...` |
| 修改里程碑批复人 | `$操作人 将里程碑批复人修改为 $修改后成员...` |
| 协作方修改批复指派 | `$操作人 将其团队的里程碑批复人修改为 $被指派人...` |

## 评论与通知

评论支持 @ 成员、@ 团队和 @ 所有参与者。

| @对象 | 通知规则 |
|---|---|
| @成员 | 仅通知对应成员 |
| @团队 | 通知该团队下参与当前工单或里程碑批复的成员 |
| @所有参与者 | 当前工单或里程碑批复的所有参与成员都收到消息和邮件 |
| 不@成员 | 不发送通知，仅在详情页面动态按钮上显示未读角标 |

成员支持按姓名或邮箱模糊搜索；团队支持按团队名称或简称模糊搜索。

工单评论可 @ 工单发起人、当前采集人、当前工单批复人、里程碑批复人，以及这些身份所属团队。里程碑批复评论可 @ 发起人、当前里程碑批复人及相关团队。

## 采集端一致性

采集端任务详情页中的工单动态和里程碑批复动态，数据与操作规则同贸易端。采集端参与评论、查看动态时，应复用同一套动态记录和未读角标规则。
