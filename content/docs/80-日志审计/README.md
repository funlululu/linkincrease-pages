## 审计分类

- 设置操作日志：团队、FlowSpace、协作 FlowSpace、资源库等配置变更。
- 订单跟踪记录：订单级关键业务节点。
- 动态与评论：工单、里程碑批复的协作过程和评论。
- 历史记录与快照：字段级变更前后快照。
- 系统与集成执行日志：公式、自动化、外部 API、软件更新等系统来源记录。
