# 10 产品端

本目录按产品端沉淀 Linkincrease 的端侧定位、职责边界、主要模块和跨端数据关系。

## 页面

| 页面 | 用途 |
| --- | --- |
| [运营端](./运营端.md) | 平台配置、模板、监管、集成、软件管理和运营后台能力总览 |
| [贸易端](./贸易端.md) | 客户团队业务协同主平台能力总览 |
| [采集端](./采集端.md) | 移动任务、采集、批复、消息和个人中心能力总览 |
| [三端数据关系](./三端数据关系.md) | 梳理运营端、贸易端、采集端之间的数据主从、流转和权限边界 |
| [账号与个人中心](./账号与个人中心.md) | 统一注册、登录、忘记密码、个人信息、多语言、退出账号和采集端我的 |

## 维护原则

1. 单端菜单和入口写在本目录。
2. 跨端共同对象写入 `20-业务对象/`。
3. 跨端流程写入 `30-业务流程/`。
4. 权限、日志、通知、自动化、导入导出等横向能力应同步写入对应目录。
