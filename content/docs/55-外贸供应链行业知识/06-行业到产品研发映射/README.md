# 06 行业到产品研发映射

本分区面向产品、测试和研发，集中维护行业场景与 Linkincrease 业务对象、产品能力、数据规则、测试重点和产品差距之间的关系。

这里的映射用于帮助产品研发理解“行业为什么需要这项能力”以及“产品模型是否足以承载真实业务”。客户配置和业务方案应继续进入运营支持知识，不能用推荐方案覆盖已确认产品规则。

## 通用映射

| 行业业务概念 | Linkincrease 承载方式 |
| --- | --- |
| 稳定、可复用的主数据 | 资源库 |
| 重复执行的业务流程 | 业务模板、FlowSpace |
| 一次业务实例 | 订单 |
| 流程阶段 | 里程碑 |
| 资料提交、现场执行或协作任务 | 工单 |
| 审核、确认或放行决策 | 工单批复、里程碑批复 |
| 外部企业参与 | 协作团队 |
| 业务职责 | FlowSpace 业务角色 |
| 数据可见范围 | 数据围栏、资源库数据范围 |
| 提醒和数据更新 | 自动化、消息通知 |
| 经营监控 | 仪表盘、报告 |
| 过程追溯 | 动态、历史记录、操作日志 |
