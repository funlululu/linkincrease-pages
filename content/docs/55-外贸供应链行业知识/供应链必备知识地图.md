# 供应链必备知识地图

本页定义产品、测试、研发和产品成功理解外贸供应链时需要掌握的知识范围。目标不是培养每个人成为采购、生产、物流或关务专家，而是建立能够正确识别业务对象、流程、规则、风险、系统边界和产品机会的共同基础。

## 1. 掌握层级

| 层级 | 要求 |
| --- | --- |
| L0 识别 | 知道术语和业务环节是什么，能够识别客户正在讨论的场景 |
| L1 理解 | 能说明角色、对象、流程、状态、风险和主要单据 |
| L2 建模 | 能将业务拆成主数据、流程数据、权限、状态、任务和指标 |
| L3 方案 | 能结合 Linkincrease 能力边界输出配置或产品方案 |

产品和测试应至少达到重点场景的 L2；负责场景方案的产品成功应达到 L2 至 L3；研发至少需要理解所开发模块对应场景的 L1 至 L2。

## 2. 供应链全局与运营模型

必须掌握：

- 供应链从需求、计划、采购、生产、质量到交付和结算的端到端关系。
- 信息流、实物流和资金流的区别及相互影响。
- 计划、订单、寻源、生产、履约、退货和治理等过程域。
- 供应链优化中的成本、交期、质量、库存、风险和服务水平权衡。
- 局部效率提升可能造成全链路问题，例如赶工提高成本、库存降低造成缺料风险。

产品价值：

- 避免把供应链理解成单一订单列表。
- 判断一个需求属于协同、主数据、专业执行还是分析能力。
- 识别 Linkincrease 与 ERP、MES、WMS、TMS、QMS、PLM 等系统的边界。

## 3. 组织、角色与商业关系

必须掌握：

- 品牌方、进口商、客户、贸易公司、采购办公室和 Sourcing Agency 的区别。
- 供应商、工厂、分包工厂之间可能是一对多、多对多或动态关系。
- QC、审核、实验室、货代、承运人、报关行和仓库的职责。
- 商业责任、执行责任、审核责任和最终决策责任可以属于不同角色。
- 同一企业在不同业务中可能承担不同角色。

产品价值：

- 支撑组织、协作团队、业务角色、处理人和数据围栏设计。
- 避免把供应商账号、工厂主体和联系人混为同一对象。

## 4. 业务对象与主数据

必须掌握：

- 客户、供应商、工厂、产品、款式、SKU、物料、证书和服务商等主数据。
- 询价、报价、合同、订单、订单行、生产批次、出货批次等过程对象。
- 主数据与交易快照的区别：历史订单不能随主数据变化而失真。
- 唯一标识、版本、有效期、归属、状态和对象关系。
- 主表与明细、一对多、多对多、引用与复制的区别。

产品价值：

- 支撑资源库、FlowSpace、订单、工单和字段引用的数据建模。
- 识别重复主体、历史快照、同步覆盖和跨流程关联风险。

## 5. 计划、订单与变更

必须掌握：

- 预测、销售订单、采购计划、采购订单和生产计划之间的关系。
- 订单头与订单行、产品数量、价格、交期和交付批次。
- 订单确认、变更、拆分、合并、取消、重启和结案。
- 请求交期、承诺交期、计划完成日、实际完成日和出货日的区别。
- 订单变更对物料、生产、质量、物流、成本和付款的连锁影响。

产品价值：

- 支撑订单生命周期、里程碑、批量操作、历史记录和变更审计设计。
- 建立延期、准时交付和 OTIF 等指标的正确时间口径。

## 6. 采购与供应商管理

必须掌握：

- 供应市场调查、供应商寻源、RFI/RFQ、报价、比价、谈判和定点。
- 供应商与工厂准入、试单、分级、绩效、复审、暂停和淘汰。
- 商务、产能、交付、质量、成本、财务、合规和协同评价维度。
- 单一来源、多来源、备选供应商和供应集中度风险。
- 供应商承诺与实际生产工厂执行之间的责任关系。

产品价值：

- 支撑供应商生命周期、询报价、审批、绩效和风险场景设计。

## 7. 产品开发、物料与生产

必须掌握：

- 产品、款式、SKU、规格、BOM、物料和包装要求。
- 样品类型、样品版本、确认意见和量产转换。
- 产能、生产计划、物料齐套、开工、完工和生产批次。
- 关键生产节点、进度百分比和异常上报不等于真实产出。
- 规格或订单变更对物料、工艺和生产计划的影响。

产品价值：

- 支撑样品开发、生产里程碑、进度采集、版本和异常协同设计。
- 明确 Linkincrease 可做过程协同，但不一定承担精细生产排程和库存核算。

## 8. 质量管理与合规

必须掌握：

- 来料检验、过程检验、成品检验、装运前验货等质量环节。
- 检验标准、抽样、AQL、严重/主要/次要缺陷及结果判定。
- 不合格、返工、复验、让步接收、拒收和放行。
- 工厂审核、社会责任审核、证书、测试报告和有效期。
- CAP 的问题、根因、纠正措施、预防措施、责任人、期限、证据和复核。
- 产品批次、供应商和工厂的追溯关系。

产品价值：

- 支撑验货组件、工单、批复、问题库、CAP、附件和审计设计。

## 9. 外贸交易条件、物流与单据

必须掌握：

- Incoterms 用于划分交付地点、责任、成本和风险，但不替代完整销售合同。
- 运输方式、订舱、截单、装柜、开船、到港、清关和交付等节点。
- 商业发票、装箱单、提单、原产地证、保险单、报关资料等常见单据。
- 订单、出货批次、箱、运输单和贸易单据之间的数量与关联关系。
- 报关、清关、制裁、出口管制和目的国要求具有专业性和地区差异。

产品价值：

- 支撑出货节点、单据收集、截止时间、协作任务和异常提醒。
- 明确 Linkincrease 可以管理协同和资料，但不应默认替代专业报关或运输执行系统。

## 10. 付款、成本与结算

必须掌握：

- 预付款、赊销、信用证、托收等常见付款安排的基本差异。
- 订单金额、费用、税费、运费、保险、索赔和退款。
- 订单、收货、验货、发票和付款之间需要核对。
- 汇率、信用、单据不符和付款延迟风险。

产品价值：

- 帮助识别资金字段、审批、单据和状态需求。
- 明确财务记账、资金支付和信用证专业处理通常属于外部系统边界。

## 11. 风险、韧性与负责任供应链

必须掌握：

- 供应中断、产能、质量、交付、物流、信用、汇率、合规和地缘风险。
- 风险发生概率、影响、暴露订单、应对措施和责任人。
- 供应商分层、多来源、备选方案和业务连续性。
- 人权、劳工、环境、反腐败等供应链尽职调查的基本逻辑。
- 风险监控不能只保存一个静态等级，应关联证据、时间和业务影响。

产品价值：

- 支撑风险字段、预警、审批、仪表盘、审计和供应商治理设计。

## 12. 指标与决策

必须掌握：

- 交付：OTIF、准时交付率、延期天数、订单周期。
- 质量：验货通过率、缺陷率、返工率、投诉和质量成本。
- 供应商：准入周期、报价响应、交付、质量、协同和风险评分。
- 整改：CAP 按期关闭率、平均关闭周期、重复问题率。
- 计划：预测准确率、计划达成率、产能负荷和缺料影响。
- 物流：准时出货、准时到货、运输异常和单据准确率。

每个指标都必须回答：

1. 用于什么管理决策。
2. 统计对象和时间范围是什么。
3. 分子、分母和排除项是什么。
4. 数据来自哪里，由谁维护。
5. 指标异常后采取什么动作。

## 13. 建议学习和建设顺序

| 阶段 | 知识重点 | 对应场景 |
| --- | --- | --- |
| 第一阶段 | 角色、主数据、订单、交期、质量、风险 | 准入、订单跟踪、验货、CAP |
| 第二阶段 | 寻源、样品、生产、出货和单据 | 询报价、样品开发、生产协同、出货协同 |
| 第三阶段 | 计划、库存、物流、结算和韧性 | 预测、齐套、运输、对账、供应链风险 |

首批建设应优先选择与 Linkincrease 产品能力和现有客户问题联系最紧密的场景，再逐步扩展到需要外部系统集成的领域。
