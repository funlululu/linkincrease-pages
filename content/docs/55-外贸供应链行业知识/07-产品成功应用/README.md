# 07 产品成功应用

本分区帮助产品成功经理在不改变产品权威规则的前提下，使用行业知识完成客户沟通、场景诊断、能力边界判断和业务方案输出。

产品成功是本知识库的重要使用者，但不是行业知识层的唯一或主要维护目标。产品能力边界必须引用产品权威页；无法确认的能力不得对客户承诺。

## 使用路径

```text
识别客户类型和业务场景
-> 使用行业知识理解角色、对象、流程和风险
-> 使用诊断清单补齐客户现状
-> 对照产品能力边界
-> 引用运营支持区的配置方案
-> 输出客户业务方案及待确认事项
```
