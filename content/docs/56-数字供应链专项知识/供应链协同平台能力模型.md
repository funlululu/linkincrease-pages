# 供应链协同平台能力模型

## 1. 定位

供应链协同平台的核心价值是让多个组织围绕同一业务对象和流程协作：有人提交资料，有人审核，有人现场执行，有人看风险和结果。它不是单一内部管理系统，而是连接品牌方、贸易公司、供应商、工厂、服务商和管理层的协同层。

## 2. 能力模型

| 能力 | 解决的问题 | Linkincrease 对应能力 |
| --- | --- | --- |
| 对象建模 | 知道业务围绕哪些对象运转 | 资源库、订单、FlowSpace |
| 流程编排 | 知道从发起到关闭怎么走 | 业务模板、里程碑、工单、批复 |
| 外部协作 | 让供应商/工厂/服务商参与 | 协作团队、邮件协作、采集端 |
| 权限隔离 | 防止越权查看和误操作 | 角色权限、数据围栏、字段显隐 |
| 数据采集 | 收集现场、附件、表单和证据 | 工单、附件、采集端、图片编辑 |
| 自动化提醒 | 减少人工催办和遗漏 | 自动化、消息通知、定时任务 |
| 审计追溯 | 保留过程证据和责任 | 动态、历史记录、操作日志 |
| 可视化分析 | 让管理层看到进度、异常和风险 | 仪表盘、报告、跨 FlowSpace 数据 |
| 复盘沉淀 | 将经验转为可复用资产 | 客户样本、FAQ、SOP、Skill |

## 3. 场景到能力组合

| 场景 | 能力组合 |
| --- | --- |
| 供应商/工厂准入 | 资源库 + 准入 FlowSpace + 审核工单 + 批复 + 权限 + 看板 |
| 订单履约跟踪 | 订单 + 里程碑 + 工单 + 自动化 + 仪表盘 |
| QC 验货 | 验货工单 + 采集端 + 附件 + 批复 + 异常跟进 |
| 出货单证 | 出货里程碑 + 单证工单 + 附件 + 批复 + 到期提醒 |
| 绩效风险 | 资源库 + 跨 FlowSpace 数据 + 指标口径 + 仪表盘 + 改善工单 |

## 4. 方案设计顺序

1. 明确业务目标和适用场景。
2. 找出主数据和流程数据。
3. 设计 FlowSpace、里程碑和工单。
4. 设计角色、权限和数据围栏。
5. 设计自动化提醒和异常升级。
6. 设计仪表盘和指标口径。
7. 设计上线试点和复盘机制。

## 5. 常见误区

| 误区 | 风险 | 正确做法 |
| --- | --- | --- |
| 先做大屏 | 数据不可信 | 先统一对象、字段和状态 |
| 先做自动化 | 误触发、漏触发 | 先确认流程和字段规则 |
| 所有异常都 CAP | 流程过重 | 设置 CAP 触发边界 |
| 外部协作直接开放全部数据 | 数据泄露 | 先设计协作团队和数据围栏 |
| 一套模板覆盖所有客户 | 适配困难 | 沉淀场景模式和配置变体 |
