# Linkincrease 知识库目录

本目录承载 Linkincrease 的标准知识库正文。当前结构按“产品阅读入口 + 权威规则层 + 运营/分析/维护/架构支撑”组织，既方便产品成员阅读，也保留业务对象、流程、权限、数据和审计的权威沉淀。

## 阅读建议

1. 新成员先读 [产品能力地图](./00-产品总览与规划/产品能力地图.md) 和 [功能模块详情](./10-功能模块详情/README.md)。
2. 写需求时先定位功能模块，再进入业务对象、业务流程、权限审计、数据分析页面校验影响范围。
3. 涉及 FlowSpace、订单、工单、批复、资源库、字段写入或同步时，必须先读 [FlowSpace 数据层级](./20-业务对象与数据模型/FlowSpace数据层级.md)。
4. 测试验收、权限矩阵、异常边界和回归重点进入 [测试支持](./45-测试支持/README.md)。
5. 运营、客户配置和最佳实践进入 [运营支持知识](./50-运营支持知识/README.md)。
6. 指标、仪表盘、报表和统计口径进入 [数据分析支持](./60-数据分析支持/README.md)。
7. 尚未确认的历史资料、客户反馈或需求候选，不直接写入权威规则页，先进入来源治理、产品维护或待确认问题。
