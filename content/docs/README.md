# Linkincrease 标准知识库目录

本目录承载拆分后的正式知识页。根目录保留总览、规范和索引；`docs/` 按标准知识库结构组织可长期维护的内容。

## 目录

| 目录 | 内容 |
| --- | --- |
| `00-入门/` | 产品总览、术语、功能地图、产品战略、用户角色、指标路线图、阅读路径 |
| `10-产品端/` | 运营端、贸易端、采集端说明 |
| `20-业务对象/` | 用户、团队、FlowSpace、订单、里程碑、工单、资源库等对象 |
| `30-业务流程/` | 从模板到 FlowSpace、订单生命周期、工单采集批复、资源库同步等流程 |
| `40-权限与安全/` | 团队、FlowSpace、协作方、资源库、数据围栏、报告、仪表盘权限 |
| `50-模板表单与数据/` | 业务模板、资源库模板、表单组件、公式、验货组件 |
| `60-协作通知与自动化/` | 消息、邮件协作、自动化、定时任务、外部 API |
| `70-展示分析/` | 工作台、常用视图、订单日程、仪表盘、报告 |
| `80-日志审计/` | 操作日志、动态、历史记录、跟踪记录、系统自动日志 |
| `90-来源与待办/` | 来源映射、待确认问题、入库状态 |
