# 仪表盘管理与设计器

## 定位

仪表盘用于在 FlowSpace 内配置统计分析页面，帮助用户快速监控订单动态、业务进度和关键指标。运营端负责仪表盘配置和设计，贸易端根据权限查看仪表盘数据。

## 管理入口

运营端 FlowSpace 列表增加仪表盘数量字段和仪表盘管理入口。

| 能力 | 规则 |
|---|---|
| 仪表盘数量 | 统计对应 FlowSpace 添加的仪表盘数量 |
| 仪表盘管理 | 可进入当前 FlowSpace 的仪表盘管理页面 |
| 添加仪表盘 | 仪表盘名称必填，限制 100 字符 |
| 修改名称 | 可修改仪表盘名称，限制 100 字符 |
| 删除仪表盘 | 需要二次确认 |
| 排序 | 支持拖动排序 |
| 国际化 | 仪表盘名称支持国际化 |

## 数据源

仪表盘数据源来自 FlowSpace 的订单信息、里程碑、工单批复等表结构，并可扩展公式字段。

| 数据源 | 字段范围 |
|---|---|
| 订单信息 | 订单信息字段、里程碑批复字段，排除所有子表字段 |
| 订单信息子表 | 订单信息字段、子表字段 |
| 里程碑 | 订单列表字段、里程碑字段、工单批复字段，排除所有子表字段 |
| 里程碑子表 | 订单列表字段、里程碑字段、子表字段 |
| 工单批复子表 | 订单列表字段、里程碑字段、工单批复字段、子表字段 |

如果主表单或里程碑批复包含子表，则订单信息或里程碑会作为分组名，分组下展示对应字段和所有子表。

### 公式字段

仪表盘支持添加、编辑、删除公式字段。

| 配置 | 规则 |
|---|---|
| 公式名称 | 必填，限制 100 字符 |
| 公式类型 | 必填，默认数字；支持数字、文本、百分比、日期 |
| 订单信息公式变量 | 订单信息、订单信息子表、所有里程碑、所有里程碑子表，排除图片、附件、签名、富文本字段 |
| 子表公式变量 | 当前子表字段 |
| 删除 | 需要二次确认 |

## 仪表盘设计器组件

仪表盘由布局组件、工具组件、图表组件和特殊图表组成。

| 类型 | 组件 |
|---|---|
| 布局组件 | 模块分组、标题、标签卡 |
| 工具 | 筛选器 |
| 图表 | 指标卡、柱状图、折线图、条形图、饼图、组合图、面积图、雷达图、统计表、透视表 |
| 特殊图表 | 里程碑状态 |

所有组件通常支持标题、提示描述和国际化。可国际化内容一般包括标题、提示描述，部分图表还包括指标名称。

## 图表通用配置

大多数图表具备类似的数据配置模型：

| 配置 | 说明 |
|---|---|
| 数据源 | 从数据表列表选择，默认订单信息 |
| 筛选设置 | 可对数据源字段设置筛选条件，并显示已设置条件数量 |
| 维度 | 按字段分组统计，日期字段可选年月日、年周、年月、年季、年等格式 |
| 指标 | 可添加多个数据源字段或自定义公式字段 |
| 统计方式 | 统计记录总数、统计字段数值、自定义公式 |
| 排序 | 支持记录顺序、维度值、指标值等排序方式 |
| 数据显示 | 可限制展示条数 |
| 图表配置 | 图例、数据标签、网格线、推荐配色、自定义配色等 |

多选字段可选择拆分统计或不拆分统计。指标卡计算出的数字统一保留一位小数。

## 筛选器

筛选器用于联动筛选一个或多个图表。

规则：

1. 可筛选图表为当前仪表盘内的图表，可多选。
2. 所选图表有几个数据源，就展示几个数据源选项。
3. 不同数据源选择的字段必须是同一类型。
4. 最后选择的字段与其他字段类型不一致时，清空其他选项。
5. 日期字段可设置日期格式。
6. 选项字段可设置选项样式。

## 典型图表

| 图表 | 核心规则 |
|---|---|
| 指标卡 | 支持统计记录总数、统计字段数值、自定义公式 |
| 柱状图 | 支持基础柱状图、堆积柱状图、百分比堆积柱状图 |
| 折线图 | 与柱状图类似，侧重趋势展示 |
| 条形图 | 与柱状图类似，横纵轴方向不同 |
| 饼图 | 支持实心和圆环；配置扇区分组和扇区数值 |
| 组合图 | 指标可设置为折线或柱状，并选择左轴或右轴 |
| 统计表 | 支持维度、统计方式、汇总、序号、排序 |
| 透视表 | 支持行维度、列维度、指标、冻结和汇总 |
| 里程碑状态 | 特殊图表，可按订单筛选并展示里程碑状态分布 |

## 仪表盘权限

贸易端按角色控制仪表盘查看和授权。

| 权限来源 | 能力 |
|---|---|
| 团队角色-内部FlowSpace管理 | 可查看所有内部 FlowSpace 的仪表盘数据，并可授权 |
| FlowSpace业务角色-仪表盘管理 | 可查看当前 FlowSpace 所有仪表盘数据，并可授权 |
| 被授权成员 | 可查看被授权的仪表盘 |
| 被授权协作团队成员 | 可查看被授权的仪表盘 |

仪表盘权限设置弹窗列出已加入当前 FlowSpace 的内部成员和协作团队成员。内部成员和协作成员即使未注册也可以授权。

权限维护规则：

1. 可模糊搜索内部成员姓名、协作团队名称、协作成员姓名。
2. 协作团队成员支持两级下钻选择。
3. 已选计数和左右列表选中状态需要同步。
4. 当前用户无仪表盘管理权限时，提示暂无权限。
5. 成员被移除 FlowSpace 后，对应仪表盘权限列表也删除；重新加入后需重新授权。

## 仪表盘查看

可管理当前 FlowSpace 仪表盘的用户可以查看当前 FlowSpace 中所有仪表盘数据。被授权部分仪表盘查看权限的成员或协作团队成员，只能查看被授权仪表盘。

可查看的仪表盘可以星标，星标后在工作台常用视图中展示。如果星标后权限被取消，常用视图中同步隐藏；重新授权后若还需要常用入口，需要重新星标。
