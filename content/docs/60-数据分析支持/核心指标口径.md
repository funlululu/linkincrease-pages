# 核心指标口径

本页用于统一 Linkincrease 数据分析中的核心指标定义。

## 指标维护模板

| 字段 | 说明 |
| --- | --- |
| 指标名称 | 指标的标准名称 |
| 业务含义 | 指标回答的业务问题 |
| 计算口径 | 计算公式、过滤条件、去重规则 |
| 数据来源 | FlowSpace、订单、工单、资源库、日志或外部系统 |
| 权限范围 | 谁可以查看、是否受数据围栏影响 |
| 更新频率 | 实时、定时、手动刷新或离线统计 |
| 关联页面 | 仪表盘、报表或运营场景 |
