# 常用视图与视图设置

## 定位

视图是用户在订单列表中沉淀查询、字段显示、排序、列统计、列宽、分页和查看模式等展示配置的载体。常用视图则把用户高频访问或主动星标的视图带回工作台，成为个人化快捷入口。

## 常用视图

常用视图展示当前用户标星的视图和访问次数前 10 的视图。常用视图仅对个人可见。

| 项目 | 规则 |
|---|---|
| 数据来源 | 用户标星的视图 + 访问次数前 10 的视图 |
| 去重 | 同一视图只展示一次 |
| 权限 | 不展示当下无权限的视图；标星视图点击时仍需判断权限 |
| 排序 | 先按星标时间倒序，再按访问次数倒序 |
| 访问次数相同 | 按最后访问时间正序 |
| 空状态 | 提示用户进入 FlowSpace 将常访问视图标星 |
| 状态记忆 | 按账号记住最后一次选中 FlowSpace 列表或常用视图列表状态 |

访问次数超过 999 后显示为 `1k` 类格式，保留一位小数并向下取整。

## 订单列表查询

订单列表查询由模糊搜索和条件查询组成，两者为且关系。

### 模糊搜索

模糊搜索支持当前列表所有文字类型字段的搜索，包括文本、数字、百分比、评级、单多选、日期、成员、协作团队、富文本文字部分、公式控件、关联引用字段等。

关键规则：

1. 隐藏字段不在模糊搜索范围内。
2. 搜索结果可高亮展示，并显示结果条数。
3. 支持切换上一条、下一条并定位到对应单元格。
4. 搜索范围跨页，高亮范围为当前页。
5. 按用户记住最近 5 次模糊搜索记录，不区分团队和 FlowSpace。

### 条件查询

条件查询只在当前用户自己的数据权限范围内筛选。

可查询字段范围：

| 类型 | 字段 |
|---|---|
| 模板字段 | 主表单、各里程碑批复字段 |
| 系统字段 | 订单 ID、订单状态、创建人、创建时间、更新人、更新时间、里程碑批复人、批复时间、里程碑状态、负责人、计划时间、实际时间、耗时等 |
| 自定义标签 | FlowSpace 设置中添加的主表单标签字段、各里程碑标签字段 |

数据围栏限制当前用户不可见的字段，查询字段也不可见。自定义视图中，如果被设为条件的字段在运营端被删除，对应字段展示删除样式并增加说明。

### 表头查询

表头可设置快捷查询条件。表头查询和右上角查询入口双向同步，被设置查询条件的列需要标记。

## 字段配置

字段配置用于控制列表展示字段、冻结列和不同查看模式下的字段表现。

| 配置 | 规则 |
|---|---|
| 冻结列 | 最多 5 个，最少 0 个 |
| 默认冻结 | 订单标识默认作为默认视图的冻结列 |
| 字段显隐 | 打开为显示，关闭为隐藏 |
| 默认隐藏 | 订单 ID 默认隐藏，其余字段默认显示 |
| 全部操作 | 支持显示所有、隐藏所有 |
| 数据围栏 | 不可见字段在字段配置中也不可见 |

冻结列适用于所有查看模式；非冻结列主要适用于详情查看模式。

## 排序

排序支持右上角排序设置和表头快捷排序，两者双向同步。

| 项目 | 规则 |
|---|---|
| 排序字段数 | 每次最多 3 列，最少 0 列 |
| 多字段排序 | 先按第一字段排序，相同值再按第二字段、第三字段排序 |
| 顺序调整 | 可拖拽修改排序字段顺序 |
| 默认排序 | 未设置排序字段时，按订单编号倒序 |

支持排序的字段类型包括文本、数字、百分比、评级、单多选、日期、成员姓名、协作团队名称、富文本文字部分、定位、地址、汇率，以及设置为这些类型的公式和关联引用字段。

文本升序规则为：空值、特殊符号、数字、英文字母、中文首字母；降序反向。相同值时，按订单 ID 排序。

## 列统计

列统计在列表底部展示基础数据统计，统计结果基于当前筛选结果跨页计算。

| 统计方式 | 说明 |
|---|---|
| 计数 | 当前表格数据条数 |
| 求和 | 当前列总和 |
| 平均值 | 有值数据总和 / 有值条数 |
| 最大值 | 当前列有值数据中的最大值 |
| 最小值 | 当前列有值数据中的最小值 |
| 未填写 | 当前列空值条数 |
| 已填写 | 当前列有值条数 |
| 唯一值 | 当前列非空值去重计数 |

规则补充：

1. 数字控件默认统计求和，包括数字公式和关联引用数字。
2. 百分比、评级不纳入数字默认求和。
3. 查询结果变更或编辑订单后，已设置的统计规则保留，并按最新数据重新计算。
4. 有勾选数据时统计勾选部分；没有勾选时统计当前筛选全部数据。
5. 图片、文件、富文本暂不做唯一值统计。
6. 操作人和操作时间同列时，默认统计操作人。
7. 里程碑计划时间、实际时间同列时，不进行统计。

## 视图保存

视图用于保存列表的展示配置。

触发保存提示的配置变更包括：

- 查询条件、表头查询、模糊搜索
- 字段配置
- 排序
- 列统计
- 列宽调整
- 每页显示条数
- 查看模式切换

视图类型：

| 类型 | 规则 |
|---|---|
| 默认视图 | 第一次进入列表时存在，展示所有字段、无排序、无筛选；不支持覆盖、重命名、删除 |
| 自定义视图 | 支持另存为、覆盖当前、重命名、删除 |

视图排序支持在每个主表单或里程碑模块下拖拽排序，不可跨模块拖拽。里程碑之间也可拖拽排序。
