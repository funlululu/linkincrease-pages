# 订单日程与任务中心

## 定位

订单日程与任务中心是工作台上的事务处理入口，目标是让用户登录后快速看到自己需要关注、处理、指派或追踪的工作。

## 订单日程

订单日程向里程碑负责人展示需要关注的订单里程碑计划，按日期和 FlowSpace 聚合展示。

### 计划负责人来源

FlowSpace 设置-计划管理支持设置默认负责人。创建或编辑订单时，各里程碑负责人默认按规则填入。

| 配置项 | 规则 |
|---|---|
| 所有订单 | 所有订单统一负责人规则 |
| 按条件区分 | 根据主表单字段条件，为不同订单设置不同负责人 |
| 可选负责人 | 订单创建人、FlowSpace 内部成员、FlowSpace 内协作团队成员 |
| 条件字段范围 | 主表单模板字段；运算符后选择的其他字段也限制在主表单范围 |

创建或编辑订单时，如果字段数据满足条件，里程碑负责人自动按配置填入。

### 工作台展示

订单日程按日历展示计划开始和计划结束信息。

| 项目 | 说明 |
|---|---|
| 计划截止 | 展示计划结束时间到达但当前还未结束的里程碑 |
| 计划开始 | 展示计划开始时间到达但当前还未开始的里程碑 |
| 日期标识 | 日期上展示开始或截止标识，点击日期查看当天明细 |
| 分组 | 明细以 FlowSpace 分组，协作 FlowSpace 显示所属团队名称 |
| 跳转 | 点击行跳转订单详情并定位到对应里程碑 |

计划今天截止展示订单标识、里程碑名称、工单完成进度、工单批复完成进度。计划今天开始展示订单标识和里程碑名称。

## 任务中心概览

工作台任务数据分为三类：

| 类型 | 说明 |
|---|---|
| 团队任务 | 当前用户作为协作团队对接人，或有相关任务指派权限时可指派的任务 |
| 我的任务 | 当前账号相关的待办、已处理、已完成任务 |
| 邮件协作任务 | 当前账号发起或接收的邮件协作任务 |

工作台任务卡片上的数量可点击跳转到任务中心并自动带入过滤条件。

## 团队任务

团队任务展示当前用户在当前团队有指派权限的任务。

| 状态 | 包含数据 |
|---|---|
| 待指派 | 里程碑进行中，任务未指派，且任务仍可处理 |
| 已指派 | 里程碑进行中，任务已指派 |
| 已完成 | 里程碑已完成或已取消，或工单已批复、已终止采集等不可编辑状态 |

团队任务默认展示“待指派”。标签和主菜单需要展示待指派任务数角标。

## 我的任务

我的任务展示当前用户可以采集、批复或处理的任务。

| 状态 | 包含数据 |
|---|---|
| 待处理 | 当前用户尚未完成处理，任务仍处于可编辑状态 |
| 已处理 | 当前用户已处理，但任务整体仍处于进行中 |
| 已完成 | 任务因里程碑完成、取消、工单批复、终止采集等进入不可编辑状态 |

协作团队未指派的任务，会显示在有权限成员的待处理中。有指派权限的协作方成员直接处理任务后，视为指派给自己并已处理。

## 我发起的

“我发起的”展示当前用户在当前团队下发出的工单或里程碑批复任务。

| 状态 | 包含数据 |
|---|---|
| 进行中 | 里程碑进行中，工单未批复、未终止采集 |
| 已完成 | 里程碑已完成或已取消，或工单已批复、已终止采集 |

默认展示“进行中”。

## 我关注的

“我关注的”展示用户在我的任务、团队任务、我发起的中标星的任务。

| 状态 | 规则 |
|---|---|
| 全部 | 展示当前仍有查看权限的标星任务 |
| 进行中 | 标星任务仍处于可处理或进行状态 |
| 已完成 | 标星任务已进入不可编辑状态 |

当标星任务失去查看权限时，不展示。

## 邮件协作任务

邮件协作任务包括“我发起的”和“我协作的”。

| 类型 | 规则 |
|---|---|
| 我发起的 | 展示当前用户发起且当前有查看权限的邮件协作 |
| 我协作的 | 展示当前邮箱账号收到的邮件协作，不区分当前团队 |

邮件协作“我发起的”以工单为分组单位，进行中表示原工单仍可编辑；已完成表示原工单进入不可编辑状态。

邮件协作“我协作的”默认展示待处理。待处理指原工单仍可编辑且当前协作邮箱未提交；已处理指已提交但原工单仍可编辑；已完成指原工单已不可编辑。

## 任务卡片通用规则

任务卡片通常展示订单标识、FlowSpace 名称、里程碑、工单、计划结束时间、完成度和操作按钮。

| 元素 | 规则 |
|---|---|
| 计划结束 | 到今天及以前的计划结束时间标红 |
| 完成度 | 工单采集完成度按已提交表单数 / 有采集人的表单总数计算 |
| 跳转 | 订单标识进入订单详情，FlowSpace 名称进入订单列表，工单打开工单弹窗 |
| 操作按钮 | 根据采集、批复、指派、修改处理人等权限展示 |
| 星标 | 采集任务和批复任务分别星标 |
| 已完成说明 | 显示第一次触发完成的原因和时间 |

## 查询与排序

任务中心支持模糊搜索和筛选。

| 能力 | 说明 |
|---|---|
| 默认排序 | 最近发起，即按任务发起时间倒序 |
| 可选排序 | 最早发起，即按任务发起时间正序 |
| 模糊搜索 | 支持订单标识、里程碑名称、工单名称、FlowSpace 名称 |
| 邮件协作搜索 | 邮件协作“我协作的”支持主题和订单标识搜索 |
| 计划结束时间 | 对应里程碑计划结束时间 |
| 任务更新时间 | 对应每项任务的最终操作时间 |
| 任务完成时间 | 任务变更为已完成或不可编辑状态的时间 |
