# 表单属性与显隐设置

## 1. 功能定位

表单属性用于配置表单名称、描述和国际化；显隐设置用于根据条件动态显示或隐藏字段。显隐规则直接影响贸易端和采集端的数据录入、必填校验、导入保存和服务端数据。

## 2. 表单属性

| 字段 | 是否必填 | 限制 |
| --- | --- | --- |
| 表单名称 | 必填 | 100 字符 |
| 表单名称国际化 | 非必填 | 100 字符 |
| 描述 | 非必填 | 200 字符 |

## 3. 显隐设置定义

显隐设置表示：当满足某些条件时，才显示指定字段。未满足条件时，指定字段隐藏。

核心规则：

- 子表和子表内组件不可作为条件字段。
- 条件中已使用的字段，不可再作为显示指定字段。
- 不同显隐规则中的显示指定字段不可重复。
- 本表单若有子表，子表作为一个大组件参与显示字段设置。

## 4. 可参与条件的数据源

| 当前表单 | 可参与条件的字段 |
| --- | --- |
| 主表单 | 主表单字段、里程碑批复字段 |
| 工单表单 | 主表单字段、同一里程碑所有表单，不含工单批复表单 |
| 工单批复表单 | 主表单字段、同一里程碑所有表单、本工单批复表单 |
| 里程碑批复表单 | 主表单字段、本里程碑批复字段 |

里程碑所有表单指工单表单和工单批复表单。

## 5. 条件字段类型与运算符

| 字段类型 | 运算符 |
| --- | --- |
| 单行文本、多行文本、单选、多选、定位 | 等于、不等于、包含、不包含、为空、不为空 |
| 数字、评级、百分比 | 等于、不等于、小于等于、大于等于、为空、不为空 |
| 成员 | 为空、不为空 |
| 日期 | 等于、早于、晚于、在范围内、为空、不为空 |
| 公式 | 根据公式显示类型使用对应运算符 |

当运算符选择“为空/不为空”时，不显示后续条件值输入。

## 6. 条件值来源

| 来源 | 规则 |
| --- | --- |
| 自定义 | 根据前方字段类型展示对应输入框；选项字段可选择选项值 |
| 其他字段 | 可选同类型数据源字段，但需排除当前条件中的目标字段 |

条件支持同时增加“或”和“且”。

## 7. 贸易端应用

- 隐藏后的组件所在整行如果无其他显示内容，需要自动上移，不保留整行空白。
- 隐藏组件的数据应清空，不验证必填。
- 隐藏组件数据不保存至服务端。
- 导入时，显隐判断为隐藏的字段即使有导入值，也应导入为空。

## 8. 变更与删除提示

- 表单内容发生变更，未保存返回或关闭页面时，需要提示保存。
- 删除控件时需要关键操作提示。
- 显隐规则中涉及的字段被删除或变更时，需要避免产生不可见但仍参与判断的悬挂规则。

## 9. 待确认问题

- 显隐设置是否影响导出、报告、仪表盘统计口径。
- 多条显隐规则同时命中同一字段时目前禁止重复设置，后续是否允许优先级模式。
- 历史数据中已保存的隐藏字段值清空时机，需要与线上逻辑核对。
