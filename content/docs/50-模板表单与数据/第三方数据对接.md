# 第三方数据对接

## 1. 功能定位

第三方数据对接用于把外部系统数据引入 Linkincrease，减少手动录入并保持数据一致。当前资料覆盖两类能力：模板内表单级 API 引用，以及运营端 FlowSpace 级外部 API 集成配置。

## 2. 表单级 API 引用

表单级 API 引用主要配置在业务模板的里程碑属性中，可分别针对工单、工单批复、里程碑批复设置引用能力。

| 配置项 | 规则 |
| --- | --- |
| 是否启用 | 默认禁用 |
| 按钮名称 | 非必填，默认“数据引用”，限制 20 字符，需国际化 |
| URL | 接口地址 |
| 请求方式 | 默认 POST |
| Result Format | 默认 JSON |
| 请求配置 | 请求头等信息，可不填 |
| 查询配置 | 传给服务器的查询、过滤、排序、分页等参数 |
| 字段匹配 | 接口字段与模板字段映射；模板字段不可重复配置 |
| 贸易端白名单 | 控制哪些团队可使用数据引用 |

如果已匹配字段在模板变更后被删除，贸易端和运营端不展示对应字段。

## 3. 自动引用与定期更新

| 能力 | 规则 |
| --- | --- |
| 自动引用 | 启用后，用户填写已匹配的触发字段时自动查询并引用 API 数据 |
| 多条匹配 | 可选择不引用、引用最新更新、引用最后创建、引用最早创建 |
| 引用时机 | 工单初次发起、工单批复初次批复、里程碑初次批复 |
| 定期更新 | 开启后，根据自动引用字段内的数据定期更新相关数据 |

可更新状态：

- 工单：里程碑进行中、未被工单批复、未终止，排除互用自的工单。
- 工单批复：里程碑进行中，排除互用自的工单。
- 里程碑批复：里程碑进行中。

更新后需要增加动态和历史记录。

## 4. 贸易端引用应用

- 对应表单开启 API 配置且当前团队在白名单内，才展示引用按钮。
- 可通过弹窗搜索接口数据，选择一条数据后按字段匹配填入表单。
- 确认引入需要二次确认。
- 填入数据支持手动修改。
- 只读或隐藏字段不填入。
- 采集端任务详情若配置引用第三方数据且工单可编辑，也展示引用能力。

## 5. FlowSpace 级外部 API 集成

FlowSpace 级外部 API 集成用于把外部系统数据直接创建或更新 Linkincrease 的订单、工单和批复。

| 配置项 | 规则 |
| --- | --- |
| 集成名称 | 必填 |
| 来源标识 | 必填，后端配置项 |
| 配置状态 | 默认开启 |
| 同步更新 | 默认关闭，关闭时只允许创建新记录 |
| 同步删除 | 默认关闭，关闭时外部删除标记不删除 FlowSpace 数据 |
| Linkincrease 同步至外部 | 默认关闭，关闭时 Linkincrease 修改不回写 |
| 冲突数据同步 | 暂定时间戳优先，仍需补充 |

集成生效后，订单和工单由外部系统创建，Linkincrease 不允许手动创建对应数据。

## 6. 字段映射

外部 API 集成支持 JSONPath 提取深层数据。

| 映射对象 | 规则 |
| --- | --- |
| 主表单主键 | 必选，可配置文本、数字、百分比、日期字段 |
| 主表单字段 | 支持非子表字段和子表字段配置 |
| 里程碑工单 | 按里程碑数组路径映射工单字段 |
| 工单批复 | 有工单批复时配置 |
| 里程碑批复 | 有里程碑批复时配置 |
| 采集人/批复人 | 通常通过邮箱与 FlowSpace 成员匹配，匹配失败则创建失败或后续手动修改 |

参与配置的 FlowSpace 字段不允许重复配置。配置了主键的模板字段不允许用户修改，以防数据冲突。

## 7. 冲突与写入策略

- API 显式写入：映射配置了字段且外部数据有值时，强制写入。
- FlowSpace 默认值：外部数据无字段或值为空时，创建时可填入默认值。
- 公式/联动：API 写入触发字段后，系统自动计算相关公式字段。
- 未映射字段不可被外部 API 修改。

## 8. 日志与追溯

外部 API 集成日志列表展示触发时间、事件类型、同步方向、数据标识、状态和详情。

业务侧需要记录：

- 订单跟踪记录：创建订单、更新订单、里程碑开始、删除工单等。
- 工单动态：创建工单、创建里程碑批复、更新工单采集、更新工单批复、更新里程碑批复等。
- 历史记录：以来源标识记录创建或编辑行为。

## 9. 待确认问题

- 外部主键组合填写规则和后端支持范围仍待补充。
- 冲突数据同步策略除时间戳优先外，是否需要人工处理队列。
- 第三方成员与 FlowSpace 成员邮箱不一致时的异常处理需要形成正式规则。
