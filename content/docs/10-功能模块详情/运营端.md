# 运营端

## 1. 定位

运营端是 Linkincrease 的平台级配置与监管后台，服务对象主要是平台运营、实施和管理人员。

它不直接承担日常订单执行，而是负责维护平台基础数据、模板能力、配置能力、监管能力和平台级审计入口。贸易端和采集端的很多业务能力，都来自运营端模板、组件、集成和平台配置的下发。

## 2. 核心职责

| 职责 | 说明 |
| --- | --- |
| 平台用户监管 | 管理和查看用户账号、启用状态、激活状态、登录记录、所属团队、相关 FlowSpace |
| 平台团队监管 | 查看团队基础信息、拥有者、成员、角色、协作邀请、团队关联 FlowSpace |
| FlowSpace 数据监管 | 查看平台团队下 FlowSpace 列表、FlowSpace 数据详情、成员记录、协作团队、订单、工单、自动化记录 |
| 资源库监管 | 查看团队资源库列表、资源库数据明细、模板来源、创建和更新记录 |
| 模板中心 | 管理业务模板、资源库模板，并向贸易端创建 FlowSpace 和资源库提供标准模板 |
| 表单与组件配置 | 维护表单组件、字段属性、显隐规则、公式、行业组件等配置底座 |
| 仪表盘与报告 | 管理 FlowSpace 仪表盘、仪表盘设计器、第三方报告链接和报告相关数据表 |
| 集成与系统能力 | 配置外部 API 集成、第三方数据引用、软件更新和系统级记录 |

## 3. 主要模块

### 3.1 用户管理

运营端用户管理用于监管平台用户账号。

常见列表字段包括 UID、账号邮箱、头像、姓名、拥有团队、加入团队、相关 FlowSpace、注册时间、最后登录时间、浏览器或终端版本、系统、设备、登录 IP、地区、账号状态。

常见筛选条件包括账号、姓名、账号状态、激活状态、创建时间、最后登录时间。

账号状态需要区分：

- `启用`：用户可正常登录并使用贸易端或采集端。
- `禁用`：用户不可登录，贸易端应展示禁用提示。
- `待激活`：已被邀请但尚未完成注册激活。

### 3.2 团队管理

团队管理用于监管平台内客户团队及其协作关系。

常见列表字段包括团队名称、团队简称、团队代码、拥有者、成员数量、已邀请协作团队数量、参与外部团队数量、FlowSpace 数量、协作 FlowSpace 数量、创建时间。

团队详情通常包含：

- 团队基础信息。
- 成员信息。
- 角色列表。
- 本团队邀请的协作团队。
- 本团队参与的外部协作团队。
- 本团队自有 FlowSpace。
- 本团队参与的外部协作 FlowSpace。

邀请记录需要区分团队成员邀请和团队协作邀请，并记录操作人、被邀请方、邀请时间、处理状态等信息。

### 3.3 FlowSpace 管理

FlowSpace 管理用于查看平台团队下的 FlowSpace 数据。

常见筛选条件包括 FlowSpace 编号、FlowSpace 名称、团队代码、团队名称、拥有者账号、拥有者姓名、创建人账号、创建人姓名、创建类型、模板行业、创建时间、模板更新时间。

列表常见字段包括 FlowSpace 编号、名称、所属团队、团队代码、团队拥有者、成员数量、协作团队数量、订单数量、模板名称、模板类型、模板行业、创建人、创建时间、模板更新人、模板更新时间。

常见操作入口包括：

- 查看 FlowSpace 数据详情。
- 修改模板。
- 复制到模板库。
- 进入仪表盘管理。
- 查看订单、工单、操作记录、成员管理记录。

### 3.4 资源库管理

资源库管理用于监管团队资源库及其数据明细。

常见筛选条件包括资源库名称、团队代码、团队名称、创建人账号、创建人姓名、模板名称、创建类型、模板行业、创建时间、更新时间。

列表常见字段包括资源库名称、所属团队、团队代码、模板名称、模板类型、模板行业、创建人、创建时间、更新人、模板更新时间。

资源库数据详情通常需要支持按资源库、团队、创建人检索，并展示资源库名称、团队、模板、表单名称、创建人、创建时间、更新人、更新时间等信息。

### 3.5 设置与软件管理

设置模块沉淀平台级软件管理能力，包括软件版本、更新记录、安装包、更新日志和相关操作记录。

该模块属于系统运维与审计能力的一部分，应与 [系统与集成执行日志](../40-权限、安全与审计/系统与集成执行日志.md) 互相引用。

## 4. 与其他产品端关系

| 关系 | 说明 |
| --- | --- |
| 运营端到贸易端 | 运营端配置模板、组件、仪表盘、报告、集成能力；贸易端在团队和 FlowSpace 场景中使用这些能力 |
| 运营端到采集端 | 运营端不直接驱动采集端任务，但通过模板、字段、表单组件和流程配置影响采集端任务详情页的展示与填写 |
| 运营端到公共能力 | 权限、日志、自动化、外部 API、报告、仪表盘等能力需要在公共能力页沉淀统一口径 |

## 5. 知识库拆分建议

运营端后续可继续拆成以下细页：

- 用户管理。
- 团队管理。
- FlowSpace 数据管理。
- 资源库数据管理。
- 邮件协作监管。
- 自动化记录。
- 外部 API 集成配置。
- 报告管理。
- 软件管理。
