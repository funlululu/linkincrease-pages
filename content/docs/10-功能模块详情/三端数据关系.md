# 三端数据关系

## 1. 总览

Linkincrease 的三端不是并列孤岛，而是围绕同一套业务对象形成配置、执行、监管和回流关系。

```mermaid
flowchart LR
  A["运营端<br/>模板、配置、监管、集成"] --> B["贸易端<br/>团队、FlowSpace、订单、资源库、协作"]
  B --> C["采集端<br/>任务、采集、批复、消息"]
  C --> B
  B --> A
```

简化理解：

- 运营端定义和监管平台能力。
- 贸易端承载客户团队的业务运行。
- 采集端处理移动执行任务，并把结果回流贸易端。

## 2. 数据主从关系

| 数据或能力 | 主维护端 | 使用端 | 说明 |
| --- | --- | --- | --- |
| 用户账号 | 运营端监管，用户自维护 | 贸易端、采集端 | 运营端可查看和管理账号状态；用户在个人中心维护个人信息 |
| 团队 | 贸易端创建维护，运营端监管 | 贸易端、运营端、采集端 | 团队是业务归属单位；采集端通过团队切换查看任务 |
| FlowSpace | 贸易端创建维护，运营端监管 | 贸易端、采集端、运营端 | FlowSpace 承载订单、工单、资源库应用、仪表盘和报告 |
| 业务模板 | 运营端 | 贸易端 | 贸易端创建 FlowSpace 时使用运营端模板 |
| 资源库模板 | 运营端 | 贸易端 | 贸易端创建团队资源库时使用运营端模板 |
| 表单组件和显隐规则 | 运营端 | 贸易端、采集端 | 采集端任务详情页展示和填写规则受模板配置影响 |
| 订单 | 贸易端 | 采集端、运营端 | 订单在贸易端创建和管理；采集端展示任务关联订单；运营端可监管数据 |
| 里程碑 | 贸易端 | 采集端、运营端 | 里程碑定义订单流程节点和批复任务 |
| 工单 | 贸易端 | 采集端、运营端 | 工单可在贸易端发起，在采集端移动填写和提交 |
| 工单批复 | 贸易端 | 采集端、运营端 | 批复任务可在采集端处理，结果回流贸易端 |
| 里程碑批复 | 贸易端 | 采集端、运营端 | 采集端可处理里程碑批复任务 |
| 资源库数据 | 贸易端 | 贸易端、采集端、运营端 | 资源库数据可被订单或工单引用，运营端监管资源库数据 |
| 自动化 | 贸易端配置，运营端监管 | 贸易端、运营端 | 自动化执行结果进入日志，部分动作影响订单、工单、资源库 |
| 消息通知 | 贸易端和系统触发 | 贸易端、采集端 | 消息状态需要跨端一致 |
| 仪表盘和报告 | 运营端配置或监管，贸易端使用 | 贸易端、运营端 | 权限控制决定查看和管理范围 |
| 日志审计 | 系统记录 | 贸易端、运营端 | 设置、操作、动态、历史、系统执行均需要可追溯 |

## 3. 核心数据流

### 3.1 从模板到 FlowSpace

1. 运营端维护业务模板、资源库模板、表单组件、字段规则。
2. 贸易端在工作台选择模板创建 FlowSpace。
3. FlowSpace 生成订单、里程碑、工单、权限、仪表盘等业务空间。
4. 后续模板更新需要按同步规则影响已创建的 FlowSpace。

参考：[从模板到FlowSpace](../30-业务流程与产品流程图/从模板到FlowSpace.md)。

### 3.2 从订单到移动采集

1. 贸易端创建或导入订单。
2. 贸易端在订单里程碑下创建工单、工单批复或里程碑批复。
3. 采集端按用户、团队、FlowSpace、任务状态展示待办任务。
4. 执行人员在采集端填写工单或提交批复。
5. 数据、动态、历史记录和任务状态回流贸易端。

参考：[工单采集与批复](../30-业务流程与产品流程图/工单采集与批复.md)、[移动端采集](../30-业务流程与产品流程图/移动端采集.md)。

### 3.3 从资源库到业务表单

1. 运营端维护资源库模板。
2. 贸易端基于模板创建团队资源库。
3. FlowSpace 应用资源库数据范围。
4. 订单或工单字段引用资源库数据。
5. 资源库数据变更后，按引用和同步规则更新业务数据。
6. 系统记录资源库同步和字段变更历史。

参考：[资源库引用与同步](../30-业务流程与产品流程图/资源库引用与同步.md)。

### 3.4 从协作到通知

1. 贸易端发起成员邀请、协作团队邀请、工单指派或邮件协作。
2. 系统按场景生成消息、实时通知、邮件或任务入口。
3. 贸易端和采集端展示未读、待办、关注、团队指派等状态。
4. 处理结果回流并更新任务状态、动态和日志。

参考：[消息中心与实时通知](../10-功能模块详情/消息中心与实时通知.md)、[邮件协作](../10-功能模块详情/邮件协作.md)。

## 4. 权限边界

三端权限关系应按“平台监管、团队归属、FlowSpace 业务角色、协作方角色、数据围栏、资源权限、展示权限”分层理解。

| 层级 | 主要控制点 |
| --- | --- |
| 平台监管权限 | 运营端可查看和监管平台用户、团队、FlowSpace、资源库、软件和系统记录 |
| 团队权限 | 贸易端团队拥有者、管理员、成员等角色控制团队设置和成员管理 |
| FlowSpace 权限 | FlowSpace 业务角色控制订单、里程碑、工单、仪表盘、报告等操作 |
| 协作权限 | 协作团队和协作方角色控制外部团队可见和可操作范围 |
| 数据围栏 | 控制字段、标签、数据范围对不同成员或团队是否可见 |
| 采集端权限 | 采集端按用户任务、编辑权限、指派权限决定按钮和表单状态 |

参考：[权限体系总表](../40-权限、安全与审计/权限体系总表.md)。
