
# 资源库快捷创建引用数据

## 1. 功能定位

资源库快捷创建引用数据用于在订单创建或编辑过程中，直接从资源库引用弹窗创建当前资源表的数据，并回到引用弹窗完成选择，缩短“发现资源库数据缺失 -> 创建资源数据 -> 完成订单引用”的路径。

快捷创建写入的是正式资源库数据，不是订单临时数据。即使后续取消订单，已创建的资源库数据仍保留。

## 2. 使用入口

用户在订单表单中打开资源库引用弹窗时，如果当前选中的资源表有效，且当前用户拥有该表“创建数据”权限，则展示“添加资源数据”按钮。

按钮只作用于当前选中的资源表；切换资源表后立即重新计算权限。前端隐藏只用于交互，打开创建页和提交创建时服务端必须再次校验。

## 3. 创建数据抽屉

点击“添加资源数据”后，在引用弹窗之上打开当前资源表的创建数据抽屉：

1. 复用当前资源表的创建表单、字段、组件和校验规则。
2. 保留订单草稿，以及引用弹窗中的资源表、搜索词、筛选、滚动位置和已选数据。
3. 抽屉底部提示：“保存后数据将直接写入资源库；即使取消订单，该数据仍会保留。”
4. 取消或关闭时不创建数据，并返回引用弹窗原状态。

## 4. 创建成功后的引用规则

| 场景 | 规则 |
| --- | --- |
| 创建成功且可引用 | 刷新当前资源表列表，定位并自动选中新数据；存在二级引用页面时，自动选中并跳转到二级页面；提示“资源数据已创建，并已为你选中” |
| 创建成功但不可引用 | 数据保留在资源库，不回滚；引用弹窗不选中该数据；提示检查数据范围 |
| 用户确认引用 | 按既有单选、多选、字段回填、空值处理、成员/协作方过滤和二级引用规则回填订单字段 |
| 订单取消或保存失败 | 不删除已快捷创建的资源库数据 |

创建资源数据本身不代表订单已引用；必须由用户在引用弹窗确认后，才按既有映射回填订单字段。

## 5. 权限、数据范围与对象边界

| 维度 | 规则 |
| --- | --- |
| 写入对象 | 当前资源库 > 当前资源表 > 单条资源库数据 |
| 可引用范围 | 已关联资源表、表有效性、表查看权限、用户数据范围、FlowSpace 应用范围及协作授权范围的交集 |
| 资源库/资源表 | 复用现有对象，不新增结构；创建目标由引用弹窗当前资源表决定 |
| 资源库模板 | 复用现有表单结构、组件和校验，无新增配置项 |

创建成功后按普通“创建资源库数据”写入历史，记录创建人、创建时间，并触发与普通资源库新增一致的既有事件。

## 6. 空态与异常

| 场景 | 页面处理 |
| --- | --- |
| 无可引用数据且有创建权限 | 显示“暂无可引用数据”和“添加资源数据”入口 |
| 无可引用数据且无创建权限 | 仅显示“暂无可引用数据”，不展示创建入口 |
| 搜索无结果 | 显示“未找到匹配数据”；有权限时仍可创建，但不自动带入搜索词 |
| 点击创建前权限被移除 | 提示“暂无权限，请联系管理员” |
| 填写中权限被移除 | 提交失败，保留已填内容并提示无权限 |
| 资源表被删除或失效 | 提交失败，关闭创建页并刷新可选资源表，提示重新选择 |
| 协作授权被移除 | 提交失败，刷新资源表可选数据范围 |
| 必填或格式错误 | 在对应字段就近提示，不提交 |
| 网络或服务异常 | 保留表单内容，提示“创建失败，请稍后重试” |
| 重复提交 | 首次提交后按钮进入加载态，不产生重复数据 |
| 创建成功但列表刷新失败 | 提示“数据已创建，请刷新列表后选择”，允许手动刷新 |

## 7. 验收重点

1. 有当前表创建权限时展示“添加资源数据”；无权限时不展示，接口也拒绝。
2. 切换不同资源表时，按钮按当前表权限实时显示或隐藏。
3. 创建抽屉复用当前资源表表单，表单校验失败时不提交。
4. 创建成功且可引用时，返回引用弹窗、刷新并自动选中新数据，但不直接写入订单。
5. 权限或资源表状态中途变化时，服务端拒绝提交并明确提示。
6. 创建成功但不可引用时，资源库数据不回滚、不选中，并提示检查数据范围。
7. 取消订单后，快捷创建成功的资源库数据仍保留。
8. 原引用能力回归：清除关联、手动修改、二级引用和同步策略不受影响。
