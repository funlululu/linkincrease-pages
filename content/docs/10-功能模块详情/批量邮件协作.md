
# 批量邮件协作

## 1. 功能定位

批量邮件协作用于在工单视图中对多条工单一次性发起邮件协作，减少重复操作。每个邮箱都会接收当前勾选工单的邮件协作，执行几条工单就收到几封邮件。

## 2. 入口与适用范围

- 入口：贸易端工单视图批量操作。
- 对象：当前勾选的多条工单。
- 发送记录：与单条邮件协作共用最近 10 条发送邮箱记录。

## 3. 配置内容

| 配置项 | 规则 |
| --- | --- |
| 收件邮箱 | 可输入多个邮箱 |
| 邮件主题 | 同单个工单邮件协作 |
| 备注 | 同单个工单邮件协作 |
| 附件 | 可选择当前里程碑工单模板中的图片/附件字段；本地上传附件应用于所有工单 |
| 协作内容设置 | 列出当前所选工单中所有表单，可分别设置显隐 |
| 预览 | 查看发出后的协作内容 |

由于批量邮件涉及多个工单，选择模板附件字段时不立即带入附件，而是在发出时统一上传。

## 4. 表单显隐与数据围栏

- 每行工单根据各自表单显隐、当前采集人是否可编辑进行展示。
- 可编辑表单发出后字段内容为空，供外部填写。
- 不可编辑表单发出后展示原工单最新数据。
- 订单基本信息按当前采集人的数据围栏控制，不可见字段对邮件协作者也不可见。

## 5. 确定校验

| 校验 | 提示 |
| --- | --- |
| 邮箱格式不正确 | 邮箱格式不正确 |
| 某工单可编辑表单全隐藏 | 至少保留一个可编辑模块 |
| 采集人可编辑表单或可见表单变更 | 工单编辑权限已变更，请刷新页面 |
| 指派权限被取消 | 暂无权限，请刷新页面 |
| 订单删除 | 订单已删除，无法操作，请刷新页面 |
| 里程碑完成或取消 | 里程碑已完成/已取消，无法操作，请刷新页面 |
| 工单终止采集、已批复或删除 | 工单已终止采集/已批复/已删除，无法操作，请刷新页面 |

## 6. 批量采集工单

同一批量操作需求中还包含批量采集工单。批量采集在编辑列表中直接修改可编辑工单字段，提交后触发与单条工单采集相同的动态、历史记录和消息通知。批量邮件协作则生成邮件协作任务，不直接提交工单采集数据。

批量采集入口标题为 `批量 + 运营端设置的当前里程碑工单采集按钮名称`，标题栏提示已选择数量和可编辑数量。可编辑工单指当前用户作为工单采集人，或协作团队未指派前具备指派权限的成员，且工单处于可采集状态。

编辑列表表头展示当前里程碑工单采集表单所有字段。每行按各自表单配置展示：隐藏表单放空；当前用户可采集表单展示输入框并可编辑；仅可查看表单展示对应值且不可编辑。表头操作可批量修改所有可编辑工单的字段值，列表操作可单独设置每个订单对应字段值。

特殊控件规则：

| 控件 | 规则 |
| --- | --- |
| 公式控件 | 根据计算因子实时计算 |
| 显隐控件 | 满足显示条件时正常编辑；满足隐藏条件时显示为 `-`，不展示输入框 |
| 关联资源库字段 | 显示引用资源库按钮，引用逻辑同单条订单编辑页面 |

编辑过程中若某一行对应的订单、里程碑或工单状态发生变化，只在对应工单行内提示并禁用该行输入，不影响其他工单编辑和提交。提交前需统一校验订单删除、采集人权限变更、订单完成或取消、里程碑完成或取消、工单终止采集、工单已批复和必填项为空等场景。

校验通过后，工单动态增加一条采集记录，历史记录增加一条采集记录，消息通知同单条工单采集，订单详情里程碑树重新计算工单采集完成状态。关闭批量编辑弹窗时，若内容已变更需提示是否保存数据。

## 7. 待确认问题

- 批量邮件协作是否支持“所有对象共同接收同一封邮件”的新发送模式，需与单条邮件协作统一。
- 批量邮件发送失败的重试、部分成功和记录展示规则需补充。
