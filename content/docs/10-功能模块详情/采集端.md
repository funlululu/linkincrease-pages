# 采集端

## 1. 定位

采集端是 Linkincrease 的移动执行入口，面向需要在移动场景中查看任务、填写工单、提交批复、处理指派和接收消息的执行人员。

采集端不是完整后台，它聚焦“我需要处理什么、在哪里处理、处理后如何同步回贸易端”。因此知识库中采集端应优先围绕任务列表、任务详情、采集提交、批复提交、消息提醒和个人中心沉淀。

## 2. 核心职责

| 职责 | 说明 |
| --- | --- |
| 登录与账号 | 邮箱密码登录、忘记密码、账号状态校验 |
| 首页概览 | 展示我的任务、团队待指派任务、我关注、FlowSpace 任务统计 |
| 任务列表 | 按进行中、已完成、我发起、我关注、团队指派等维度查看任务 |
| 任务搜索 | 搜索工单、工单批复、里程碑批复任务 |
| 任务详情 | 查看工单详情、工单批复详情、里程碑批复详情 |
| 移动采集 | 填写工单表单、引用第三方数据、处理子表、提交数据 |
| 图片采集与编辑 | 拍照、相册多选、图片预览、标注、脱敏、上传和失败重试 |
| 批复处理 | 提交工单批复和里程碑批复 |
| 指派处理 | 在具备权限时处理协作工单或批复的指派 |
| 消息中心 | 接收任务、评论、协作、系统相关消息 |
| 我的 | 查看个人信息和基础账号入口 |

## 3. 主要模块

### 3.1 登录

采集端登录与贸易端账号体系保持一致，通常使用邮箱和密码登录，并支持忘记密码。

账号状态、禁用状态、待激活状态等应与平台账号规则一致。若账号被禁用，应阻止登录并提示用户。

### 3.2 首页

首页展示任务相关数据和 FlowSpace 相关任务数据。常见区域包括：

- 我的任务。
- 团队待指派任务。
- 我关注。
- FlowSpace 任务统计。
- 团队切换入口。
- 底部导航。

FlowSpace 统计需要展示该团队下与当前用户相关的订单数、任务数、里程碑任务数、待办数等。若 FlowSpace 来自外部协作，需要展示协作标识和所属团队信息。

首页需要支持下拉刷新；页面较长时可出现返回顶部入口；点击头像或名称进入个人中心；点击待办、团队指派、我关注等入口跳转到任务列表对应标签页。

### 3.3 任务列表

任务列表按不同状态和业务维度展示任务，至少包含：

- 进行中任务。
- 已完成任务。
- 我发起任务。
- 我关注任务。
- 团队指派任务。

进行中任务需要区分待办和已处理。任务类型包括工单、工单批复、里程碑批复。任务列表应排除互用产生的工单，仅展示正常创建的工单。

常见筛选和排序包括：

- 任务状态标签。
- 任务排序：最新发起、最近发起等。
- FlowSpace 范围：全部或指定 FlowSpace，多选。
- 订单状态：全部、进行中、已完成、已取消等。

列表需要支持下拉刷新、上拉加载更多、标签切换、进入任务搜索页、点击任务进入详情、关注和取消关注。

### 3.4 任务详情

任务详情覆盖三类页面：

- 工单详情页。
- 工单批复详情页。
- 里程碑批复详情页。

工单详情页需要展示基础信息，包括里程碑状态、订单标识、FlowSpace 名称、里程碑名称、发起人、发起时间、采集人、最新采集时间、批复人、最新批复时间、工单完成度、可编辑模块、所属团队等。

工单表单需要按可编辑和不可编辑状态展示。若用户具有编辑权限且工单可编辑，则展示提交按钮；若无权限或不可编辑，则隐藏提交按钮。

采集端任务详情还需要处理：

- 未提交修改返回时的保存提示。
- 服务端任务更新后的冲突提示。
- 指派按钮显隐。
- 第三方数据引用入口。
- 工单终止标签。
- 工单动态。
- 子表引用、添加、保存、继续添加、继续关联。
- 子表行数据切换和未保存提示。
- 图片拍照、相册多选、大图预览、编辑、删除、上传状态和失败重试。

工单批复详情页以工单批复为第一标签，其他逻辑与工单详情页保持一致。里程碑批复详情页需要展示里程碑批复表单、该里程碑下的工单和工单批复、订单信息。

### 3.5 图片采集与编辑

工单、工单批复和里程碑批复中的图片组件支持拍照和相册多选。拍照后先进入单图预览，可直接使用、编辑或重拍；相册多选后直接加入图片组件，不强制逐张确认。

图片编辑支持方框、文字、马赛克、撤销、清空和重新编辑。编辑结果与原图合成为新图片并替换当前图片，不新增图片数量。图片未上传完成时不允许提交表单，上传失败时保留本地图片并提供重新上传。

详细规则见 [采集端图片编辑](./采集端图片编辑.md)。

### 3.6 消息中心与我的

采集端消息中心承接任务、评论、协作、系统相关消息，并与贸易端消息状态保持一致。需要支持未读提示和 App 通知入口。

我的页面用于展示个人中心信息，通常承接头像、姓名、账号相关信息、退出或账号管理入口。

## 4. 与其他产品端关系

| 关系 | 说明 |
| --- | --- |
| 来自贸易端 | 任务、工单、批复、指派、订单和 FlowSpace 信息从贸易端同步到采集端 |
| 回流贸易端 | 采集提交、批复提交、评论、动态、指派结果回写贸易端 |
| 受运营端配置影响 | 表单组件、字段显隐、第三方数据引用、模板规则由运营端配置，并在采集端任务详情中体现 |

## 5. 知识库拆分建议

采集端后续可继续拆成以下细页：

- 登录与账号状态。
- 首页任务统计。
- 任务列表。
- 任务搜索。
- 工单详情。
- 工单批复详情。
- 里程碑批复详情。
- 图片采集与编辑。
- 消息中心。
- 我的。
