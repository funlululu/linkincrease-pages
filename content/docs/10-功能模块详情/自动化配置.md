
# 自动化配置

## 1. 功能定位

自动化配置用于在 FlowSpace 内设置触发条件和执行操作，自动完成通知、创建工单、更新订单或批复数据等机械性工作。启用状态下才会执行。

## 2. 自动化列表

| 字段 | 说明 |
| --- | --- |
| 自动化名称 | 支持模糊搜索 |
| 内容 | 展示触发条件和执行操作摘要 |
| 状态 | 全部、启用、未启用 |
| 执行日志 | 查看对应自动化已执行情况 |
| 操作 | 编辑、删除 |

启用自动化时需要校验设置是否完善；未完善时提示前往设置。

## 3. 配置结构

一个自动化包含：

- 1 个触发条件。
- 最多 5 个执行操作。
- 是否启用。
- 执行失败通知，可选择站内、邮件、短信。

自动化触发条件和执行操作只在同一订单内发生，不跨订单触发执行。

## 4. 触发条件

| 条件 | 说明 |
| --- | --- |
| 新增数据时 | 订单基本信息、里程碑批复、里程碑工单新增后触发 |
| 数据内容变更时 | 指定数据源字段变更时触发，可使用“变更时”条件 |
| 到达记录中的时间时 | 到达数据源内日期字段的当时、之前或之后触发 |
| 定时任务 | 按不重复、每天、每周、每月、每月第几个周几执行 |

数据源选择工单且满足条件使用该工单字段时，可设置工单范围为当前工单。

到达记录中的时间时，触发时间支持当时、之前、之后。之前/之后需要输入正整数，并选择分钟、小时、天、周、月、年等单位；当选择当时时，偏移输入隐藏。

## 5. 执行操作

| 操作 | 说明 |
| --- | --- |
| 发送通知 | 通过 Linkincrease 消息或邮件通知成员、团队、角色或模板控件人员 |
| 新增数据 | 自动新增里程碑工单，并设置处理人和默认值 |
| 更新数据 | 更新订单基本信息、里程碑批复或工单字段 |

自动化按顺序执行。任一步失败，后续操作不执行，并根据失败通知配置通知相关对象。

## 6. 发送通知

通知对象包括：

- FlowSpace 成员。
- FlowSpace 协作团队。
- 业务角色和协作方角色。
- 订单模板控件。
- 步骤一数据源角色。

通知对象可进一步包含主团队成员、协作团队负责人和成员、业务角色、协作方角色、订单模板中的成员/协作方控件，以及步骤一数据源中的创建人、更新人、负责人、发起人、采集人、批复人等角色。协作团队负责人和具体成员为同一人时需要去重通知。

通知渠道包括 Linkincrease 消息和邮件。邮件可配置分别发送，或让所有被通知对象同时接收同一封邮件。标题和正文可拼接模板字段；邮件可附带步骤一数据源中的图片或附件字段。

## 7. 新增数据

新增数据当前主要用于创建工单。

配置项：

- 数据源。
- 工单名称，自定义或自动编号。
- 处理人，至少保留一个非隐藏表单，且至少设置一项采集人、工单批复人或里程碑批复人。
- 工单默认值；未设置处理人的采集表单中如果包含必填字段，必须设置默认值。

不执行场景包括订单已完成/取消、里程碑已完成/取消、里程碑互用自其他订单、处理人为空、必填默认值为空等。

## 8. 更新数据

更新数据可选择订单基本信息、里程碑批复、工单。数据源为工单时，可选择所有记录或指定记录；指定记录需设置过滤条件。

不执行场景包括：

- 订单已完成或取消。
- 里程碑已完成或取消。
- 里程碑或工单互用自其他订单。
- 更新工单采集字段时，工单已批复或终止采集。

数据源为工单且更新指定记录时，过滤条件仅可使用工单范围字段。执行后，订单基本信息更新写入订单跟踪记录；里程碑批复更新写入里程碑批复动态；工单更新按采集和批复分别写入动态，操作人显示为自动化或系统身份。

## 9. 状态写入限制

自动化可写入的前提是目标业务对象仍处于可流转状态。订单结束、里程碑结束、工单采集结束后，自动化不能绕过状态限制继续改写业务字段。完整状态矩阵见 [系统自动计算与更新规则](../30-业务流程与产品流程图/系统自动计算与更新规则.md)。

## 10. 定时任务

定时周期：

- 不重复。
- 每天。
- 每周。
- 每月。
- 每月第几个周几。

设置的时间不存在时不执行，且不属于执行失败。

定时任务特殊规则：

- 通知对象仅保留 FlowSpace 成员、协作团队、业务角色、协作方角色 4 个分组。
- 新增工单时需增加订单筛选条件。
- 更新数据时需增加记录范围设置，过滤符合条件的数据。

## 11. 待确认问题

- 部分成功目前为后续规划，当前状态是否只保留成功/失败需要与线上统一。
- 失败通知中的短信规则仍依赖外部模板。
- 自动化与资源库同步、API 同步同时更新同一字段时的优先级需要补规则。
