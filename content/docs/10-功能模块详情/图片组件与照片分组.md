
# 图片组件与照片分组

## 1. 功能定位

图片组件支持把同一业务主题下的照片按“包装整体、外箱标签、包装细节”等分组采集、查看、导入导出和统计，避免为每个主题重复配置图片组件。照片分组适用于主表单及子表内图片字段，并在运营端配置、贸易端和采集端执行。

## 2. 运营端配置

照片分组默认关闭；关闭时沿用普通图片组件。开启后可配置最多 20 个默认分组，并控制是否允许运行态用户维护自定义分组。

| 配置 | 规则 |
| --- | --- |
| 默认分组 | 名称必填、最多 100 字符、组件内去除首尾空格后不可重名，可排序、独立设置必填 |
| 分组必填 | 必填分组至少有 1 张上传成功图片；存在必填分组时组件自动视为必填 |
| 组件上限 | 所有分组共用组件最大图片数；最大图片数不得小于必填默认分组数 |
| 自定义分组 | 默认关闭；开启后用户只维护当前业务实例，不修改模板和其他订单 |
| 国际化 | 可配置默认分组英文名及自定义分组按钮中英文文案 |

启用分组但没有默认分组且未允许自定义分组、分组名为空或重复、必填分组数超过组件图片上限时，不允许保存或发布。复制模板、表单或组件时需完整复制分组配置。

## 3. 配置变更与存量数据

| 变化 | 存量处理 |
| --- | --- |
| 不分组改为分组 | 原图片进入第一个默认分组 |
| 分组改为不分组 | 图片保留并平铺展示，隐藏原分组关系 |
| 新增默认分组 | 既有图片不迁移，新分组为空 |
| 删除默认分组 | 删除该分组及业务实例中的对应图片，必须高风险二次确认 |
| 关闭自定义分组 | 自定义分组图片迁移到第一个默认分组，只移除分组结构 |

## 4. 运行态操作

默认分组可上传、删除图片，但不可改名、删除或排序。只有组件允许自定义分组、用户拥有当前表单编辑权限且对象状态可编辑时，才可新增、改名或删除自定义分组。自定义分组名称必填、最多 100 字符且组件内不可重名；创建后至少需上传 1 张成功图片，否则提交时要求上传或删除该分组。

子表单元格继续以紧凑缩略图汇总展示，不铺开分组标题；进入行详情后查看和编辑分组。拖入照片或点击子表分组图片字段时，先打开分组选择上传弹窗。达到组件总上限、上传未完成或上传失败时禁止继续新增或提交。

## 5. 照片管理集合视图

贸易端工单/批复编辑页和采集端任务详情可提供照片管理入口，统一汇总当前用户有权查看且可编辑表单中的图片组件。条件隐藏、只读或无编辑权限的组件不得进入集合视图。目录沿用模板表单顺序，仅列出至少包含一个可编辑图片组件的表单；子表按行导航，每次展开一行的图片字段。

照片管理只是一种高效编辑视图，变更仍保留在当前业务草稿中，用户返回原页面后统一提交，不增加独立保存状态。

## 6. 配套能力

- Excel 导入导出按默认分组拆列，列名为“图片组件名称/默认分组名称”；自定义分组不通过 Excel 创建，导出时统一进入“自定义”列。
- 列表、批量编辑和翻单继续以缩略图汇总展示；进入上传弹窗后再选择分组。
- 批量下载文件名需包含图片组件名和分组名；工单文件名额外包含工单名称。
- 自动化或资源库向分组图片写入数据时必须指定默认分组。
- BI 的主表与子表图片明细增加“分组名称”列；原图片汇总字段继续汇总全部图片链接。
- 全部入口都必须复用当前表单、字段、对象状态和数据围栏权限，不能因照片管理或导出扩大数据范围。

## 7. 验收重点

覆盖无分组、默认分组、自定义分组、必填、组件总上限、子表行详情、配置切换、删除分组、高风险确认、导入导出、批量下载、自动化、资源库写入、BI 字段，以及贸易端与采集端并发修改和上传失败场景。
