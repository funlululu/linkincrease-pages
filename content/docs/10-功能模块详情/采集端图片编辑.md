
# 采集端图片编辑

## 1. 功能定位

采集端图片编辑用于现场采集人员在提交工单、工单批复或里程碑批复前，对图片组件中的照片进行标记和脱敏处理。

适用图片来源包括现场拍照和相册选择。每次只编辑一张图片；相册支持多选，但选择后不强制逐张预览或编辑。

## 2. 功能范围

| 优先级 | 能力 |
| --- | --- |
| P0 | 拍照预览、相册多选、大图预览、方框标注、文字标注、马赛克、撤销、清空标注、保存编辑、取消编辑、重新编辑、删除图片 |
| P1 | 自由画笔、箭头标注、重做 |

第三方组件和具体技术选型由开发调研确定，不属于当前产品规则。

## 3. 上传与预览流程

### 3.1 拍照

1. 用户点击图片上传区域并选择拍照。
2. 拍照完成后进入单图预览。
3. 用户可直接使用、编辑图片或重新拍摄。
4. 编辑完成后返回预览页，确认使用后加入图片组件并进入上传流程。
5. 返回且放弃当前照片时，需要提示用户确认。

### 3.2 相册多选

- 最大可选数量为“图片组件最大数量减去当前已有图片数量”。
- 选择完成后直接加入图片组件，不逐张进入预览页。
- 图片顺序与相册选择结果保持一致。
- 每张图片独立显示上传状态。
- 用户可点击任意图片进入大图预览、编辑或删除。

### 3.3 大图预览

- 支持左右滑动切换图片，并展示当前位置，如 `2/5`。
- 图片可编辑时展示编辑和删除操作。
- 图片不可编辑时仅允许查看和切换，不展示编辑、删除操作。

## 4. 编辑规则

| 工具 | 规则 |
| --- | --- |
| 方框标注 | 支持拖动生成、调整位置和大小、选中删除；默认使用醒目的红色 |
| 文字标注 | 点击图片位置输入文字，支持移动、修改和删除；单条文字建议最多 100 个字符 |
| 马赛克 | 支持连续涂抹；必须合成到最终图片，输出后不可通过取消图层恢复遮挡区域 |
| 撤销 | 新增、移动、修改或删除标注均记为一次操作；无可撤销内容时按钮置灰 |
| 清空标注 | 清除当前图片全部标注，但保留原图片；执行前二次确认 |

编辑页采用全屏结构，至少包含返回、当前图片、工具栏、撤销、清空和完成。

## 5. 保存、取消与重新编辑

### 5.1 保存编辑

点击完成后：

1. 将原图片和全部标注合成为一张新图片。
2. 使用编辑后的图片替换当前图片。
3. 保持图片数量和排列位置不变。
4. 将编辑后的图片进入上传或重新上传流程。

编辑图片不视为新增图片，不占用新的图片数量。

### 5.2 取消编辑

- 未产生编辑时，返回可直接退出。
- 存在未保存编辑时，提示“当前编辑内容尚未保存，是否放弃？”。
- 用户可继续编辑或放弃编辑。
- 放弃后恢复进入编辑页之前的图片。

### 5.3 重新编辑

表单提交前可以再次编辑已选择图片。重新编辑以当前图片为基础，保存后替换当前图片，不影响其他图片。

## 6. 上传状态与提交限制

图片上传状态包括：

- 待上传。
- 上传中。
- 上传成功。
- 上传失败。

规则：

- 编辑已上传成功的图片时，需要重新上传编辑后的图片并替换原图片。
- 新图片替换成功前保留原图片，避免上传失败导致图片丢失。
- 图片编辑期间暂停当前图片的上传或替换。
- 图片未上传完成时，不允许提交表单。
- 上传失败时保留本地图片，并提供重新上传入口。

## 7. 权限与状态

- 图片编辑入口受图片组件和任务当前是否可编辑控制。
- 工单、工单批复或里程碑批复不可编辑时，仅允许查看图片。
- 图片数量达到组件配置上限时，不允许继续添加图片。
- 图片编辑只改变当前图片文件，不改变表单内其他图片的数量和顺序。

## 8. 待确认问题

- 方框、文字和马赛克是否支持颜色、线条粗细或画笔粗细配置。
- P1 的自由画笔、箭头标注和重做能力是否纳入首期发布。
- 弱网或离线场景下，图片编辑结果、上传队列和重新上传如何持久化。
- 图片压缩、尺寸、格式、文件大小和 EXIF 信息的处理规则。
